# 常见问题

## 一般问题

### Q: Sage 是什么?

A: Sage 是一款记忆型 AI 桌面助手,具备持久记忆、自我进化、技能扩展等能力。它可以帮助你:
- 进行自然语言对话
- 记住跨会话的信息
- 处理 Office 文档
- 执行各种任务(通过技能扩展)

### Q: Sage 支持哪些操作系统?

A: Sage 支持:
- Windows 10/11 (64位)
- macOS (Intel 和 Apple Silicon)
- Linux (Ubuntu 20.04+, Debian 11+)
- Windows 7 SP1 (LTS 版本,支持到 2027-12-13)

### Q: 如何获取 Sage?

A: 访问 [GitHub Releases](https://github.com/oneMuggle/sage/releases/latest) 下载最新版本。

## 配置问题

### Q: 如何配置 API 端点?

A: 
1. 打开**设置**页面
2. 在**模型选择**部分,输入:
   - API Base URL (如 `https://api.openai.com/v1`)
   - API Key
3. 点击**测试连接**验证配置

### Q: 支持哪些 AI 模型?

A: Sage 支持所有兼容 OpenAI API 格式的模型,包括:
- OpenAI GPT 系列
- Anthropic Claude 系列
- 本地模型(通过 Ollama 等)
- 其他兼容 API

### Q: 如何切换模型?

A: 在设置页面的**模型选择**部分,你可以:
- 添加多个 API 端点
- 为不同功能(对话、嵌入等)选择不同的模型

## 记忆系统

### Q: 记忆是如何工作的?

A: Sage 使用三层记忆系统:
1. **工作记忆**: 当前对话的上下文
2. **情景记忆**: 过去的对话记录
3. **语义记忆**: 从对话中提取的知识和事实

### Q: 记忆会占用多少空间?

A: 取决于使用量。默认配置下:
- 每条记忆约 1-5 KB
- 建议保留最近 1000 条记忆
- 可以在设置中调整保留策略

### Q: 如何删除记忆?

A: 
1. 打开**记忆**页面
2. 找到要删除的记忆
3. 点击记忆右侧的删除按钮
4. 或使用批量删除功能清理旧记忆

### Q: 记忆会同步到云端吗?

A: 不会。所有记忆都存储在本地数据库中,不会自动上传到云端。你可以手动备份数据库文件。

## Office 功能

### Q: 支持哪些 Office 格式?

A: Sage 支持:
- Word (.docx)
- Excel (.xlsx)
- PowerPoint (.pptx)
- PDF (读取和部分生成)

### Q: 如何用自然语言编辑文档?

A: 
1. 打开 Office 页面
2. 创建或打开文档
3. 在对话框中输入指令,如:
   - "添加一个标题'第一章'"
   - "在表格中添加一行"
   - "将这段文字改为粗体"

### Q: 文档模板在哪里?

A: 
1. 打开 Office 页面
2. 点击**从模板创建**
3. 选择内置模板或自定义模板

## 更新问题

### Q: 如何更新 Sage?

A: Sage 会自动检查更新。你也可以:
1. 打开**设置**页面
2. 点击**更新**标签页
3. 点击**立即检查**按钮

### Q: 更新会丢失数据吗?

A: 不会。更新过程会保留:
- 所有对话历史
- 记忆数据
- 配置设置
- 技能数据

### Q: 如何回滚到旧版本?

A: 
1. 打开**设置** → **更新**
2. 如果有可用更新,会显示**回滚**按钮
3. 点击回滚并确认

## 故障排除

### Q: 应用启动失败?

A: 
1. 检查系统要求(操作系统版本、内存等)
2. 查看日志文件(在应用数据目录)
3. 尝试重新安装

### Q: API 连接失败?

A: 
1. 检查 API 端点配置
2. 验证 API Key 是否正确
3. 检查网络连接
4. 查看 API 提供商的状态页面

### Q: 应用运行缓慢?

A: 
1. 检查内存使用情况
2. 清理旧记忆(设置 → 记忆 → 修剪)
3. 重启应用
4. 检查是否有后台进程占用资源
