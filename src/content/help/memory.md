# 记忆系统

Sage 的核心特性是**持久记忆**——所有对话都会自动保存,并可在未来对话中智能检索。

## 记忆类型

Sage 使用三层记忆架构:

### 1. 工作记忆(Working Memory)

- **用途**: 当前对话的上下文
- **生命周期**: 仅在当前对话中有效
- **容量**: 受模型上下文窗口限制

### 2. 情景记忆(Episodic Memory)

- **用途**: 保存过去的对话记录
- **生命周期**: 永久保存(除非手动删除)
- **内容**: 完整的对话历史
- **检索**: 按时间、关键词、语义相似度

### 3. 语义记忆(Semantic Memory)

- **用途**: 从对话中提取的知识和事实
- **生命周期**: 永久保存
- **内容**: 结构化的知识点(如"用户偏好 Python"、"项目使用 React")
- **检索**: 智能匹配相关知识点

## 记忆的工作原理

### 自动保存

每次对话都会自动保存到记忆系统:

1. **对话结束**时,Sage 提取关键信息
2. **生成摘要**和知识点
3. **存储到数据库**(本地 SQLite)
4. **创建向量索引**(用于语义检索)

### 智能检索

在新对话中,Sage 会自动:

1. **分析当前输入**的语义
2. **检索相关记忆**(基于向量相似度)
3. **融入回复**中(如果相关)

例如:
- 你说"继续上次的项目讨论"
- Sage 会检索最近的项目相关对话
- 自动加载上下文继续讨论

## 查看和管理记忆

### 打开记忆页面

1. 点击左侧导航栏的**记忆**图标
2. 查看所有保存的记忆片段

### 记忆列表

记忆页面显示:

- **标题**: 记忆的简短描述
- **摘要**: 关键内容预览
- **时间**: 创建/更新时间
- **来源**: 来自哪个对话
- **标签**: 分类标签(如有)

### 搜索记忆

- 在搜索框输入关键词
- 支持按标题、内容、日期筛选
- 语义搜索:输入自然语言描述

### 编辑记忆

1. 点击记忆卡片
2. 修改标题或内容
3. 保存更改

### 删除记忆

1. 找到要删除的记忆
2. 点击右侧删除按钮
3. 确认删除

> **注意**: 删除后无法恢复

### 批量操作

- **多选**: 勾选多个记忆
- **批量删除**: 删除选中的记忆
- **批量导出**: 导出为 JSON 文件

## 记忆设置

### 调整保留策略

1. 打开**设置** → **记忆**
2. 调整以下选项:
   - **最大记忆数量**: 保留最近 N 条记忆
   - **自动修剪**: 超过阈值时自动删除旧记忆
   - **向量索引**: 启用/禁用语义检索

### 修剪记忆

- 点击"修剪记忆"按钮
- Sage 会删除超出保留策略的旧记忆
- 释放存储空间

### 备份和恢复

**备份**:
1. 打开记忆页面
2. 点击"导出"
3. 选择导出格式(JSON / SQLite)
4. 保存到安全位置

**恢复**:
1. 打开记忆页面
2. 点击"导入"
3. 选择备份文件
4. 确认导入

## 记忆同步

### 本地存储

- 所有记忆默认存储在本地数据库
- 不会自动上传到云端
- 数据完全由你控制

### 手动同步(可选)

如果需要跨设备同步:

1. **导出记忆**: 在源设备导出
2. **传输文件**: 通过云盘或其他方式传输
3. **导入记忆**: 在目标设备导入

## 记忆优化

### 提高检索质量

1. **使用清晰的描述**: 在对话中明确表达意图
2. **添加标签**: 为重要记忆添加分类标签
3. **定期整理**: 删除无关或过时的记忆

### 减少存储占用

1. **修剪旧记忆**: 删除不需要的历史记录
2. **调整保留策略**: 设置合理的最大记忆数
3. **定期备份后清理**: 备份后删除旧记忆

## 常见问题

### Q: 记忆会占用多少空间?

A:
- 每条记忆约 1-5 KB
- 1000 条记忆约 1-5 MB
- 向量索引额外占用约 20-30% 空间

### Q: 记忆检索不准确怎么办?

A:
1. 检查记忆内容是否清晰
2. 添加更多上下文信息
3. 调整检索阈值(设置 → 记忆 → 高级)

### Q: 如何禁用自动记忆?

A:
1. 打开**设置** → **记忆**
2. 关闭"自动保存对话"选项
3. 手动选择要保存的对话

### Q: 记忆会被 AI 模型读取吗?

A:
- 记忆存储在你的本地数据库
- 只有在你发起对话时,Sage 才会检索相关记忆
- 检索到的记忆会作为上下文发送给 AI 模型
- 你可以选择不发送记忆(隐私模式)

### Q: 如何查看记忆的向量表示?

A:
1. 打开记忆页面
2. 点击记忆卡片
3. 查看"向量信息"标签页
4. 显示向量维度和相似度得分
