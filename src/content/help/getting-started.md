# 快速上手

欢迎使用 Sage!本节将帮助你快速开始使用这款记忆型 AI 桌面助手。

## 第一步: 配置 API 端点

1. 打开**设置**页面(点击左侧导航栏的"设置"图标)
2. 在"模型选择"部分,配置你的 API 端点:
   - **API Base URL**: 输入你的 API 服务地址(如 `https://api.openai.com/v1`)
   - **API Key**: 输入你的 API 密钥
3. 点击**测试连接**按钮验证配置是否正确

## 第二步: 开始对话

1. 点击左侧导航栏的**对话**图标
2. 在欢迎页面,输入你的第一个问题或消息
3. Sage 会根据你的输入生成回复,并记住这次对话的内容

## 第三步: 探索记忆系统

Sage 的核心特性是**持久记忆**:

- **自动记忆**: 所有对话都会自动保存到记忆系统
- **跨会话**: 你可以在不同的对话中引用之前的内容
- **智能检索**: Sage 会根据当前对话自动检索相关记忆

查看记忆:
1. 点击左侧导航栏的**记忆**图标
2. 浏览所有保存的记忆片段
3. 使用搜索功能快速找到特定内容

## 第四步: 使用技能扩展

Sage 支持通过**技能**扩展功能:

1. 点击左侧导航栏的**技能**图标
2. 浏览可用的技能列表
3. 点击安装按钮添加新技能
4. 在对话中使用 `@技能名` 调用特定技能

## 第五步: Office 文档处理

Sage 可以处理 Word、Excel、PPT 等 Office 文档:

1. 点击左侧导航栏的**Office**图标
2. 创建新文档或打开现有文档
3. 使用自然语言指令编辑文档
4. 导出为所需格式

## 常见问题

### Q: 如何清除对话历史?

A: 在对话页面,右键点击会话列表中的会话,选择"删除"。

### Q: 记忆占用太多空间怎么办?

A: 在设置中调整记忆保留策略,或手动删除不需要的记忆。

### Q: 如何更新 Sage?

A: Sage 会自动检查更新。你也可以在设置的"更新"标签页中手动检查。
