# 编排功能

Sage 的编排(Orchestration)功能让你可以**自动化多步骤任务**,通过可视化界面管理复杂工作流。

## 什么是编排?

编排是 Sage 的高级功能,用于:

- **自动化工作流**: 将多个步骤组合成可重复执行的任务
- **多代理协作**: 让多个 AI 代理协同完成复杂任务
- **任务管理**: 跟踪任务状态、进度和结果

## 核心概念

### 1. 计划(Plan)

计划是编排的核心单元,包含:

- **目标**: 要完成的任务描述
- **步骤**: 分解为多个子任务
- **依赖**: 步骤之间的执行顺序
- **状态**: 待执行 / 执行中 / 已完成 / 失败

### 2. 代理(Agent)

代理是执行任务的 AI 实体:

- **主代理**: 协调其他代理
- **子代理**: 执行具体任务
- **专用代理**: 特定领域的专家(如代码审查、数据分析)

### 3. 任务(Task)

任务是计划中的具体步骤:

- **类型**: 代码生成、测试、审查、部署等
- **输入**: 任务需要的数据或参数
- **输出**: 任务产生的结果
- **状态**: 待执行 / 执行中 / 已完成 / 失败

## 使用编排

### 1. 创建计划

在对话中输入:

```
帮我制定一个项目重构计划
```

Sage 会:
- 分析需求
- 分解为多个步骤
- 生成可视化计划卡片
- 等待你确认

### 2. 查看计划

1. 打开**编排**页面(如果有的话)
2. 查看所有计划列表
3. 点击计划查看详情

### 3. 执行计划

1. 点击"开始执行"
2. Sage 按步骤执行任务
3. 实时显示进度
4. 完成后显示结果

### 4. 监控进度

- **进度条**: 显示总体完成度
- **步骤列表**: 每个步骤的状态
- **日志**: 实时执行日志
- **错误**: 失败步骤的错误信息

## 编排页面

### 计划列表

显示所有计划:

- **标题**: 计划名称
- **状态**: 待执行 / 执行中 / 已完成
- **进度**: 完成百分比
- **创建时间**: 计划创建时间
- **操作**: 查看 / 执行 / 删除

### 计划详情

点击计划查看:

- **目标描述**: 计划的总体目标
- **步骤列表**: 所有步骤及其状态
- **依赖关系**: 步骤之间的执行顺序
- **执行日志**: 详细的执行记录
- **结果输出**: 每个步骤的输出

### 步骤状态

| 状态 | 含义 | 颜色 |
|---|---|---|
| **待执行** | 还未开始 | 灰色 |
| **执行中** | 正在执行 | 蓝色 |
| **已完成** | 执行成功 | 绿色 |
| **失败** | 执行失败 | 红色 |
| **跳过** | 被跳过 | 黄色 |

## 计划类型

### 1. 代码重构计划

```
帮我重构这个模块:
1. 分析现有代码结构
2. 识别问题和改进点
3. 设计新的架构
4. 逐步实施重构
5. 运行测试验证
```

### 2. 功能开发计划

```
开发用户认证功能:
1. 设计数据库模型
2. 实现 API 端点
3. 开发前端界面
4. 编写测试用例
5. 集成测试
6. 部署到测试环境
```

### 3. 数据分析计划

```

3. 探索性分析
4. 生成可视化图表
```

### 4. 文档生成计划

```
生成项目文档:
1. 扫描代码结构
2. 提取 API 接口
3. 生成 API 文档
4. 编写使用指南
5. 创建示例代码
6. 输出完整文档
```

## 高级功能

### 1. 自定义步骤

可以手动添加、编辑、删除步骤:

1. 打开计划详情
2. 点击"编辑步骤"
3. 添加/修改/删除步骤
4. 保存更改

### 2. 调整依赖

可以调整步骤之间的执行顺序:

1. 打开计划详情
2. 点击"依赖关系"
3. 拖动步骤调整顺序
4. 保存更改

### 3. 重试失败步骤

如果某个步骤失败:

1. 查看失败原因
2. 修复问题(如有需要)
3. 点击"重试"按钮
4. 从失败步骤继续执行

### 4. 暂停和恢复

可以暂停执行中的计划:

1. 点击"暂停"按钮
2. 计划暂停在当前步骤
3. 点击"恢复"继续执行

### 5. 导出计划

可以导出计划供后续使用:

1. 打开计划详情
2. 点击"导出"
3. 选择格式(JSON / Markdown)
4. 保存到本地

## 代理协作

### 主代理

主代理负责:

- **分解任务**: 将大任务拆分为小步骤
- **分配工作**: 为每个步骤选择合适的代理
- **协调执行**: 确保步骤按顺序执行
- **汇总结果**: 收集所有步骤的输出

### 子代理

子代理执行具体任务:

- **代码生成代理**: 编写代码
- **测试代理**: 运行测试
- **审查代理**: 审查代码质量
- **文档代理**: 生成文档

### 代理选择

Sage 会根据任务类型自动选择代理:

| 任务类型 | 代理类型 |
|---|---|
| 代码生成 | Code Generator |
| 代码审查 | Code Reviewer |
| 测试执行 | Test Runner |
| 数据分析 | Data Analyst |
| 文档生成 | Doc Writer |

## 计划模板

### 保存为模板

常用的计划可以保存为模板:

1. 打开计划详情
2. 点击"保存为模板"
3. 输入模板名称
4. 保存模板

### 使用模板

从模板创建新计划:

1. 打开编排页面
2. 点击"从模板创建"
3. 选择模板
4. 修改变量(如有)
5. 创建计划

## 常见问题

### Q: 编排和对话有什么区别?

A:
- **对话**: 单次交互,即时回复
- **编排**: 多步骤任务,可视化执行,可暂停/恢复

### Q: 编排会消耗多少 Token?

A:
- 每个步骤都会消耗 Token
- 总体消耗取决于步骤数量和复杂度
- 可以在设置中查看 Token 消耗

### Q: 计划执行失败怎么办?

A:
1. 查看失败步骤的错误信息
2. 分析问题原因
3. 修复问题(如修改代码、调整参数)
4. 点击"重试"继续执行

### Q: 可以并行执行步骤吗?

A:
- 默认按顺序执行
- 如果步骤之间没有依赖,可以并行执行
- 在计划设置中启用"并行模式"

### Q: 如何查看执行历史?

A:
1. 打开计划详情
2. 点击"执行历史"
3. 查看所有执行记录
4. 查看每次执行的日志和结果

### Q: 编排可以自动化吗?

A:
- 可以设置定时执行
- 可以监听事件触发(如文件变更)
- 可以通过 API 调用
