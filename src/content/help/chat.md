# 对话功能

Sage 的核心是与 AI 进行自然语言对话。本章介绍对话功能的基本使用。

## 开始对话

1. 点击左侧导航栏的**对话**图标
2. 在欢迎页面输入你的问题或指令
3. Sage 会生成回复,并自动记住对话内容

## 对话界面

对话页面包含以下区域:

### 左侧边栏

- **会话列表**: 显示所有历史对话
- **新建对话**: 点击 "+" 按钮创建新对话
- **搜索**: 快速查找特定对话
- **右键菜单**: 删除、重命名会话

### 主对话区

- **消息列表**: 显示对话历史
- **输入框**: 输入消息或指令
- **发送按钮**: 发送消息
- **停止按钮**: 停止生成回复

### 右侧面板(可选)

- **Artifacts**: 查看生成的文件(代码、文档等)
- **记忆**: 查看当前对话相关的记忆片段
- **用量**: 查看 Token 消耗和成本

## 高级功能

### 1. 引用记忆

在对话中,你可以引用之前保存的记忆:

```
根据我之前保存的 XX 记忆,...
```

Sage 会自动检索相关记忆并融入回复。

### 2. 使用技能

在对话中调用技能:

```
@技能名 你的指令
```

例如:
```
@code-review 帮我审查这段代码
```

### 3. 引用文档

在 Office 功能启用后,可以引用文档:

```
请分析 @报告.docx 的内容
```

### 4. 多模态输入

- **文本**: 直接输入问题
- **文件**: 拖拽文件到输入框(支持图片、文档等)
- **粘贴**: 从剪贴板粘贴内容

## 对话管理

### 导出对话

1. 点击会话列表中的会话
2. 右键选择"导出"
3. 选择格式(Markdown / JSON)
4. 保存到本地

### 删除对话

1. 在会话列表中找到要删除的对话
2. 右键选择"删除"
3. 确认删除

> **注意**: 删除后无法恢复,但记忆仍保留在记忆系统中

### 搜索对话

- 在左侧边栏的搜索框输入关键词
- 支持按标题、内容、日期筛选

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl/Cmd + Enter` | 发送消息 |
| `Ctrl/Cmd + K` | 打开命令面板 |
| `Ctrl/Cmd + N` | 新建对话 |
| `Ctrl/Cmd + Shift + C` | 复制最后一条回复 |

## 常见问题

### Q: 对话中断了怎么办?

A: 
1. 检查网络连接
2. 检查 API 配置是否正确
3. 重新发送消息或刷新页面

### Q: 回复太慢怎么办?

A:
1. 检查 API 提供商状态
2. 切换到更快的模型
3. 减少输入长度

### Q: 如何清除对话历史?

A:
1. 右键点击会话
2. 选择"删除"
3. 或批量删除多个会话

### Q: 对话会占用多少空间?

A:
- 每条消息约 1-10 KB(取决于长度)
- 默认保留所有对话历史
- 可以在设置中调整保留策略
