# Sage 后端 - 可选依赖
# 安装: pip install -r requirements-optional.txt
#
# 本文件列出与 production 冲突但 Sage 仍希望用户能启用的可选依赖。
# 默认 `pip install -r requirements.txt` 不会安装这些包。
# 启用前请阅读每节顶部的"为什么单独放"说明。

# =============================================================================
# MCP (Model Context Protocol) — 模型上下文协议客户端
# =============================================================================
#
# 为什么单独放:
#   `mcp` 的传递依赖与 `httpx==0.26.0` 锁定版本存在 starlette 版本冲突:
#     - httpx 0.26 要求 starlette<0.36
#     - mcp 0.x 要求的 starlette 上界不同
#   pip install -r requirements.txt 后,mcp 默认**不可用**。
#
# 安装步骤(任选其一):
#
#   A. 兼容升级(推荐):先升 starlette 到 0.41.x,再装 mcp
#      $ pip install -U 'starlette>=0.41' 'httpx>=0.27'
#      $ pip install mcp
#      验证: $ python -c "import mcp; print(mcp.__version__)"
#
#   B. --no-deps 安装(临时方案,可能与其他包冲突):
#      $ pip install mcp --no-deps
#      风险: mcp 自己的依赖被跳过,需要用户自行保证运行时满足
#
#   C. 兼容老 mcp 版本(若 A 失败):
#      $ pip install 'mcp<1.0'
#      自行测试 Sage 与 mcp 的 API 兼容
#
# 验证安装成功:
#   $ python -c "import mcp; print('mcp', mcp.__version__)"
#
# 长期计划(2026-09-15 CVE review):
#   见 docs/plans/2026-09-15_cve-expiry-2026-10-01-review.md Phase 2
#   升级 starlette + httpx 后,本节可降级为单行 `mcp>=1.0`,与 requirements.txt 合并。
#
# 当前推荐: **暂时不要在 main 分支装 MCP**,
#            直到 starlette 升级 PR 完成(预计 2026-09-30 前)。
# =============================================================================
# OCR 扫描件兜底 (office-p4a) — pytesseract + tesseract 二进制
# =============================================================================
# 为什么单独放: OCR 整页光栅化 + tesseract 推理代价高，且 tesseract 是
# 系统级二进制（含中文需 chi_sim 语言包），不适合进默认依赖。
# 启用: 1) pip install pytesseract  2) 安装 tesseract（PATH 可见）
#       3) 中文识别需 chi_sim 语言包  4) 环境变量 SAGE_OCR=1 显式开启
# 验证: SAGE_OCR=1 python -c "from backend.office.ocr import ocr_available; print(ocr_available())"
#
# pytesseract>=0.3.10

# =============================================================================
# Word COM 自动化 (Round 39 目录真页码) — pywin32
# =============================================================================
# 为什么单独放:
#   pywin32 仅 Windows 可用、非 pure-python（含二进制扩展），且只在
#   "本机装有 Microsoft Word" 时才有意义——不适合进默认依赖。
#   现有两个消费方共用本通道:
#     - office/export_pdf.py  Word COM 导出 PDF（SaveAs2, wdFormatPDF）
#     - office/toc_refresh.py 刷新 TOC 域为真页码（TablesOfContents.Update）
#   两者均为懒加载：未安装时优雅降级（capabilities.word_com_available=False，
#   工具返回带安装引导的失败），不影响默认安装面。
# 启用: pip install pywin32
# 验证: python -c "import win32com.client; print('pywin32 OK')"
# win7（Python 3.8 手动启用）: 钉 pywin32==306（最后支持 3.8 的版本）；
#   新功能不回流 release/win7，本条仅供老分支自装参考。
#
# pywin32>=306

# =============================================================================
# AB3 TLS/HTTP2 指纹 (Round 27) — curl_cffi
# =============================================================================
# 为什么单独放:
#   curl_cffi 含平台二进制扩展（libcurl-impersonate），且属于"对抗性增强"
#   而非基础能力 —— 未安装时静态抓取照常走标准 httpx 传输（行为与 R26 前
#   完全一致）。release/win7（Python 3.8 依赖契约）不安装本包。
# 启用: pip install curl_cffi
#       并在 设置→网络→web_access_config 打开 tls_fingerprint（默认关）
# 验证: python -c "import curl_cffi; print('curl_cffi OK')"
#
# curl_cffi>=0.7
