# Landing Page Template

Generate a responsive landing page prototype with the following sections:

## Required Sections

1. **Hero Section**
   - Large headline with value proposition
   - Subheading with supporting text
   - Primary call-to-action button
   - Optional background image or gradient

2. **Features Section**
   - 3-4 feature cards in a grid layout
   - Each card: icon/emoji, title, brief description
   - Responsive grid (3 columns desktop, 1 column mobile)

3. **Call-to-Action Section**
   - Compelling headline
   - Supporting text
   - Prominent action button
   - Visual emphasis (contrasting background)

4. **Footer Section**
   - Company/product name
   - Navigation links (About, Contact, Privacy, Terms)
   - Copyright notice
   - Social media links (optional)

## Design Requirements

- Mobile-first responsive design
- Clean typography hierarchy
- Consistent spacing and padding
- Accessible color contrast (WCAG AA)
- Semantic HTML structure
- Smooth scroll behavior for anchor links

## Content Guidelines

- Use realistic placeholder content (not lorem ipsum)
- Headlines should be benefit-focused
- Keep copy concise and scannable
- Use active voice in CTAs
