# Win7 内网离线诊断与管理员维护

`fix.bat` 现为**只读诊断**：不要求提权，不修改注册表/服务，不注册 DLL，不重启电脑。
它输出系统版本及 TrustedInstaller/wuauserv 的状态、启动类型；服务 STOPPED 或转换中不等于应用不可运行。
不要为了运行 Sage 擅自解除企业组策略或启用 Windows Update。

## 不能启动时

1. 由管理员核对批准的 Windows 7 SP1 x64、SHA-2/服务栈及经 Win7 验证的 VC++/UCRT 基线。
2. 记录错误码、OS build、组件版本和本地日志；应用未能启动时，使用本脚本及组织预检工具，不依赖 Electron 内的检查。
3. 缺少组件：使用管理员从官方/批准来源取得并核验的离线维护包；不要执行在线 pip/conda，不安装主线 requirements，不从不明来源拷贝 DLL。
4. 补丁前置条件、替代关系及必要重启由管理员按目标机器确定。维护需提前保存工作；本脚本不会替用户重启。
5. 若必需基线无法满足，停止部署并申请系统升级/替换；不要关闭签名或 TLS 校验。

## 升级与恢复

升级前备份数据库、附件、配置及批准的凭据恢复材料，并保留原安装包。应用的 `upgrade-backups/` 是 SQLite 固定恢复点，不涵盖所有业务文件。
日常 backups 轮转不应清理它；验证新版稳定且经过维护审批后才可手动归档/清理。
恢复时先停止应用/后端，使用匹配的程序与数据快照；不要让旧程序直接打开已迁移且不兼容的数据库。

详细部署合同见源码仓库 `docs/technical/101-win7-offline-maintenance.md`；安装介质应附该手册与经批准的组件清单。
