后端起不来，日志显示 8765 端口被占用，怎么处理？
大概率是上一次退出时后端子进程没有被回收。可以先确认占用进程： netstat -ano | findstr 8765 ，拿到 PID 后结束它再重启。
2 个工具调用 · 全部成功 展开详情
shell.exec cmd: "netstat -ano | findstr 8765" done
files.read path: backend/main.py done
