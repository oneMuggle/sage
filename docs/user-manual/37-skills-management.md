# 技能管理、导出与备份

> 入口：左侧边栏「技能」→ `/skills`
> 适用版本：含技能页优化的 Sage 版本（M1–M4）

技能是 Sage 可以复用的能力包：一段提示词模板，或者一个带脚本、参考资料、素材的完整工作流。本页说明如何浏览、分组、导出、定位技能，以及版本升级时你的技能会不会丢失。

---

## 1. 技能存在哪里

Sage 的技能分三类，页面上按组展示：

| 分组         | 来源                                                                 | 升级行为                     |
| ------------ | -------------------------------------------------------------------- | ---------------------------- |
| **内置技能** | 随 Sage 代码发布（如搜索、写作、编码）                               | 随应用升级替换               |
| **推荐模板** | 随安装包附带的只读模板（如学术检索、论文写作、PPT 制作）             | 随应用升级替换               |
| **我的技能** | 你自己导入、或由 AI 从对话中沉淀审批生成                             | **保留，不会因升级丢失**     |

「我的技能」默认保存在用户目录：

```
~/.sage/skills/<技能名>/SKILL.md
```

Windows 上是 `C:\Users\<用户名>\.sage\skills\...`。这个目录在家目录里，安装包升级只替换应用目录，不会动它。

> ⚠️ 如果你在 **设置 → 工具与连接 → 技能** 里把「技能目录」改到了应用安装目录内部，升级时可能被替换。建议保持留空（使用默认 `~/.sage/skills`），或指向自己的文档目录。

每张技能行右侧的来源徽章会标出它属于哪一类：**内置 / 模板 / AI 生成 / 已导入 / 本地**。

## 2. 浏览与查找

- 顶部搜索框支持按技能名、描述、触发词搜索。
- 「来源」筛选：只看内置、只看模板、只看我的技能。
- 「状态」筛选：只看已启用、只看已停用、只看已归档。
- 默认是**紧凑列表**，一行一个技能；右上角可切换到**卡片视图**看更完整的信息。
- 点任意一行 → 右侧弹出**详情抽屉**，里面有完整描述、触发词、提示词正文、版本、变更历史和全部管理按钮。

列表分组默认可折叠，点组名即可收起，方便在技能很多时快速定位。

## 3. 启用、停用与管理

- **开关**：行尾开关控制技能是否参与自动触发。关闭后技能仍保留，只是 Sage 不会自动使用它。
- **钉住**：钉住的技能不会被「固化巡检」建议归档。
- **归档**：软隐藏，技能文件不删，可随时取消归档。
- **删除**：只对「我的技能」显示；内置与模板不可删除。删除前需要二次点击确认。
- **变更历史**：查看该技能的修改记录，并支持回滚到上一版。

这些动作在列表行右键菜单、详情抽屉里都能找到。行内 hover 时也会直接显示归档/删除按钮。

## 4. 待审草稿（AI 自动沉淀）

「待审草稿」页签里是 AI 认为值得保存为技能的候选。它们来自三种方式：

1. **复杂回合自动沉淀**：当 AI 在一次任务里连续调用多个工具（读文件、跑命令、查资料等）时，系统会判断这个流程是否值得复用；值得则生成草稿。
2. **主动保存**：你可以对 AI 说「把这个流程保存为技能」，或在聊天里输入 `/learn`。
3. **扫描冷技能**：点技能页的「扫描冷技能」按钮，系统会检查长期未用的技能，给出合并或归档建议。

每张草稿卡可以 **预览** 完整 SKILL.md，再选择 **批准**（写入 `~/.sage/skills` 并立即可用）或 **拒绝**。

> 草稿生成需要先配置好默认模型。如果一直是空的，先到 **设置 → 模型** 完成模型接入；也可以在草稿空态点「从最近会话生成」手动触发一次。

## 5. 从最近会话生成草稿

待审草稿为空时，空态里有一个 **「从最近会话生成」** 按钮：它会取你最近一次对话，让 AI 复盘并尝试沉淀技能草稿。适合你刚完成一个可复用流程、想立即保存的场景。

## 6. 导出技能（备份 / 分享）

有两种导出方式：

- **导出单个技能**：打开技能详情 → 点 **「导出技能」**。会弹出保存对话框，生成 `<技能名>.zip`。
- **导出我的技能**：技能页右上角的下载图标按钮。会把所有「我的技能」打包成一个 `sage-skills.zip`。

zip 内含：

```
<技能名>/
├── SKILL.md
├── scripts/
├── references/
├── assets/
└── templates/
```

只会打包 SKILL.md 与上述白名单目录；其他文件、隐藏文件、符号链接不会被打包。内置技能没有磁盘目录，不能导出。

导出成功后会自动在文件管理器中定位到 zip 文件，方便你复制到网盘或发给同事。

## 7. 打开技能目录 / 在文件夹中显示

- 技能页右上角的 **文件夹搜索图标**：用系统文件管理器打开「我的技能」的根目录。
- 详情抽屉里的 **「在文件夹中显示」**：直接定位到该技能所在的子目录。

这两个入口适合你想手动编辑 SKILL.md、放脚本或整理目录时使用。在 `~/.sage/skills` 下放软链接也可以正常识别和打开。

## 8. 导入技能

页头有两个导入按钮：

- **导入 SKILL.md**：选择一个或多个 `SKILL.md` 文件，系统会为每个技能创建 `~/.sage/skills/<技能名>/` 目录。
- **导入技能目录**：选择整个技能目录（含 `scripts/`、`references/`、`assets/`、`templates/`），会连同附属资源一起导入。

导入成功后技能会立即可用，并标记为「已导入」。同名技能已存在时会跳过，不会覆盖；内置技能同名也会跳过。

## 9. 常见问题

**Q：升级 Sage 后我的技能还在吗？**
A：在。「我的技能」保存在 `~/.sage/skills`，升级不会删除。只有你把技能目录设置到了应用安装目录内才有风险，建议改回默认。

**Q：为什么待审草稿一直是空的？**
A：先确认已配置默认模型；另外草稿需要一定的触发条件（多工具复杂回合、主动 `/learn`、或手动扫描冷技能）。空态里的「从最近会话生成」可以立即触发一次。

**Q：内置技能/模板能改吗？**
A：不能直接改，升级时会被替换。想自定义，把修改后的技能目录导入到用户目录即可，同名用户技能优先级高于模板。

**Q：导出 zip 后怎么分享给别人？**
A：把 zip 发给对方，让对方在技能页用 **导入技能目录** 选择解压后的目录（或先解压再导入）；SKILL.md 会自动解析并注册。

**Q：删除技能会删掉我的文件吗？**
A：会删除 `~/.sage/skills/<技能名>` 整个目录，不可撤销。建议先导出备份。内置技能与模板不可删除。
