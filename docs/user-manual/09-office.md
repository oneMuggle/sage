# 09. Office 文档管理

> **适用版本**: Sage main @ 2026-09-09 —— Office 对标批次 1-3 + Round 2/3(PR #554 / #561 / #564 / #569)
> **用户入口**: 桌面端 Office 页面(`/office` 路由)+ Chat 内自动调用

## 9.1 什么是 Office 文档助手

Sage 现在可以用**自然语言**帮你创建、读取、编辑、分析、转换 **Word(`.docx`)、Excel(`.xlsx`)、PowerPoint(`.pptx`)、PDF** 四类文档,并从模板一键生成。

完整流程是:**在 chat 里告诉 Sage 你想做什么** —— 它会自动创建文件、修改内容、分析数据、插入图表图片、导出 PDF、归档历史版本,并在工作区里管理这些文档的元数据。误删可以恢复,误改可以撤销(改前快照 + 验证历史),二进制文件不会被文本流破坏。

简单说:**Sage 是你的 Office 文档助手,文档跟对话一起走,不会因为切窗口或重启软件而丢失。所有数据只在你的电脑上处理。**

## 9.2 你能用它做什么

### 9.2.1 创建一份新文档

**场景**: "帮我做一份 2026 Q4 销售报告的 PPT"

Sage 会:

1. 让你选择保存到哪个工作区(绑定的当前工作区,或选一个新目录)
2. 根据你描述的标题和大纲生成 PPT
3. 把文件落盘并在 Office 页面登记
4. 生成后**自动回读摘要**(页数/段落数/表格数)核对是否符合你的要求
5. 把生成的文档链接附在回复里

你会看到:

- 一个 `.pptx` 文件出现在你选的工作区
- Office 页面里多了一条记录
- Chat 回复末尾有"已生成 X 文档,可在 Office 页面查看"

> **小贴士**: 生成 Excel / Word / PDF 同理 —— "做一份 2026 年客户满意度调查表(xlsx)"、"写一份季度总结文档(docx)"、"生成一份两页的活动说明 PDF"。

### 9.2.2 修改现有文档

**场景**: "把这份 docx 的标题改成 '2026 年度战略复盘'"

Sage 会:

1. 自动定位你说的文档(用文件名或 `@文件名` 引用)
2. 在改之前**自动备份当前版本**(快照,用户可在 Office 页面回滚)
3. 用 python-docx / openpyxl / python-pptx 改文件
4. 改完自动回读摘要让你核对

支持的操作包括(不限于):

- **Word**: 替换文字、追加段落/表格、改表格单元格、删段落、调段落样式(字号/加粗/斜体/颜色/对齐)、插图片、加批注/删批注
- **Excel**: 设单元格(**支持 `=SUM()` 公式**)、追加行、增/删/改名 sheet、原生图表(折线/柱状/饼图)、列宽/数字格式/填充色/冻结窗格
- **PPT**: 替换文字、改标题/要点/备注、增/删页、插图片、版式选择

> **提示**: 可以让 Sage "先预览一下改动"(dry-run)——它会给出逐条变更清单而不落盘;Office 页面的「编辑预览」对话框也能先看红绿 diff,确认后**一键应用**(应用前自动留快照)。

### 9.2.3 公式与数据分析

**场景**: "这张表里哪个类别销售额最高?做个汇总"

- Excel 单元格支持**真公式**——Sage 写入的 `=SUM(B2:B10)` 在 Excel 打开时正常计算;读取时即使文件里没有缓存值,Sage 也能**本地求值**直接给出结果(个别复杂函数除外,见 Q10)
- `office_analyze` 能做**本地数据分析**:统计描述、分类计数、分组聚合、相关性分析——需要时还会生成带原生图表的分析报告 xlsx,聚合图表同步出现在对话里。**数据全程不出你的电脑**

### 9.2.4 图表与图片

- Excel 里插入**原生图表**(在 Excel 中可继续编辑)
- Word / PPT 里插入图片(base64 或工作区文件,≤10MB)
- "画个趋势图"类请求,Sage 会用图表引擎渲染并插入文档

### 9.2.5 从模板创建

Office 页面生成表单切到「从模板创建」,内置 **10 套中文模板**:

| 类型 | 模板 |
|---|---|
| Word | 周报、会议纪要、项目计划、日报、项目复盘、简历 |
| Excel | 预算表、库存台账 |
| PPT | 项目启动会、周例会 |

选模板 → 填占位符(标题/日期/表格内容…) → 一键生成。也可以把自己的模板(含 `{{变量}}` 标记的 .docx / .xlsx / .pptx)放进工作区 `office/templates/` 目录,Sage 会自动识别并列出。

### 9.2.6 PDF 能力

- **读**: 提取文本、表格、页数
- **生成**: 从标题 + 段落生成中文 PDF(A4/Letter/Legal)
- **表单**: AcroForm 表单读取与填充(可拍平)
- **转 Word**: 文本版 PDF 一键转成可编辑 docx(保留标题层级与表格;扫描件需 OCR,暂不支持)
- **导出**: Word/Excel/PPT → PDF——需要本机装有 LibreOffice 或 MS Word(见 Q9),Office 页面点「导出 PDF」即可

### 9.2.7 归档与恢复

**场景**: "这份旧报价单先收起来"

- 归档是**软删除**:文档从默认列表消失,随时可恢复
- Office 页面「归档文档」视图支持**多选批量**归档/恢复

### 9.2.8 版本快照与验证历史

- 每次编辑前自动留快照(每文档保留最近 10 份/100MB),文档行的「历史版本」面板可**一键恢复到任意版本**(恢复前也会为当前状态留底,恢复本身可撤销)
- 每次 AI 创建/编辑/归档后的**验证结果**(页数、段落、表格等回读摘要)记入「验证历史」,随时可查——AI 改了什么、验证是否通过,全程可追溯

### 9.2.9 在 chat 里 `@文件名` 引用文档

`@` 引用 docx/xlsx/pptx/**pdf**,Sage 会把文档的结构化摘要(标题层级、整段正文、表格转 markdown、公式、批注概况、页数)注入对话上下文,让回答有据可依。

### 9.2.10 不让 Sage 用 write_file 写二进制文件

二进制格式(docx/xlsx/pptx/pdf 等)一律走 office 工具族——带格式校验、前置快照、入库登记;`write_file` 会拒绝二进制扩展名,防止文本流破坏文档结构。

## 9.3 常见问题 FAQ

### Q1. 文档归档后还能找到吗?

**A**: 能。Office 页面顶部切到「归档文档」视图即可看到,支持单条或**批量**恢复。

### Q2. 编辑过的文件会自动备份吗?

**A**: 会。每次编辑前自动生成快照(保留最近 10 份/100MB);在「历史版本」面板可一键回滚,恢复前还会为当前状态再留一版。

### Q3. chat 里 `@文件名` 怎么用?

**A**: 输入 `@` 后从弹层选择,或直接 `@文件名`。支持 docx / xlsx / pptx / **pdf**。Sage 注入文档结构摘要(含批注概况),回答更准。

### Q4. 为什么 LLM 不让我删/写某些文件?

**A**: 工作区之外的写入需要你逐次审批;破坏性删除已从界面与默认工具面移除(用归档代替)。writer 助手档位也没有删除权限。

### Q5. 文档改坏了能撤销吗?

**A**: 三重保障:①「历史版本」恢复到任意快照;②归档/恢复软删除;③「验证历史」让你定位是哪一步改坏的。

### Q6. 为什么我看不到 `/office` 页面?

**A**: 需要先绑定一个工作区(页面有引导)。图表渲染、数据分析、公式本地求值等新能力需要 main 通道版本;Win7 LTS 通道因依赖限制不含这些能力。

### Q7. 多个工作区之间能互相引用文档吗?

**A**: 不能。`office_doc_scope` 严格限定在当前绑定的工作区下 —— 即使你 `@文件名`,Sage 也只在当前工作区里找。跨工作区引用需要先切换工作区。

### Q8. 文档元数据(`derived_from`、`original_filename`)是什么意思?

**A**: 两个 Sage 自动维护的字段:

- **`original_filename`**: 你(或上传工具)给文件的原始名(如 `Q4报告.pptx`)。Sage 内部用 UUID 目录管理,但保留原始名便于引用。
- **`derived_from`**: 如果这份文档是从另一份文档派生出来的(例如"PDF 转出来的 Word"、"基于模板生成的报告"),`derived_from` 指向源文档。Lineage 追溯用。

这两个字段在 re-read(再读一次)时**不会丢失**。

### Q9. 导出 PDF 提示"未找到转换器"?

**A**: Office→PDF 依赖本机的 LibreOffice 或 MS Word,Sage 不捆绑安装。装任一即可;LibreOffice 不在默认路径时,可设环境变量 `SAGE_SOFFICE_PATH` 指向 soffice 可执行文件。

### Q10. 公式显示"需在 Excel 中打开后生效"?

**A**: 本地求值引擎不支持个别复杂函数、或公式超过 500 个(求值上限)时会降级为提示。文件在 Excel 中打开并保存一次后,缓存值即可被直接读取。

## 9.4 注意事项

### 9.4.1 破坏性操作要二次确认

- **删除已从界面与默认工具面移除**:用归档(软删除)代替,可恢复
- **恢复快照、应用编辑**都有确认步骤;应用前自动留快照
- **`office_restore` 是幂等的**:已经可见的文档再调一次不报错,直接返回成功

### 9.4.2 工作区绑定

- Office 文档全部在**当前绑定的工作区**下管理,绑定的目录在 Settings 里改
- 切换工作区后,旧的 chat 里 `@文件名` 会失败(文档在新工作区找不到)
- 跨工作区搬文档需要手动复制文件 + 在新工作区 office_create

### 9.4.3 数据本地化

- 所有文档元数据存在**本机 SQLite**(`office_documents` / `office_self_checks` 表)
- 文档文件存在**工作区磁盘**上(不做云同步)
- 文档读取、编辑、数据分析、公式求值全部本地完成,不经过任何服务器
- 删除 session **不会**自动删除磁盘上的 office 文档

### 9.4.4 LLM 行为不可预测时的兜底

三层兜底,不必再把重要文档藏在工作区外:

1. **dry-run 预览**: 让 LLM 先给变更清单(不落盘),确认再应用
2. **改前快照**: 每次 update/应用自动留底,「历史版本」一键回滚
3. **验证历史**: 每步操作的回读摘要入库,错误可定位、可追溯

> 旧版手册建议"重要源文档放工作区外"——现在有了快照 + 历史 + diff 确认,工作区内协作是安全的;对绝不容有失的原始档案,仍建议保留只读副本。

## 9.5 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| chat 里 `@文件名` 报 404 | 文件名拼错 / 在归档状态 / 不在当前工作区 | 检查文件名 / "恢复"它 / 切换工作区 |
| office_create 报 `content_shape_invalid` | LLM 传了错误形状的参数 | 让 LLM 重新尝试,或换个描述方式 |
| 导出 PDF 失败"未找到转换器" | 本机无 LibreOffice/Word,或 `SAGE_SOFFICE_PATH` 无效 | 安装其一 / 修正环境变量 |
| 公式读不到计算值 | 复杂函数不支持 / 公式数超 500 / 无缓存值 | 见 Q10;或拆分公式 |
| 图表生成报错 | main 通道缺 matplotlib | 安装依赖;Win7 LTS 不支持 |
| 模板没出现在列表 | 不在 `office/templates/` 或扩展名不符 | 放置 .docx/.xlsx/.pptx 模板 |
| 预览空白/截断 | 文档过大触发展示上限 | 用 chat 的 office_read 看全文 |
| /office 页面空白 | 没绑定工作区 / 数据库表损坏 | Settings 绑定工作区 / 跑 sage doctor |
| Win7 上部分能力缺失 | matplotlib/pandas 无法进 Win7 打包 | 使用 main 通道 |
