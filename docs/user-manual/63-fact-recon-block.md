# 事实侦察区块

当你发出一个需要背景资料的请求时，Sage 会先做一轮**事实侦察**，再开始正式回答。侦察到的内容现在会显示在对话气泡里的「**事实侦察**」区块中，你可以随时展开核对。

## 区块长什么样

气泡里会出现一条可点击的折叠头：

```
▸ 事实侦察 · 5 条事实 · 12.3s
```

点击后展开，逐条列出侦察到的事实：

```
1. 项目的依赖版本约束在 backend/requirements.txt 中集中维护
   来源：backend/requirements.txt
2. 前端使用 Vite 开发服务器，默认端口 1420
   来源：vite.config.ts
3. ...
```

- **条数**是这一轮侦察找到的事实条数。
- **耗时**是侦察阶段实际用掉的时间。
- 侦察正在进行时，折叠头会显示「· 侦察中」，并且区块**自动展开**，方便你看着它一条条填出来。

## 展开与收起

| 场景 | 行为 |
| --- | --- |
| 侦察进行中 | 自动展开 |
| 侦察完成后 | 保持展开，方便你立刻逐条核对 |
| 你手动点过之后 | 以你的选择为准，不会再被自动策略改动 |

也就是说：想实时看着它填，看它自己展开就行；看完了、不需要时，手动点折叠头收起即可。

## 事实正文不会被截断

这是这个区块存在的核心理由 —— **正文完整换行显示，不做省略**。你可以逐条读完，判断内容是否正确、是否遗漏。

如果侦察出的事实太多（单次上限 12 条），区块底部会提示「事实条数超过展示上限，仅显示前 N 条」，让你知道还有内容没显示出来。

## 来源标注

如果侦察到的某条事实带有来源（例如某个文件路径、某篇文档），会显示在正文下方的浅色标签里，写着「来源：xxx」。没有来源的事实不带这个标签。

## 侦察过程

展开事实清单后，还有一个二级折叠项「**侦察过程（N）**」，里面是这一轮侦察的思考、工具调用与结果轨迹（例如读了哪些文件、搜了哪些关键词）。

- 侦察进行中时它默认展开，侦察完成后保持展开；
- 你可以单独点它收起或展开，不影响事实清单本身的展开状态。

## 刷新之后还在

事实清单会随这条回答一起保存。**刷新页面、重新打开会话、甚至重启 Sage 之后，这条回答里的「事实侦察」区块依然在** —— 你随时可以回看当时侦察到了什么，核对结论是否可靠。

## 什么时候看不到这个区块

- 简单任务不需要侦察，直接回答 —— 不会出现这个区块。
- 选择**深度调研**时，走的是另一套展示（调研报告），不会重复显示事实清单。

## 常见问题

**Q：区块是空的 / 什么都不显示？**
A：说明这一轮没有侦察产出事实（或任务很简单跳过了侦察）。区块在没有数据时不会显示空盒子。

**Q：为什么规划进度里看不到侦察的过程行了？**
A：侦察过程已经移到「事实侦察」区块里了，避免同一段内容在两处重复出现。规划进度里仍保留「事实侦察」这个阶段本身的状态点与耗时。

**Q：事实看完了能标注「这条不对」吗？**
A：当前版本只做展示，暂不支持逐条标注与反馈回流。
