# 端点思考参数（推理强度 / 思考预算）

> 适用版本：main + release/win7（2026-11-03 起）
> 入口：设置 → 模型与端点 → 端点列表 → 编辑端点

## 1. 这是什么

不同的推理模型对"思考"的控制方式不一样：有的按**强度档位**（低/中/高），有的按
**token 预算**。Sage 把这两种控制放到**端点配置**里，你可以为每个端点单独设置，
互不影响。

| 设置项 | 作用 | 取值 |
| --- | --- | --- |
| **推理强度** | 告诉支持 `reasoning_effort` 的模型（如 OpenAI o1/o3 系列）用多少推理力度 | 关闭（默认）/ 低 / 中 / 高 |
| **思考预算** | 限制模型最多花多少 token 用于思考（Anthropic / DeepSeek / Gemini 等） | 留空（默认）/ 0 / 正整数 |

## 2. 怎么配置

1. 打开 **设置 → 模型与端点**；
2. 在端点列表中找到目标端点，点击**编辑**；
3. 展开该端点的详细配置，找到 **推理强度** 与 **思考预算** 两项；
4. 选择或填写需要的值；
5. 保存设置。

> 这两个字段是**按端点**保存的。切换模型时请确认对应端点的取值是否符合预期。

## 3. 取值说明

### 3.1 推理强度

- **关闭**（默认）：不向模型发送推理强度参数，使用模型自身默认行为；
- **低 / 中 / 高**：发送给支持该参数的上游模型。

如果模型不支持 `reasoning_effort`，上游通常会忽略该参数。

### 3.2 思考预算

- **留空**（默认）：不发送思考预算，使用上游默认值；
- **0**：显式关闭思考（适用于支持 `thinking_budget=0` 的模型，如 Gemini 2.5）；
- **正整数**：思考 token 上限。数值越大，模型可用于推理的预算越多，响应时间与费用也越高。

> 清空输入框 = 留空 = 不发送参数，**不等于** 0。要关闭思考请显式填 `0`。

## 4. 与「思考过程展示档位」的关系

- **端点的思考参数**决定上游模型**是否产出**思考内容；
- **思考过程展示档位**（聊天区顶部工具条 / 设置 → 基础设置）决定前端**显示多少**思考内容。

如果上游始终没有产出思考内容，先检查本页的思考参数是否配置正确，而不是去调展示档位。

## 5. 常见问题

**Q：改了之后没生效？**

1. 确认修改的端点就是当前会话使用的端点；
2. 确认保存成功（设置页会显示保存结果提示）；
3. 新开的会话才会使用新端点的最新配置；进行中的会话可能沿用启动时的配置；
4. 若模型本身不支持该参数，上游会忽略——换用支持思考的模型（如 o1/o3、DeepSeek reasoner、Gemini 2.5）再验证。

**Q：填了预算但完全看不到思考？**

思考预算只控制"能用多少"，模型是否可以输出思考内容还取决于模型能力与上游是否支持。
可先用一个已知支持思考的模型做对照。

**Q：数值填多大合适？**

通常从几百到几千 token 起步，根据任务复杂度调整。预算越大，耗时与费用越高。
