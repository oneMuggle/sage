# 网页模式（Web Fallback）

> 当桌面端无法运行时（如 Win7 Electron 21 安全更新受限），可通过浏览器使用 Sage 核心功能。

---

## 1. 什么是网页模式？

网页模式是 Sage 的**降级通道**，允许您通过浏览器访问 Sage 的核心功能（聊天、会话管理、Wiki），而不需要 Electron 桌面端。

**适用场景：**
- Windows 7 用户无法升级 Electron（CVE 安全更新受限）
- 桌面端启动失败的临时替代方案
- 需要在多台设备间快速切换

**不适用场景：**
- 需要文件选择器、Office 导入等桌面端专属功能
- 需要系统托盘、全局快捷键等桌面集成

## 2. 浏览器要求

| 浏览器              | 最低版本     | 说明                          |
| ------------------- | ------------ | ----------------------------- |
| Google Chrome       | 109+         | Win7 最后支持的 Chrome 版本   |
| Mozilla Firefox     | ESR 102+     | Win7 最后支持的 Firefox 版本  |
| Microsoft Edge      | 109+         | 基于 Chromium，同 Chrome 要求 |

> **Win7 用户注意**：Chrome 109 和 Firefox 115 ESR 是最后支持 Windows 7 的版本。请确保已安装。

## 3. 启动网页模式

### 3.1 Windows（一键启动）

1. 打开 Sage 安装目录
2. 双击运行 `scripts\sage-web.bat`
3. 等待浏览器自动打开

脚本会自动：
- 检查环境（Python、后端代码、前端构建）
- 生成安全 token
- 启动后端服务
- 打开浏览器

### 3.2 命令行启动

```bash
# 构建前端（首次需要）
npm run build:web

# 启动后端
scripts\sage-web.bat
```

## 4. 访问 Sage

启动后，浏览器会打开类似以下地址：

```
http://127.0.0.1:8765/?token=xxxxxxxxxxxxxxxx
```

**地址说明：**
- `127.0.0.1:8765` - 本地后端地址
- `?token=xxx` - 安全认证 token（自动生成，无需手动输入）

> **安全提示**：token 是临时的，后端重启后会变化。请勿分享此 URL。

## 5. 功能对照

| 功能         | 桌面端 | 网页模式 | 说明                          |
| ------------ | ------ | -------- | ----------------------------- |
| 聊天对话     | ✅     | ✅       | 完整可用                      |
| 会话管理     | ✅     | ✅       | 创建、切换、删除会话          |
| Wiki 知识库  | ✅     | ✅       | 查看和编辑 Wiki 文档          |
| 专家对话     | ✅     | ✅       | 与 AI 专家对话                |
| 文件选择器   | ✅     | ❌       | 需要使用"上传"按钮替代        |
| Office 导入  | ✅     | ❌       | 网页模式暂不支持              |
| 桌面宠物     | ✅     | ❌       | 仅桌面端可用                  |
| 全局快捷键   | ✅     | ❌       | 仅桌面端可用                  |
| 系统托盘     | ✅     | ❌       | 仅桌面端可用                  |

**功能降级标识**：不可用的功能按钮会显示为灰色，鼠标悬停时显示"此功能仅桌面端可用"提示。

## 6. 常见问题

### 6.1 页面打不开？

**检查后端是否启动：**

```bash
curl http://127.0.0.1:8765/health
```

应返回 `{"status":"ok",...}`。如果失败，后端未启动。

**解决步骤：**
1. 关闭已打开的浏览器页面
2. 重新运行 `scripts\sage-web.bat`
3. 等待 30 秒让后端启动

### 6.2 提示"本地授权凭据无效"？

这通常是因为 URL 中的 token 与后端不匹配。

**解决步骤：**
1. 关闭浏览器页面
2. 关闭后端（Ctrl+C）
3. 重新运行 `scripts\sage-web.bat`

### 6.3 聊天功能正常但其他功能报错？

某些高级功能（如 Office 文档操作）在网页模式下不可用，会显示错误提示。这是正常行为。

### 6.4 如何停止网页模式？

**Windows：**
1. 在运行后端的命令行窗口按 `Ctrl+C`
2. 关闭浏览器页面

### 6.5 数据会丢失吗？

不会。网页模式和桌面端共享同一份数据（存储在本地数据库）。切换使用不会丢失任何数据。

## 7. 与桌面端的关系

| 对比项       | 桌面端                    | 网页模式                    |
| ------------ | ------------------------- | --------------------------- |
| 启动方式     | 双击 Sage 图标            | 运行脚本 + 浏览器           |
| 功能完整度   | 100%                      | 核心功能约 70%              |
| 离线使用     | 支持（本地后端）          | 支持（本地后端）            |
| 数据同步     | 本地存储                  | 本地存储（同一份数据）      |
| 推荐场景     | 日常使用                  | 临时替代 / Win7 降级        |

**建议**：如果桌面端能正常运行，优先使用桌面端获得完整功能体验。

## 8. 技术信息（高级用户）

如需了解更多技术细节，请参阅[技术文档](../technical/103-web-fallback-mode.md)。

**关键环境变量：**
- `SAGE_WEB_MODE=1` - 启用网页模式
- `SAGE_LOCAL_AUTH_TOKEN` - 认证 token（自动生成）
- `PYTHON_BACKEND_PORT` - 后端端口（默认 8765）
