# 网页模式（Web Fallback）

> 当桌面端无法运行时（如 Win7 Electron 21 安全更新受限），可通过浏览器使用 Sage 核心功能。

---

## 1. 什么是网页模式？

网页模式是 Sage 的**降级通道**，允许您通过浏览器访问 Sage 的核心功能（聊天、会话管理、Wiki），而不需要 Electron 桌面端。

**适用场景：**

- Windows 7 用户无法升级 Electron（CVE 安全更新受限）
- 桌面端启动失败的临时替代方案
- 需要在多台设备间快速切换

**不适用场景：**

- 需要文件选择器、Office 导入等桌面端专属功能
- 需要系统托盘、全局快捷键等桌面集成

## 2. 浏览器要求

| 浏览器          | 最低版本 | 说明                          |
| --------------- | -------- | ----------------------------- |
| Google Chrome   | 109+     | Win7 最后支持的 Chrome 版本   |
| Mozilla Firefox | ESR 102+ | Win7 最后支持的 Firefox 版本  |
| Microsoft Edge  | 109+     | 基于 Chromium，同 Chrome 要求 |

> **Win7 用户注意**：Chrome 109 和 Firefox 115 ESR 是最后支持 Windows 7 的版本。请确保已安装。

## 3. 启动网页模式

### 3.1 安装版 Windows（推荐）

1. 打开**开始菜单**，点击「**Sage 网页模式**」
   （等同于双击安装目录下的 `SageWeb.cmd`）
2. 等待浏览器自动打开

启动器会自动：

- 使用安装包内置的 Python 启动本地后端，**无需**系统 Python / Node
- 若默认端口 `8765` 被占用，自动改用下一个空闲端口
- 生成安全 token 并打开浏览器

### 3.2 源码目录（开发者）

在 Sage 源码目录中，先激活后端环境，再运行：

```bash
conda activate sage-backend
scripts\sage-web.bat
```

首次运行若缺少前端产物，会提示执行 `npm run build:web`。

## 4. 访问 Sage

启动后，浏览器会打开类似以下地址：

```
http://127.0.0.1:8765/?token=xxxxxxxxxxxxxxxx
```

**地址说明：**

- `127.0.0.1:8765`（若该端口被占用会顺延，例如 `127.0.0.1:8766`）- 本地后端地址
- `?token=xxx` - 安全认证 token（自动生成，无需手动输入）

> **安全提示**：token 是临时的，后端重启后会变化。请勿分享此 URL。

## 5. 功能对照

| 功能        | 桌面端 | 网页模式 | 说明                   |
| ----------- | ------ | -------- | ---------------------- |
| 聊天对话    | ✅     | ✅       | 完整可用               |
| 会话管理    | ✅     | ✅       | 创建、切换、删除会话   |
| Wiki 知识库 | ✅     | ✅       | 查看和编辑 Wiki 文档   |
| 专家对话    | ✅     | ✅       | 与 AI 专家对话         |
| 文件选择器  | ✅     | ❌       | 需要使用"上传"按钮替代 |
| Office 导入 | ✅     | ❌       | 网页模式暂不支持       |
| 桌面宠物    | ✅     | ❌       | 仅桌面端可用           |
| 全局快捷键  | ✅     | ❌       | 仅桌面端可用           |
| 系统托盘    | ✅     | ❌       | 仅桌面端可用           |

**功能降级标识**：不可用的功能按钮会显示为灰色，鼠标悬停时显示"此功能仅桌面端可用"提示。

## 6. 常见问题

### 6.1 页面白屏 / 显示"当前浏览器无法加载 Sage"？

网页模式依赖现代浏览器的 ES Modules。**Windows 7 自带的 Internet Explorer 不受支持**，
请安装 Chrome 109+ / Firefox ESR 102+ / Edge 109+ 中的任意一个，并设为默认浏览器后
重新点击「Sage 网页模式」。

如果页面 8 秒内没有任何内容，启动器打开的就是不兼容的浏览器；此时可以直接把
命令行窗口里打印的地址（形如 `http://127.0.0.1:8765/?token=…`）粘贴到已安装的
Chrome/Firefox 地址栏打开。

**检查后端是否启动：**

```bash
curl http://127.0.0.1:8765/health
```

应返回 `{"status":"ok",...}`。如果失败，后端未启动。

**解决步骤：**

1. 关闭已打开的浏览器页面
2. 重新点击开始菜单「Sage 网页模式」（源码目录运行 `scripts\sage-web.bat`）
3. 等待 30 秒让后端启动

### 6.2 提示"本地授权凭据无效"？

这通常是因为 URL 中的 token 与后端不匹配。

**解决步骤：**

1. 关闭浏览器页面
2. 关闭后端（Ctrl+C）
3. 重新点击开始菜单「Sage 网页模式」（源码目录运行 `scripts\sage-web.bat`）

### 6.3 配置 API 端点时提示"连接失败: 上游返回 401：API Key 无效或已过期"？

先确认提示里的措辞 —— 网页模式下有两类 401，含义不同：

| 提示                                 | 含义                                    | 处理                                            |
| ------------------------------------ | --------------------------------------- | ----------------------------------------------- |
| `上游返回 401：API Key 无效或已过期` | 上游服务商拒绝了您的 API Key            | 检查 Base URL 与 Key；见下方步骤                |
| `本地授权凭据无效：请刷新页面`       | 网页模式的本地凭据失效，与您的 Key 无关 | 关闭页面重新启动「Sage 网页模式」获取新的 token |

> 2026-11-24 修复：此前浏览器端把本地凭据与上游 Key 都放进 `Authorization`，
> 两者互相覆盖，导致**填对了 Key 也报"API Key 无效"**。现已分开携带
> （本地凭据走 `X-Sage-Local-Authorization`，上游 Key 走 `Authorization`）。

仍报"上游返回 401"时：

1. 确认 Base URL 完整且以 `/v1` 结尾（部分服务商要求 `https://host/v1`）
2. 确认 Key 没有多余空格或换行
3. 确认该 Key 有权限访问所选模型（部分网关按 Key 分组路由模型）

### 6.4 聊天功能正常但其他功能报错？

某些高级功能（如 Office 文档操作）在网页模式下不可用，会显示错误提示。这是正常行为。

### 6.5 如何停止网页模式？

**Windows：**

1. 在运行后端的命令行窗口按 `Ctrl+C`
2. 关闭浏览器页面

### 6.6 数据会丢失吗？

不会。网页模式和桌面端共享同一份数据（存储在本地数据库）。切换使用不会丢失任何数据。

## 7. 与桌面端的关系

| 对比项     | 桌面端           | 网页模式                           |
| ---------- | ---------------- | ---------------------------------- |
| 启动方式   | 双击 Sage 图标   | 开始菜单「Sage 网页模式」 + 浏览器 |
| 功能完整度 | 100%             | 核心功能约 70%                     |
| 离线使用   | 支持（本地后端） | 支持（本地后端）                   |
| 数据同步   | 本地存储         | 本地存储（同一份数据）             |
| 推荐场景   | 日常使用         | 临时替代 / Win7 降级               |

**建议**：如果桌面端能正常运行，优先使用桌面端获得完整功能体验。

## 8. 技术信息（高级用户）

如需了解更多技术细节，请参阅[技术文档](../technical/152-web-fallback-mode.md)。

**关键环境变量：**

- `SAGE_WEB_MODE=1` - 启用网页模式
- `SAGE_LOCAL_AUTH_TOKEN` - 认证 token（自动生成）
- `PYTHON_BACKEND_PORT` - 起始端口（默认 8765，被占用时自动顺延）
