# Plan Mode 增强：智能规划与步骤确认

> 适用版本：2026-10 及以后。技术实现见 [技术文档 108](../technical/108-plan-mode-enhancement.md)。

## 1. 这个功能解决什么问题

当你用 `/plan` 让 Sage 先规划再执行时，Sage 现在会自动判断任务有多复杂，并据此调整调研深度、执行模式和确认点：

- **简单任务**（改 typo、调颜色）：不调研、不打断，直接执行；
- **中等任务**（加按钮、重构函数）：轻量侦察后给出计划，执行前确认一次；
- **复杂任务**（设计子系统、性能优化）：深度调研、给出调研摘要供你审阅，并在执行到破坏性步骤前暂停询问。

---

## 2. 你会看到的三个新界面

### 2.1 执行模式推荐（PlanApprovalBar 内）

计划生成后，计划卡片的上方会出现一行推荐：

```
推荐：编排模式（多 agent 并行）    [按推荐执行 ▾]
```

下拉可覆盖为：

| 选项 | 含义 |
|------|------|
| 按推荐执行 | 采纳 Sage 的判断 |
| 强制单 agent | 一条线串行做完 |
| 强制编排 | 拆成多个子任务并行/分波执行 |

当 Sage 判断"拿不准"时，会弹出一个**执行模式选择框**，让你直接选。**点"取消"= 停止执行，计划保留待你稍后决定**，不会擅自开跑。

### 2.2 调研摘要卡片（ResearchSummaryCard）

复杂任务的计划卡片前会多一张调研摘要：

- 顶部：调研主题 + **充分度进度条**（越高表示资料越充分）；
- 中部：若干条发现，每条带相关性标签（高/中/低）和来源链接；
- 底部：`查看 N 个来源` 可展开；三个按钮：
  - **[基于调研生成 Plan]** —— 继续生成计划；
  - **[补充调研]** —— 再跑一轮，补足资料；
  - **[放弃]** —— 结束本次 `/plan`。

> 深度调研不可用（超时或未配置搜索服务）时会自动退回轻量侦察，你不会看到这张卡片，流程照常。

### 2.3 步骤确认对话框（StepConfirmDialog）

当计划中包含**破坏性/高影响步骤**时（例如删除文件、调用外部 API、写数据库、发布/强推），执行到该步骤前会暂停并弹出：

```
即将执行：删除旧迁移脚本
影响：将删除 3 个文件
类别：文件删除
上一步：已完成 xxx
接下来：yyy

[继续]  [跳过此步]  [终止全部]
```

| 按钮 | 结果 |
|------|------|
| 继续 | 执行该步骤，然后继续后续任务 |
| 跳过此步 | 该步骤标记为「已跳过」，直接进入下一任务 |
| 终止全部 | 取消整个计划，已完成的步骤结果保留 |

未在 **10 分钟**内做出选择，系统会自动按「终止全部」处理，避免任务无限挂起。

## 3. 什么时候会弹出步骤确认

**默认自动**：Sage 先判断任务复杂度，只有 **复杂（complex）任务** 才启用步骤确认；简单和中等任务不会被打断。

启用后，Sage 会对计划中每一步做规则匹配，只有命中规则的步骤才会暂停：

| 命中的操作 | 例子 |
|------------|------|
| 删除文件 | `rm -rf`、删除/清空目录 |
| 调用外部 API | HTTP 请求、webhook、curl |
| 数据库写操作 | INSERT / UPDATE / DELETE / 迁移 |
| 高风险操作 | force push、发布、提权 |

**手动覆盖**：通过接口或脚本发起聊天时，可以用请求参数强制开/关：

```json
{ "message": "...", "step_confirm": true }
```

- `true`：所有命中步骤都暂停（不论复杂度）
- `false`：本次完全不暂停
- 不传：自动模式（按复杂度判断）

> 规则引擎是关键词/正则匹配，可能偶有误判（例如计划里只是"文档提到删除文件"）。误判的代价是多点一次「继续」，不会造成破坏。

---

## 4. 任务状态怎么看

- 任务树和待办清单中，被跳过的步骤显示 **↷** 图标，标签为「已跳过」；
- 运行摘要行会追加 **`· 跳过 N`**，一眼看出本次有多少步被跳过。

## 5. 常见问题

**Q：为什么我的复杂任务没有出现调研摘要卡片？**
A：可能深度调研超时或未配置搜索服务，系统已自动退回轻量侦察。检查设置中的搜索/网页访问配置后重试。

**Q：执行模式我选了「编排」，但看起来还是串行？**
A：编排模式会按步骤依赖关系分波执行；若步骤之间存在强依赖，仍会串行，这是预期行为。

**Q：我点了「跳过此步」，之后能补做吗？**
A：可以。跳过的步骤不会自动补做，但你可以针对该步骤单独发起一次请求，或重新生成计划。

**Q：步骤确认对话框关不掉 / 提交失败怎么办？**
A：提交失败时对话框仍会关闭并提示错误；后端最多等待 10 分钟，超时按终止处理，不会卡死会话。

**Q：为什么我的简单任务从来没弹过步骤确认？**
A：这是预期行为。步骤确认默认按复杂度自动启用，只有复杂任务才会对命中规则的步骤暂停；简单/中等任务不会被打断。

**Q：我点了「跳过任务」但确认框还在？**
A：不需要等它自动关闭 —— 跳过后系统会立即按「跳过」收口，确认框随之消失。
