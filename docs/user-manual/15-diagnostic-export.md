# 出错时如何导出诊断包

> 当 Sage 的 LLM 调用出现异常(报错、乱码、行为不符预期)时,可以一键导出
> 最近 50 次调用的诊断信息为 zip 文件,发给支持人员离线分析。
>
> **适用场景**: 尤其在内网 Win7 环境(无法远程调试)下,这是最快的排障方式。

---

## 操作步骤

### 方式一:托盘菜单(推荐)

1. **找到系统托盘图标** — Sage 在屏幕右下角(时钟旁边)有图标
2. **右键点击图标** → 弹出菜单
3. **点击「导出诊断包…」**
4. 弹出确认对话框,询问是否包含原始 prompt 内容:
   - **默认「不含」**(推荐) — 只保留调用结构,不含对话内容
   - 若支持人员明确需要看 prompt 内容,再选「含」
5. 弹出文件保存对话框:
   - 默认保存到「下载」文件夹
   - 文件名: `sage-diagnostic-<版本号>-<时间>.zip`(可不改)
6. 点击「保存」

### 方式二:设置页

若找不到托盘图标,也可走设置:

1. 打开 Sage **设置**
2. 进入 **高级** 区域
3. 找到 **LLM 诊断导出** 卡片
4. 可选: 勾选「包含原始 prompt」/「包含本机主机名」
5. 点击「导出诊断包…」

---

## 导出完成后

- 文件管理器会**自动打开**,定位到刚保存的 zip
- 直接将 zip 拖到 IM 或邮件附件发给支持人员即可

---

## 导出前请知悉

**默认情况下,以下信息已被自动脱敏**:

- API key / Bearer token / JWT
- 密码、cookie
- 本地授权 token

但即使默认脱敏,发送前仍建议:

1. 打开 zip,阅读里面的 `README.txt`(给支持人员的人读说明)
2. 确认各文件含义
3. 如不确定,选「不含 prompt」最稳妥

---

## zip 里有什么

| 文件 | 内容 | 说明 |
|---|---|---|
| `manifest.json` | 导出元信息 | app 版本、schema 版本、trace 数量 |
| `system.json` | 系统信息 | 操作系统、Python / Electron 版本 |
| `config.yaml` | 配置快照 | 已自动脱敏 secrets |
| `trace.jsonl` | LLM 调用记录 | 每行一条,含上游 URL、状态码、耗时 |
| `README.txt` | 人读说明 | 给支持人员的指引 |

---

## Win7 注意事项

- 默认保存路径是「下载」文件夹,**不要**改到 `C:\` 根目录(权限问题)
- 若杀毒软件拦截写入,可尝试换到用户目录(如桌面)或暂时关闭杀软
- 文件名 `sage-diagnostic-...zip` 较中性,一般不触发杀软启发式拦截

---

## 常见问题

**Q: 导出后 zip 是空的?**
A: 说明最近还没有 LLM 调用记录。请先正常对话几次再导出。

**Q: 提示「无法连接 Sage 后端」?**
A: 后端服务未启动。请重启 Sage 桌面端后再试。

**Q: 导出的记录不全,只有最近几十条?**
A: 设计上最多保留 50 条。更早的记录会被自动丢弃。

**Q: 重启应用后记录还在吗?**
A: 不在。记录只存在内存中,重启即清空。如需保留,请在重启前导出。
