# §46 项目工作台

**日期**: 2026-11-10

## 1. 项目工作台是什么

- 左侧栏点「项目」进入项目列表页（`/projects`）。
- 点任一项目进入该项目的**工作台**（`/projects/:id`），工作台分五章：**概览 / 规则 / 资料 / 文件 / 设置**。
- 规则章的详细操作见 [§44 规则中心](./44-project-workbench-rules-center.md)。

## 2. 项目列表页

- 顶部标题「项目」，右上角「**新建项目**」。
- 工具栏一行：搜索框（按名称 / 路径 / 描述过滤）、类型筛选、**活跃 | 归档** 切换、排序（最近活动 / 名称 / 阶段）、「批量管理」。
- 一行一个项目：文件夹图标 + 项目名 + 类型徽章 + 阶段徽章 + 路径 + 会话数 + 最近活动。
  - 点整行进入工作台。
  - 鼠标移到行上时出现「开始会话 / 新建会话」按钮与「···」菜单（新建会话 / 归档 / 移除 / 在文件夹中显示 / 复制路径）。
  - 点项目名前的展开箭头可查看该项目下的会话。
- 「批量管理」后行首出现勾选框，工具栏变为「取消选择」+「归档所选（N）」；取消选择会清空已勾选项。

> 提示：以前这个页面会同时显示两份项目列表，上方那份还会在项目少时撑出大片空白。现在只剩一份，且在项目列表页时侧栏的「项目」分区会自动隐藏，不会再出现两个项目入口。

## 3. 概览章：现在什么状态、下一步做什么

从上到下四块：

1. **状态行**：项目类型、当前阶段、初始化进度（`已完成/总数`）。没初始化完时右侧有「继续初始化」。
2. **下一步**：最多三条待办，每条一句话说明 + 一个跳转按钮（如「补齐当前阶段交付物」「去处理」）。全部做完后显示「一切就绪，可以开始工作了。」
3. **里程碑进度**：总体进度条 + 完成 / 进行 / 阻塞数量 + 最近三条未完成里程碑。
4. **当前阶段**：当前阶段与「分解任务」入口。

「项目结构」（工程概览等低频信息）默认折叠，需要时点开。

页面右上角常驻唯一主按钮「**开始会话**」，点它直接开新会话。

## 4. 规则章

见 [§44 规则中心](./44-project-workbench-rules-center.md)。本章只做了显示层微调：

- 规则行内的来源路径只显示文件名（如 `SAGE.md`），鼠标悬停可看完整路径；
- 冲突数量旁的 `?` 说明「同一分类下内容不一致的规则」；
- 「查看最终生效规则」改为「查看规则生效顺序」。

规则内容、编辑、AI 修改、导入导出行为不变。

## 5. 资料章

两个二级页签：

### 5.1 项目资料

- **添加资料**：两种方式——从工作区文件入库（填相对路径，如 `docs/notes.md`），或直接粘贴文本。
- **已入库资料列表**：每条可启用/停用、预览内容、重建索引、删除；右上角可复制整份为 Markdown。

### 5.2 AI 记忆

原先的用户画像区，用于维护 AI 对本项目的长期记忆条目。

### 5.3 语义检索（折叠）

- 「语义检索」默认收起，展开后才是检索框与结果区。
- 内部的索引实现细节（如向量维度）不再直接显示在标题上。

> 变更说明：以前这一页混着「项目资料 + 语义检索 + Git 状态 + Wiki 生成」四块内容，且露出内部术语。现在资料页只保留资料相关操作；**Git 状态**移到了概览章的「项目结构」折叠区，**Wiki 生成**移到了设置章的「高级设置」。

## 6. 文件章

让 AI 以**只读**方式访问项目目录之外的文件或文件夹。

- **新增引用**：填「项目相对路径」（如 `data/cases`，指项目内的位置）、「目标绝对路径」（如 `/home/user/external/cases`，真正要读的地方）、「别名」、类型（文件夹 / 文件 / 符号链接）。必填项填齐后「新增引用」按钮才可点。
- **重新扫描**：识别项目中的符号链接并自动登记。
- 列表里每条显示类型、相对路径、目标路径和创建时间；删除前会二次确认，**只移除引用，不会删除源文件**。

界面文案已全部中文化。

## 7. 设置章

从上到下五个分区：

### 7.1 基本信息

项目描述与会话指令。这两项会作为**每次会话的背景**自动带给 AI。改完点「保存」，成功显示「已保存」。

### 7.2 项目总纲（SAGE.md）

项目最高优先级的背景说明文件。点「编辑项目总纲」展开编辑区（默认收起），里面可以生成草稿或直接改写。

### 7.3 AI 初始化

按需分析项目并生成建议。

- **不会自动运行**：进入这一页不会触发 AI 分析，只有点「分析项目」才会开始。
- 分析结果逐条展示，**需要你逐条勾选后才会应用**，不会自动改文件。
- **分析过程中可取消**：分析进行中右侧会显示「取消」按钮，点击后不再等待结果（后端仍在后台跑完，但你可以继续操作）。
- **超时提示**：如果分析超过 60 秒还没完成，会弹出超时提示，你可以点「重新分析」再试一次。
- **缓存加速**：同一项目、同一个 git 提交版本，1 小时内再次分析会直接返回上次结果（秒回，不消耗 LLM 额度）；项目有代码变更后会自动重新分析。

### 7.4 项目类型与版本控制

- **项目类型**：编码 / 科研 / 商务 / 个人，影响目录骨架与初始化建议。
- **阶段**：随类型变化（如编码类有「研发实现」等阶段）；改阶段后会多出「推进至下一阶段」按钮。
- **版本控制**：Git 仓库 / 内置快照。

### 7.5 高级设置（默认收起）

展开后包含：目录初始化（补齐项目目录与说明文件）、外部文件夹（只读，授权 AI 读项目外的路径）、项目 Wiki 生成、项目状态快照与 JSON 导出台账。

> 变更说明：以前打开设置页会自动跑一次 AI 分析（10–30 秒）并常驻一个大文本框；现在改为主动触发 + 对话框式编辑。

## 8. 常见问题

- **侧栏「项目」分区一直显示「暂无项目」？** 早期版本存在启动竞态（后端未就绪时首次请求失败且不重试），现已改为监听后端就绪事件自动补刷。若仍出现，重启桌面端。
- **概览页找不到原来的「+ 规则 / + 记忆 / + 资料」按钮？** 这些跨页动作已移到规则章和资料章执行，概览只保留「下一步」里与你当前阶段相关的动作。
- **资料页找不到 Git 状态 / Wiki 生成？** 分别在概览章「项目结构」折叠区、设置章「高级设置」里。
- **文件引用里「项目相对路径」填什么？** 填项目目录内的相对位置（该处通常是链接本身）；「目标绝对路径」填实际要读的文件或目录的完整路径。
