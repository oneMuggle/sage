# 56 · 智能体编排

> 当你让 Sage 处理一个较大的目标时，它会自动把目标拆成若干子任务，派出多个「子代理」分头去做，再把结果汇总给你。本页说明这套编排能力怎么用、过程怎么看、费用怎么算。

## 1. 能做什么

当你给出一个需要多步完成的目标时，Sage 的编排内核会先生成**计划**，再把计划里的任务派给子代理执行，最后由主控汇总。你可以看到的编排能力包括：

| 能力 | 你能做什么 |
|---|---|
| 拆分与派发 | 系统按任务类型派出不同能力的子代理（探索 / 规划 / 通用三类），无需你手动指定 |
| 后台执行 | 子代理可在后台继续跑，不阻塞你继续对话；完成后会以系统提示的形式回到对话里 |
| 同时运行多个 | 同一会话最多同时运行 4 个后台子代理；同轮多个子代理也可并行 |
| 暂停 / 恢复 | 可暂停或恢复单个子任务，也可一键暂停 / 恢复整个编排运行 |
| 继续追问 | 子任务完成后，可在它的「对话」记录里继续追问，新开一个跟进任务延续上下文 |
| 失败自动重规划 | 子任务重试后仍失败时，会提示主控调整计划后重新派发（每轮最多 3 次） |
| 完成通知 | 编排运行完成 / 失败 / 取消 / 等待审批时，桌面端弹系统通知，点击直达对应会话与任务 |
| 费用透明 | 任务树、任务详情、状态栏、会话运行历史显示估算金额 |

> 说明：子代理「类型」（探索 / 规划 / 通用）由编排内核根据任务本身自动选择，一般不需要你干预。

## 2. 怎么看编排过程

### 2.1 任务列表与运行目录

- **右栏进度面板**：当前会话正在运行的编排任务会显示为任务树，实时更新每个子任务的状态（排队、运行中、暂停、失败、完成）。
- **任务中心**：侧边栏「任务」入口汇总了各会话的子代理任务，并按状态分组（活跃 / 失败 / 已完成）。
- **运行目录**：运行列表按时间从新到旧排列，可切换查看「活跃 / 失败 / 已完成 / 全部」。这些视图都会自动刷新，无需手动点刷新。

### 2.2 任务详情的两个视图

点开任一子任务，详情里有两个切换视图，互为补充：

| 视图 | 看什么 |
|---|---|
| **过程** | 实时事件与时间线，适合看「正在发生什么」；工具调用会显示耗时（如 `· 1.2s`） |
| **对话** | 完整的消息级记录（目标、思考、正文、工具调用与结果全文），适合事后回看「它到底做了什么」 |

> 运行过程中，「对话」记录会自动增量刷新；任务结束后记录仍可回看。

### 2.3 继续追问与运行历史

- 对**已完成**的子任务，切到「对话」视图，底部有「继续追问这个子代理…」输入框；发送后会新开一个跟进任务，并沿用该子代理之前的上下文。
- 当前会话的历次编排运行，可在会话的运行历史面板中查看（保留最近若干条），每条显示请求摘要、状态与金额。

## 3. 用量与统计

| 指标 | 在哪里看 | 说明 |
|---|---|---|
| 估算金额 | 任务树、任务详情、状态栏、会话运行历史 | 以 `≈ $0.0123` 形式显示，来自内置价格表的**估算**，不是账单真值 |
| token 消耗 | 任务详情 / 任务树 | 显示本次任务或运行消耗的 token |
| 耗时 | 任务详情、过程时间线 | 单个工具调用会显示执行耗时；任务级显示总耗时 |

金额显示的几个约定：

- 金额一律带「约」的含义（`≈` 前缀），请勿当作精确账单；
- 非常小的金额显示为 `≈<$0.0001`，避免显示成 `$0.0000` 被误认为免费；
- **没有金额不代表免费**：当模型没有可用的定价信息时，界面不显示金额，而不是显示 0；
- 一次运行的金额等于其子代理已定价调用之和；主控自身与未定价模型不计入。

## 4. 常见问题

**Q：任务一直显示「等待审批」，怎么办？**
子代理要执行需要授权的操作时会停下来等你确认。处理权限弹窗（允许或拒绝）后任务会继续。桌面端也会弹出「等待审批」通知，点击可直达该任务。

**Q：我点了暂停，为什么任务还显示「排队中」？**
暂停会在子代理的下一个迭代边界生效，界面把暂停中的任务计入「未完成」，所以看起来像排队。暂停期间不消耗 token；点「恢复」后继续。

**Q：后台子代理跑了很久，结果去哪了？**
后台任务完成后，结果会以系统提示的形式注入到主对话的下一轮；你也可以在任务中心或任务详情里直接查看它的过程与结果。

**Q：运行里的某个任务失败了会怎样？**
失败任务会触发一次重新规划提示给主控，主控可能调整计划、重新派发或直接汇总已有结果。每轮运行最多触发 3 次这样的提示。

**Q：为什么有些任务没有显示金额？**
该任务调用的模型没有可用定价（或没有已定价的调用记录），此时界面不显示金额，这不表示它是免费的。

**Q：能回看很早以前每次子任务的详细过程吗？**
当前支持按「运行」查看近期历史与已结束运行的过程与对话；更久远、跨运行的任务级历史视图仍在规划中，具体展示方式待定。
