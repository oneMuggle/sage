# 侧边栏 Git 面板

> 左侧边栏的 Git 状态面板：显示当前上下文仓库的分支与变更文件，30 秒自动刷新。

## 这是什么

左侧边栏有一个 **Git** 折叠分区。展开后可以看到：

- 当前分支名（点击可复制）
- 变更文件列表，每个文件左侧有一个状态字母：`S` 已暂存 / `M` 已修改 / `?` 未跟踪 / `D` 已删除 / `R` 已重命名 / `!` 冲突
- 变更数量徽章
- 筛选按钮：全部 / 已暂存 / 已修改 / 未跟踪

点击任一文件会打开 **Diff 抽屉**，查看该文件相对 HEAD 的差异。新文件显示全部内容作为新增 diff，删除文件显示 HEAD 版本作为删除 diff。

面板顶部还有一个刷新按钮，可手动立即拉取最新状态。

## 面板在看哪个目录

这是最容易困惑的一点：**面板显示的是"当前上下文"的仓库，不是"最近打开的项目"。**

解析顺序：

| 优先级 | 目录来源 | 什么时候生效 |
| --- | --- | --- |
| 1 | 当前会话绑定的工作区 | 在聊天页选了某个工作区 / 项目时 |
| 2 | 最近打开的项目 | 没有会话上下文时，按最后打开时间取最新的一个 |
| 3 | 无 | 两者都没有 → 显示"未选择项目" |

这与右侧「变更」页签**同源**——两个面板检查的是同一个目录，所以不会再出现"左边有文件、右边说不是 Git 仓库"的情况。

## 显示"当前目录不是 Git 仓库"

当当前上下文的目录不是一个 git 仓库（或根本没选目录）时，面板会显示这个提示，并在下方用小号等宽字体列出**正在检查的目录路径**。

看到路径就能立刻判断问题出在哪：

- 路径是一个临时 / scratch 目录 → 说明当前会话绑定的是这个目录，切回你的项目即可；
- 路径不是你预期的项目 → 说明上下文还没切换或会话绑定有误；
- 路径正确但仍报非仓库 → 确认该目录确实有 `.git`（子模块、容器挂载目录等情况下可能没有）。

## 复制与导出

「…」菜单提供批量操作：

- **复制全部路径** —— 把当前筛选结果的路径逐行复制到剪贴板
- **复制 Markdown 清单** —— 生成形如 ``- [M] `src/app.ts` `` 的 Markdown 列表，方便贴进 issue 或提交说明

文件行 hover 时会出现「复制路径」按钮；分支名点击复制。

## 常见问题

**面板一直是空的 / 显示"工作区干净"**
说明当前目录确实没有变更。等一会儿（最多 30 秒）或点刷新按钮。

**面板和我终端里的 `git status` 结果对不上**
面板每 30 秒轮询一次，终端是实时的，两者可能短暂不一致。另外面板只显示当前上下文目录，终端可能在另一个目录下执行。

**看不到某个文件**
未跟踪（`?`）文件默认会显示，但被 `.gitignore` 忽略的文件不会出现在 git status 里，面板同样看不到。

**中文文件名显示成乱码或带引号**
面板使用 `git status -z` 输出，中文与含空格路径原样返回，不会出现转义问题。若你看到旧版本的表现，请确认应用已更新到本版本。
