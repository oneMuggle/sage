# 本地 OCR（图片文字识别）

> 适用版本：main（2026-10-31 起）
> 入口：设置 → 模型 → 本地 OCR；聊天输入区图片附件

## 1. 这个功能解决什么问题

当你使用的对话模型不支持「看图」时，Sage 可以在**本机**把图片/截图里的文字识别出来，作为文本发给模型继续对话。图片默认不上传。

典型场景：

- 粘贴报错截图、网页截图、表格截图；
- 扫描件/PDF 页面没有文本层；
- 只想提取图片文字，不需要模型描述画面。

## 2. 启用前检查

打开 **设置 → 模型 → 本地 OCR**：

- **状态**为「可用（rapidocr）」或「可用（tesseract）」即已就绪；
- 显示「不可用」时，说明本机没有安装 OCR 引擎（见第 5 节）；
- 点「测试识别」可确认引擎是否真的能工作。

> 当前安装包默认不包含 OCR 引擎与 ONNX 运行时。需要使用可选依赖安装（main / Win10+ 推荐 RapidOCR；Win7 推荐 Tesseract 4.1）。

## 3. 设置项

| 设置 | 说明 | 建议 |
|---|---|---|
| OCR 引擎 | 自动 / RapidOCR / Tesseract | 默认「自动」：优先 RapidOCR，缺失时回退 Tesseract |
| 识别语言 | 自动 / 中文 / 英文 | 中文截图选「自动」或「中文」 |
| 有视觉模型时也优先本地 OCR | 即使模型能看图，也先用 OCR 提字 | 纯文字截图建议开启；照片/图表建议关闭 |
| 测试识别 | 用内置图片验证引擎 | 首次启用时点一次 |

设置会自动保存，无需重启。

## 4. 在聊天中使用

1. 直接粘贴或拖入截图（没有视觉模型也可以上传）；
2. 输入区会出现「图片文字（本地 OCR）」卡片：
   - 可以**复制**识别结果；
   - 可以**直接编辑**文本（错字、断行可手动修正）；
   - 可以点刷新按钮**重新识别**；
3. 发送消息时，以卡片里**当前显示的文字**为准（编辑后的内容会随消息发送）；
4. 如果识别失败，会显示「识别失败：原因」；可以重试或改用视觉模型。

## 5. 安装 OCR 引擎

### 推荐：RapidOCR（main / Win10+）

在 Sage 使用的 Python 环境（`sage-backend`）中安装：

```bash
pip install "rapidocr>=3.10,<4" "onnxruntime==1.19.2"
```

RapidOCR 自带小型中英模型，安装后即可离线使用。

### 兼容：Tesseract

1. 安装 `pytesseract`：`pip install pytesseract`；
2. 安装系统 `tesseract`，并确保在 PATH 中；
3. 中文识别需安装 `chi_sim` 语言包。

如果 tesseract 不在 PATH（例如便携版/捆绑版），可设置环境变量
`SAGE_TESSERACT_PATH` 指向 `tesseract.exe` 的完整路径。

Win7 用户建议使用 Tesseract 4.1 兼容构建（Tesseract 5 官方只支持 Win10/11）。

安装后回到设置页点「测试识别」验证。

## 6. 隐私与数据

- OCR 默认在**本机**完成，图片不上传；
- 聊天图片本身不落盘（刷新后原图不可回看，这是现状）；
- 只有你在设置里配置了视觉模型时，图片才会发给该模型；
- 识别结果只随当前消息进入对话上下文。

## 7. 常见问题

**设置页一直显示不可用？**
检查引擎是否装在当前后端 Python 环境（不是系统 Python），以及 `tesseract` 是否在 PATH。点「测试识别」查看具体失败原因。

**识别出来是空的？**
图片可能没有清晰文字，或文字太小/太模糊。可以裁剪图片后重试，或改用视觉模型。

**识别很慢？**
首次使用需要加载模型（约 1–3 秒）；之后会快很多。大图会先缩放到 1280 长边。CPU 繁忙时可能更慢。

**Win7 能用吗？**
Tesseract 4.1 路径可用；RapidOCR 在 Win7 上属于实验路径，默认不承诺。
