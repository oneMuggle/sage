# 37 AI 文档工作台（文档库 · 规范书库 · AI 审校与修改）

> 「文档与验收」页的「文档工作台」里有哪些能力、怎么用。适用于每天要处理一批 Word / PDF 稿件的同学。

## 1. 文档库：找文件、筛选、排序

打开「文档与验收」→「文档工作台」，左侧就是当前项目的文档库。

| 你会用到的 | 位置 | 作用 |
|------------|------|------|
| 搜索框 | 文档列表上方 | 按文件名关键词过滤（不需要完整名字，片段即可） |
| 类型下拉 | 搜索框旁 | 只看 Word / Excel / PPT / PDF，或全部 |
| 排序下拉 | 搜索框旁 | 最近更新（默认）/ 最早更新 / 最新创建 / 最早创建 / 名称 A→Z / 名称 Z→A / 大小 从大到小 / 从小到大 |
| 「已归档」开关 | 列表工具栏 | 切换到已归档文档，可以把误归档的文件恢复 |

排序或筛选后立刻生效，列表会自动重新加载；关掉页面再回来，排序等条件不会保留。

## 2. 重复文档：识别与清理

当同一个文件被反复导入，文档库里会出现内容完全相同但各自独立的记录。

- 列表里的文档如果与其他文档内容相同，会显示「重复」徽标；
- 列表上方会出现横幅，写明「发现 N 组重复文档」，并提供「清理重复（保留最新）」按钮。

点「清理重复（保留最新）」后：

1. 每一组重复里保留**创建时间最新**的那一份；
2. 其余自动归档（不是删除，可以在「已归档」里找回）；
3. 若中途有一条归档失败，整批会停下并提示，不会悄悄跳过。

> 仅内容完全一致才算重复。文件名相同但内容不同，不会被当成重复。

## 3. 格式规范书库

很多稿件有硬性的格式要求（投稿规范、单位写作规范）。把这份说明文件存成「规范书」，审校时就有了依据。

### 3.1 导入一份规范书

1. 打开「文档工作台」里的「规范书库」面板；
2. 选择说明文件（Word / PDF / Markdown 都可以）→「提取规则」；
3. 系统会读出一组格式规则，逐条展示给你确认、修改；
4. 确认后保存，这份规范书就出现在列表里。

没配置 AI 模型也能用：提取会退回纯人工方式，你可以直接从已有规则包创建，或手工补规则。

### 3.2 设为默认 / 绑定到某篇文档

- 点规范书上的「设为默认」：本项目所有没单独绑定的文档都用它审校；
- 在某一篇文档的详情里「切换规范书」：只对这篇生效，优先级高于默认（换期刊投稿时非常有用）。

优先级从高到低：**文档单独指定 → 项目默认 → 无规范书**。规范书只在当前项目内可见，跨项目不会互相串。

## 4. AI 审校：找出问题

在文档详情右侧的「AI 助手」面板：

1. 顶部会显示「当前规范书：<名称>」，可随时切换；
2. 点「审校」（或勾选「合规检查」）；
3. 结果列表按严重程度分组，每条问题都带来源徽章：
   - **规范书 X**：来自你导入的硬性规则，通常可直接改；
   - **AI 补充**：模型给的语义建议，需要你自己判断。

每条问题显示：问题描述、建议、依据（规范书条款或 AI 的理由）、以及它出现在哪一段。你可以按来源过滤，只看「规范书」或只看「AI 补充」。

### 常见的提示

| 提示 | 含义 | 怎么办 |
|------|------|--------|
| 未配置模型 | 设置里没有可用的 LLM | 去 设置 → 模型配置填好端点/密钥；规范书规则审校仍然可用 |
| 该格式不支持 AI 审校 | 目前只对 Word 做语义审校 | 其它格式先用规范书规则或手工检查 |
| 文档没有可读内容 | 文件是空的或图片为主 | 检查文件是否损坏 |
| AI 响应无法解析 | 模型返回格式异常 | 重新审校一次；持续失败可换模型 |
| 部分段落超出分析范围 | 文档太长，只分析了前面的部分 | 拆分文档分别审校 |

## 5. 把问题应用成修订

1. 在结果列表里**勾选**要处理的问题（只有带「可自动修复」的问题能勾选，其他会灰掉）；
2. 列表底部出现「应用到文档（N 项）」按钮；
3. 点击后弹出确认框，写明将修改哪篇文档、是否覆盖原文件、会先自动备份；
4. 确认后执行。

执行后：

- 改动以 **Word 修订痕迹**写入（能清楚看到删了什么、加了什么），不会直接抹掉原文；
- 每条修改附带一条评论，注明是 AI 建议还是哪条规范书规则；
- 修改前的原文件已自动备份，路径会显示在结果里。

> 如果勾选的问题里没有任何一条可以自动定位到原文，会提示「所选问题没有可应用的修订」，文档不会被改动。

## 6. 出错后怎么恢复

**方式一：用自动备份还原**

应用修订后，结果里会给出备份路径，形如：

```
<该文档所在目录>/.snapshots/1762300000000-draft.docx
```

前缀数字是备份时间（毫秒时间戳）。把这个文件复制回去覆盖当前文档即可回到修改前状态。备份失败不会阻塞你的修改，但结果里不会出现备份路径——这种情况请谨慎操作。

**方式二：在 Word 里「拒绝所有修订」**

因为修改写成了修订痕迹，直接用 Word 打开 → 审阅 → 拒绝所有修订，也能回退。

## 7. 审校历史

文档详情里的「审校历史」会保留每次审校记录：

- 用的哪份规范书、哪个模型；
- 发现多少个问题、摘要；
- 耗时和 token 消耗（方便估算成本）；
- 时间（本地时区显示）。

历史只记录、不会自动回放；需要再次应用请重新审校并勾选。

## 8. AI 侧栏：选中即问

打开任意文档后，右侧会出现「AI 助手」侧栏。你可以选中文本后直接提问，或在侧栏里输入指令。

### 8.1 选中文本 → 浮出条

在文档里选中一段文字后，会出现 4 个按钮：

| 按钮 | 作用 |
|------|------|
| 改写润色 | 优化选中段落的表达，结果出现在侧栏卡片里 |
| 就这段提问 | 把选中文本预填到侧栏输入框，你可以接着追问 |
| 按指令修改 | 描述要怎么改（如「改成更正式的语气」），AI 会定位段落并给出 diff |
| 审校建议 | 对选中段落做审校，结果以卡片列表展示，可逐条应用 |

**只有 Word 文档支持「应用到文档」**。Excel / PPT / PDF 的结果只能复制，不能直接写回。

### 8.2 侧栏命令

在侧栏输入框里输入 `/` 开头的命令：

| 命令 | 作用 |
|------|------|
| `/summarize` | 生成当前文档摘要 |
| `/translate` | 翻译当前文档（需先设置目标语言） |
| `/audit` | 对当前文档做完整审校 |
| `/rules` | 提取当前文档的格式规则 |

输入普通文本会触发 AI 对话（上下文感知，会记住最近 20 条消息）。

### 8.3 按 Tab 切换快捷指令

侧栏顶部有 4 个 Tab，每个 Tab 显示一组快捷按钮：

- **文档**：审校全文 / 提取规则 / 生成摘要 / 翻译
- **生成**：从摘要扩展 / 优化结构 / 补充细节 / 检查一致性
- **规则**：提取规则 / 检查冲突 / 合并相似
- **LaTeX**：编译检查 / 引用格式化 / 公式校对

点击快捷按钮会自动填入输入框并执行。

### 8.4 编辑预览对话框的 AI 按钮

在「编辑预览」对话框里，表单标题下方有 4 个 AI 按钮：

| 按钮 | 作用 |
|------|------|
| 改写 | 优化当前编辑框里的文本 |
| 润色 | 让表达更流畅 |
| 扩写 | 扩展内容（增加细节） |
| 缩写 | 精简内容 |

点击后 AI 会读取当前编辑框内容，生成结果后自动回填。**对话框本身支持撤销**，所以不用担心改错。

## 9. 常见问题

**Q：点了排序没反应？**
检查是否选的是「最近更新」——这本来就是默认顺序。其它排序会立即改变列表。

**Q：清理重复后文件去哪了？**
进了「已归档」，打开「已归档」视图即可恢复。

**Q：规范书改了，之前审校的结果会变吗？**
不会。历史记录保留当时的依据；要按新规范重审，请重新点「审校」。

**Q：AI 建议一定要全部采纳吗？**
不需要。只有你勾选的问题才会被应用；AI 补充类的建议通常需要人工判断。

**Q：能给 Excel / PPT 也应用修订吗？**
目前「应用到文档」只支持 Word；其它格式的审校结果可以阅读，但需手工修改。

**Q：整个流程会不会偷偷改我的文件？**
不会。所有写入都发生在你点击确认之后，且默认先做备份；不确认就不会写盘。
