# 52 — PDF 页码与图表引用

> 2026-11-15 新增：上传 PDF 后，AI 回答可以标注页码，并在提到图表时内联展示原图

## 能做什么

把 PDF 拖进输入框（或点附件按钮选择）发送后：

- AI 回答 PDF 里的内容时会标注**页码**，例如「（第 12 页）」；
- PDF 里的**插图会被自动抽取**，AI 提到相关图表时会在回复里直接显示原图，
  图片下方标注「第 12 页 · 图 3」这样的图注；
- 点击图片可放大查看；
- 附件卡片悬停可看到该 PDF 的**页数与抽取到的图片数**。

## 怎么用

1. 把 PDF 拖进会话页（任意位置）或点输入框的附件按钮选择；
2. 正常提问，例如「这篇论文的实验结果如何」「第 3 张图说明了什么」；
3. AI 回答里出现页码或内联图片即表示引用生效；
4. 点击图中的图片可放大；附件卡片上的状态仍会显示「已读取 / 已跳过」原因。

## 适用与限制

- 支持带文本层的 PDF；扫描版 PDF 需要开启本地 OCR（见用户手册 §29 / §50）
  才能抽取文字，纯图片页会尽量以图片清单形式提供给 AI；
- 目前抽取的是 PDF 内**嵌入的位图**（照片、截图、导出图片）。由矢量图形绘制的
  图表（部分 Word/LaTeX 导出）可能不会出现在图清单里，AI 仍可凭文字描述回答；
- 每份 PDF 最多抽取 40 张插图；小图标、整页扫描背景与重复图片会被过滤；
- 附件卡片与引用里的页码可点击，打开 PDF 原文并定位到对应页（Esc 或点遮罩关闭）。

## 常见问题

**Q：回复里没有出现页码？**
确认上传的是 PDF 而不是 Word/Excel；Word/Excel 目前按整篇文本注入，不提页码。

**Q：AI 提到了图，但没有显示图片？**
可能是矢量图未被抽取（见上方限制），或该页没有图注。可以直接问「第 N 页有哪些图」，
或把该页截图发给 AI。

**Q：图片显示不出来？**
请在 Sage 桌面端查看；浏览器降级模式下媒体图片需要后端可访问。若图片一直加载失败，
可打开附件卡片确认文件读取状态。
