# 51 — 项目健康与 AI 规程助手

> 2026-11-14 新增：项目健康看板、主动告警、AI 对话式规程定制

## 项目健康看板

### 查看方式

打开「项目」页面，在顶部搜索栏下方会自动显示 **项目健康看板**。

看板最上方是三张**指标卡**，从左到右依次是 **风险 / 关注 / 正常**，每张卡用对应颜色显示当前各有多少个项目处于该状态：

- 🔴 **风险**：项目有里程碑逾期达到 **7 天及以上**
- 🟡 **关注**：项目有里程碑逾期但不足 7 天，或有里程碑处于**阻塞**状态
- 🟢 **正常**：项目没有逾期、也没有阻塞，里程碑都在正常推进

> 提示：三张卡的数字统计的是全部活跃项目，切换下面的筛选按钮不会改变卡上的数字。打开页面时会自动检查一次，之后可随时点 **重新检查** 重新扫描并刷新。

### 按严重度分组的列表

指标卡下方的项目列表会**按严重度从重到轻分组**：先列「风险」项目，再列「关注」项目，最后列「正常」项目。当处在「全部」视图且同时存在多个等级时，每组上方会有一个小标题（组名 + 该组项目数）；若某一组为空则不显示该组。

每个项目一行，从左到右能看到：

- 一个对应颜色的圆点（红/黄/绿）
- 项目名称，以及它当前所处的阶段
- 已完成的里程碑数与总数（例如 `2/5 里程碑`）
- 右侧的**逾期徽标**或状态文字

### 逾期徽标

只要项目有逾期里程碑，该行右侧就会显示一个**红色圆角徽标**，文案为「**逾期 N 项**」，N 是逾期的里程碑条数。徽标统一用红色，方便一眼定位所有有问题的时间节点。没有逾期时，那里改为显示状态文字「存在风险 / 需要关注 / 一切正常」。

### 筛选与刷新

- 顶部的 **全部 / 风险 / 关注 / 正常** 按钮可以只看某一严重度的项目
- 点击 **重新检查** 会立即重新扫描所有活跃项目并更新数字与列表
- 列表加载时会先显示几行灰色占位条；没有活跃项目、或筛选后没有匹配的项目时，会给出相应提示

### 该怎么做

- 看到「风险」项目，说明有里程碑已经拖了很久：点进该项目，在治理页确认是哪几个里程碑逾期时间最长，优先处理。
- 看到「关注」项目，说明有临近的逾期或存在阻塞：留意即将到期的工作，或去解除阻塞项。
- 三张卡的数字可以帮助你判断整体盘子：风险卡数字越高，越应先集中清理逾期项目。

### 单项目健康卡

进入任一项目的「治理」页 → 「项目概览」分区，会显示该项目的健康卡片：

- 卡片根据严重度显示对应颜色（风险红 / 关注黄 / 正常绿）与对应的状态图标
- 显示里程碑进度条及完成百分比（如 `3/5 · 60%`）
- 非正常状态时，最多列出前 3 条逾期里程碑及各自的逾期天数，超出部分显示「…还有 N 项」
- 若有阻塞但没有逾期，会提示「有 N 个里程碑处于阻塞状态」
- 一切正常时显示「所有里程碑进度正常」

## 主动告警

当检测到项目存在逾期或风险时，桌面端会弹出通知：

- **通知标题**：「项目风险提醒」
- **通知内容**：包含逾期天数与项目名称
- **节流策略**：同一项目、同一严重度每 24 小时只推送一次，避免打扰

## AI 规程助手

### 启用

在项目工作台 → 「规程」面板 → 点击 **AI 定制**。

### 对话流程

1. **启动**：点击「开始对话」，AI 会根据项目目录与内置模板生成规程草案
2. **多轮对话**：在输入框中描述需求，例如：
   - 「加一个中期检查阶段」
   - 「把实施阶段拆成数据采集和数据分析两个阶段」
   - 「结题阶段需要增加经费决算产物」
3. **回退**：如果调整不满意，点击「撤销上一步」回到上一版规程
4. **确认绑定**：规程满意后，点击「确认绑定」生效

> 提示：对话最多支持 10 轮。超过轮次会强制要求确认当前版本。

### 未配置 LLM 时

若后端未配置 LLM 端点，AI 助手会降级为基于规则的草案生成：

- 输入「中期检查」→ 自动在规程中插入中期检查阶段
- 输入「延期」→ 调整后续阶段的时间节点
- 输入「结题」→ 追加结题阶段

降级草案会弹出提示：「（未配置 LLM，已降级为规则草案）」。

### 从项目目录推断

若希望 AI 根据已有文件自动推断阶段划分：

1. 点击 **从目录推断** 按钮
2. 助手会扫描项目目录，识别类似 `01_开题`、`02_实施` 的编号目录
3. 显示推断结果（含置信度与来源）
4. **需要手动点击「绑定推断结果」** 才会生效——推断结果不会自动覆盖已有规程

### 从 Git 历史推断

同样通过「从目录推断」按钮，助手会同时分析最近的 git 提交记录：

- 匹配「开题报告」「初稿」「实验数据」「结题」等关键词
- 按提交时间分桶，推断项目经历的阶段
- 合并目录与 git 两种来源的结果

## 常见问题

**问：定时健康检查什么时候运行？**
答：每天上午 09:00 自动扫描所有活跃项目，生成健康报告并触发桌面通知。

**问：AI 规程助手会覆盖我已绑定的规程吗？**
答：不会。AI 助手生成的是草案，必须手动点击「确认绑定」才会生效。

**问：为什么 AI 助手提示「降级为规则草案」？**
答：后端未配置 LLM 端点（例如未安装 OpenAI / 未设置 API key）。此时使用规则引擎生成基础草案，不影响功能使用。

**问：定时检查会影响性能吗？**
答：不会。定时任务在 Electron 启动后注册，由 `SchedulerService` 调度，仅在每天 09:00 触发一次。扫描过程限制最多 100 个项目，超时即中止。
