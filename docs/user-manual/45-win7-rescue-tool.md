# 45. Sage 修复工具（Win7 内网）

> 当 Sage 前端闪退、启动失败，或需要在没有前端的情况下配置模型端点时使用。
> 配套 [11 sage doctor CLI](./11-sage-doctor.md)（安装环境体检）与 [06 诊断与日志](./06-diagnostics.md)。

---

## 45.1 什么时候用

- 双击 Sage 后窗口闪退 / 白屏 / 一直停在启动屏；
- 提示「后端服务未响应」或「Sage 启动失败」；
- 需要在内网配置 LLM 端点（服务器地址 / API Key / 模型名），但没有可用的前端界面；
- 需要生成诊断包发给 IT/支持人员；
- 怀疑是单位管控软件（360 天擎、北信源、深信服等）拦截了 Sage。

## 45.2 入口

| 入口 | 位置 |
|---|---|
| 开始菜单 | 「Sage 修复工具」 |
| 安装目录 | `SageDoctor.cmd`（双击） |
| 托盘菜单 | 右键 Sage 托盘图标 → 「运行修复工具…」 |
| 应用菜单 | 帮助 → 「运行修复工具」 |
| 启动失败对话框 | 点击「运行修复工具」 |
| 崩溃恢复对话框 | 前端崩溃时主进程弹出，点击「运行修复工具」 |

> 修复工具不依赖 Electron/Chromium，使用安装包内置的 Python 运行；即使前端完全打不开也能用。

## 45.3 主菜单

```text
[1] 一键体检
[2] 配置模型端点
[3] 修复启动问题
[4] 生成诊断包（发给 IT/支持）
[5] 生成管控软件放行清单
[6] 处置遗留管控软件
[7] 查看崩溃记录
[q] 退出
```

### 46.3.1 一键体检

运行 25 项环境检查（安装完整性 / DB 完整性 / 端点连通性 / 崩溃历史 / 管控软件识别 / 端口归属 / 数据目录等），输出 CRITICAL / WARN / INFO 三级结果与修复建议。

### 46.3.2 配置模型端点

1. 选择「列出端点」查看现有配置（API Key 已脱敏）；
2. 「新增端点」输入 Base URL（如 `http://10.0.0.5:8000/v1`）、API Key、模型 ID；
3. 「测试连接」验证网络与认证（分类显示 DNS / 连接拒绝 / 超时 / 401 / 404）；
4. 「设为当前聊天模型」绑定 `chatModel`；
5. 「导入配置包」可由管理员用 U 盘下发（导入后请删除含明文 key 的文件）。

> 修改端点时请先退出 Sage（避免与后端并发写配置）。写入前会自动备份数据库。

### 46.3.3 修复启动问题

- 清理 Chromium 缓存（不影响会话/登录数据）；
- 重置窗口位置（窗口跑到屏幕外时）；
- 截断超大日志（先备份原文件）；
- 清理 8765 端口孤儿进程；
- 备份并重置端点配置（会丢失全部端点，需确认）；
- 数据库完整性检查（`PRAGMA quick_check`）。

### 46.3.4 生成诊断包

把最近的日志、崩溃记录、启动时间线、doctor 报告、脱敏配置摘要打包为 zip（`%APPDATA%\Sage\diagnostics\sage-support-*.zip`），手动发给支持人员。默认脱敏 API Key、隐藏主机名，不包含聊天内容。

### 46.3.5 生成放行清单

生成 `sage-allowlist-*.md/.json`，包含 Sage 可执行文件路径、SHA-256、进程链、目录、本机回环端口 8765。交给 IT 管理员评估放行；工具本身不修改任何安全软件配置。

### 46.3.6 处置遗留管控软件

> ⚠️ 该功能用于单位内网中**已停止维护、IT 无法放行**的遗留管控软件。处置可能违反单位 IT 管理规定，是否使用请与所在单位确认。工具只提供能力，不静默执行。

- 自动识别已知服务/进程/注入模块；
- 支持：临时结束进程、停止服务、禁用服务（需管理员，记录原启动类型）、恢复到备份状态；
- 每个动作前自动备份服务状态到 `%APPDATA%\Sage\backups\security\`；
- 处置后可运行 `security restore`（或菜单 [5] 恢复服务）回滚。

### 46.3.7 查看崩溃记录

显示 `%APPDATA%\Sage\diagnostics\crash-journal.jsonl` 最近 50 条结构化崩溃事件（原因、退出码、窗口年龄、兼容档位）。

## 45.4 安全模式（兼容档位）

连续异常退出时，Sage 下次启动会自动升一档兼容模式：

| 档位 | 变化 |
|---|---|
| L0 | 正常 |
| L1 | 关闭 GPU 合成、桌宠、HTML 预览 |
| L2 | 进一步减少子窗口与进程隔离 |
| L3 | 实验性单进程模式 |

手动设置：`SageDoctor.cmd safe-mode set 1`，恢复：`SageDoctor.cmd safe-mode off`。

前端崩溃时主进程会弹原生对话框，可直接选择「安全模式重启」而无需打开终端。

## 45.5 隐私与安全

- 诊断包默认脱敏 API Key/token，隐藏主机名，不包含 LLM prompt/trace；
- 不自动上传任何数据（仅本地生成 zip，由你决定发送对象）；
- 修复工具以当前用户权限运行；禁用服务等动作需要管理员权限（UAC 提权）；
- 所有处置动作写入 `rescue-actions.jsonl` 审计，可回滚。

## 45.6 常见问题

| 现象 | 处理 |
|---|---|
| 修复工具窗口一闪而过 | 在 cmd 中运行 `SageDoctor.cmd` 查看报错；检查安装目录 `resources\python\python.exe` 是否存在 |
| 提示「未找到 Sage 内置 Python」 | 安装包不完整，重新安装 Sage |
| 配置端点后前端仍用旧 key | 启动 Sage 一次让前端同步；旧版本 localStorage 缓存由 `apiKeyUpdatedAt` 机制失效 |
| 管控软件检测不到 | 特征表只覆盖常见产品；可在 [6] 中手动输入服务名/进程名 |
| 禁用服务后 Sage 仍闪退 | 可能有看门狗/驱动；用 [6] 查看绕过建议，或联系支持生成诊断包 |
