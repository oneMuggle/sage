# 文献研究

文献研究让 Sage 帮你完成一次可追溯的文献调研与综述写作：从指定学术站点检索文献，
建立本次研究的文献池，抽取证据，生成大纲并分节写作，最后做引用检查、事实核验与
导出。所有中间结果都保存在工作区的运行目录里，你可以随时暂停、检查或让 Sage 重跑
某一步。

适合：写文献综述、做课题调研、整理某个方向的核心论文与证据。
不适合：替代正式同行评审，或绕过数据库权限获取文献。

## 1. 使用前提

- 在 Sage 桌面端中打开一个工作区。运行目录会放在
  `<工作区>/.sage/literature_runs/<运行编号>/`。
- 准备可用的检索站点账号。默认内置「学术资源站」（xueshu789）；
  也可以在 `~/.sage/literature_sites/` 放置自定义站点配置。
- 首次使用某站点需要登录时，Sage 会打开可见浏览器窗口，由你自己完成登录。
  遇到验证码或滑块时，同样由你手动完成，Sage 不会代填密码、不会导出 cookie，
  也不会绕过付费墙。
- 仅使用本人账号或机构已授权的资源。第三方站点默认不启用，需要你明确同意。

## 2. 发起一次文献研究

在对话中直接说明需求，例如：

> 帮我调研「大语言模型在医疗影像诊断中的应用」，整理近五年的文献并写一篇综述。

Sage 会进入文献研究工作流，并先与你确认范围：

1. 研究问题与核心概念；
2. 时间范围与语言范围；
3. 纳入 / 排除标准（例如只要期刊论文、排除预印本）；
4. 目标篇幅与结构偏好；
5. 使用哪个检索站点。

建议在开始前把这几项说清楚，后续筛选和大纲都会以此为准。

## 3. 操作流程

### 3.1 选择站点并登录

Sage 会先说明将使用哪个站点、是否需要登录。若需要登录，浏览器窗口会打开，
你完成登录后告诉 Sage 继续即可。登录态只保存在本地，不会上传。

### 3.2 检索文献

Sage 会在站点中执行检索，读取结果页并整理成结构化文献条目。你可以看到检索词、
结果数量与本次新增的文献。检索可能需要一点时间；如果站点响应慢或要求验证，
Sage 会提示你处理。

### 3.3 筛选与建立文献池

Sage 按你确认的纳入 / 排除标准筛选，并把入选文献写入本次运行的文献池。
文献池是后续所有引用的唯一来源，未进入文献池的条目不会被引用。

### 3.4 抽取证据

对入选文献，Sage 会抽取任务、方法、数据、指标、主要发现与局限等证据，
并尽量记录页码、段落或图号。证据越完整，后面的核验越可靠。

### 3.5 确认大纲

Sage 会基于文献与证据生成综述大纲，列出各章节标题、要点与拟引用文献。
**请在这一步认真确认或修改大纲**，确认后再进入写作，可以显著减少返工。

### 3.6 分节写作与合并

Sage 按大纲逐节写作并合并为完整草稿。正文引用使用文献池中的条目，
不会编造作者、年份或 DOI。你可以要求调整某一节的详略、语气或结构。

### 3.7 引用检查

写作完成后，Sage 会做一次确定性检查，确认：

- 每个引用都能在文献池中找到；
- 大纲中的章节都已出现在正文；
- 证据指向的文献真实存在；
- 草稿非空。

检查不通过时，Sage 会指出具体问题（例如某条引用不存在、某章缺失），
修复后才能导出。

### 3.8 事实核验

核验分几层进行：

- **引用存在性**：句子引用的文献是否在文献池中；
- **证据支持**：被引文献是否至少有一条证据记录；
- **外部元数据**：对带 DOI 或 arXiv 编号的文献，向 Crossref、OpenAlex、
  Semantic Scholar 查询，至少两家在标题、年份、作者上匹配才算通过；
- **语义支持**：由 Sage 逐条对照证据，判断证据是否真的支持该句。

核验结果会写入运行目录，并在报告中按状态分组展示。

### 3.9 生成核验报告与写作自检

Sage 会生成一份核验报告，汇总每条论断的状态、元数据核验结果与证据账本统计。
另外会生成一份四维写作自检（方法、覆盖、逻辑、写作，各 5 分，总分 20），
指出检索次数、证据覆盖率、文献量、被引比例、大纲覆盖、正文体量与引用密度等方面的
问题。

这份自检是**模拟评审和写作自检，不是同行评审**，分数只反映流程完整度，
不能作为投稿依据。

### 3.10 导出与转 Word

你可以选择引用样式：

- **GB/T 7714**（默认，适合中文期刊与学位论文）；
- **IEEE**（适合英文工程类论文）。

导出会得到：

- `final.md`：正文 + 参考文献；
- `references.json`：结构化参考文献；
- `papers.bib`：BibTeX，可导入文献管理工具。

如需 Word 文档，可以让 Sage 把参考文献与分章内容交给论文写作能力生成 docx，
并做一次排版自检。文献研究本身不负责 docx 排版。

## 4. 结果文件在哪里

每次研究对应一个运行目录：

```
<工作区>/.sage/literature_runs/<运行编号>/
  meta.json                  本次研究的主题、站点与时间
  papers.jsonl               文献池
  evidence.jsonl             证据表
  claims.jsonl               逐条论断与核验状态
  outline.json               大纲
  draft.md                   完整草稿
  verification.json          引用检查结果
  metadata_verification.json 外部元数据核验结果
  ledger.json                证据账本
  export/
    final.md                 最终稿
    references.json          结构化参考文献
    papers.bib               BibTeX
    verification_report.md   核验报告（另有 .json）
    rubric_review.md        写作自检（另有 .json）
```

这些文件都可以直接打开查看，也可以作为产物在 Sage 中预览。中断后重新进入同一
运行目录，可以继续未完成的步骤。

## 5. 如何解读核验结果

### 5.1 论断状态

| 状态 | 含义 | 建议 |
|---|---|---|
| `supported` | 引用存在，且已通过当前层级的支持检查 | 可保留 |
| `flagged` | 引用存在，但被引文献没有证据记录，或语义支持存疑 | 补充证据或人工复核 |
| `unsupported` | 该句没有任何引用 | 补引用或删除 |
| `unresolved` | 引用的文献不在文献池 | 补文献或改正引用 |
| `unclear` | 语义核验无法判断 | 人工确认 |
| `unverified` | 尚未核验 | 继续执行核验 |

`unsupported` 与 `unresolved` 属于必须处理的问题；`flagged` 需要你重点复核。

### 5.2 元数据核验状态

| 状态 | 含义 |
|---|---|
| `verified` | 至少两家外部数据源在标题、年份、作者上匹配 |
| `partial` | 只有一家匹配 |
| `unverified` | 没有任何外部数据源匹配 |
| `skipped` | 文献没有 DOI / arXiv 编号，无法外部核验 |

`unverified` 建议核对文献信息或补充 DOI；`skipped` 不代表文献有问题，只是缺少
可自动核验的标识。

### 5.3 写作自检

- 优：16–20 分；良：12–15 分；及格：8–11 分；待改进：低于 8 分。
- 每个维度都会列出具体问题，例如「检索次数偏少」「部分被引文献缺少证据」
  「正文偏短」「引用密度偏低」。
- 可按问题清单逐项改进，但不必追求满分。

## 6. 常见问题与限制

**为什么某条引用被标成 `flagged`？**
通常是引用的文献还没有抽取证据，或语义核验认为证据不足以支持该句。
补一条证据，或改写句子，再重新核验即可。

**为什么找不到某篇文献？**
先确认站点选择与登录状态，再检查纳入 / 排除条件是否过严。也可以换一个站点，
或在自定义站点配置中加入新的来源。

**内置学术资源站有哪些已知问题？**
实测只有 `/dbItem/3` 入口稳定可用；`/dbItem/1` 会显示代理错误，`/dbItem/2`
会触发知网滑块验证，需要你手动完成。PDF 下载完成后，新标签页可能显示
「页面不存在」，但文件通常已经保存，请以浏览器下载目录为准。

**下载的文献为什么是 PDF 而不是 CAJ？**
系统默认拒绝 CAJ 格式，并校验文件头是否为 `%PDF-`、文件名是否与题名匹配，
以避免下载到错误文件。

**能使用 APA 等其他引用样式吗？**
目前只支持 GB/T 7714 与 IEEE；APA/CSL 尚未实现。

**核验通过是否代表论文一定正确？**
不代表。核验只能确认引用存在、元数据一致、证据与句子相关，不能保证研究结论正确，
也不能替代同行评审。最终判断仍由你负责。

**可以直接得到投稿用的 Word 文档吗？**
可以在导出后交给论文写作能力生成 docx，但仍需你检查格式、内容和引用是否符合目标
期刊要求。

## 7. 合规提醒

- 仅使用本人账号或机构已授权的资源；
- 不绕过付费墙、不批量抓取受限制内容；
- 验证码与滑块由你本人完成，Sage 不会破解；
- 引用必须来自本次文献池，Sage 不会编造文献、作者、年份或 DOI。
