# 项目规程（Playbook）

> 适用版本：Sage 0.6.0-alpha.72+
> 入口：项目主页 → 概览 / 设置

项目规程是一套"这个项目应该怎么管"的规则：分几个阶段、每个阶段需要哪些目录和文档、什么条件算完成。Sage 会按规程检查当前资料是否齐全，并在你确认后推进阶段。

## 1. 绑定规程

1. 打开项目主页（项目列表双击或右键「项目设置与 AI 初始化…」）。
2. 在「概览」中找到「项目规程」卡片。
3. 下拉选择规程（内置：科研课题、代码工程、公文档案、个人知识库），点击「绑定此规程」。
4. 绑定后卡片显示阶段条与整体完成度；规程中的规则会自动写入项目规则（幂等），AI 会读取并遵循。

科研课题内置阶段：

| 阶段 | 必需要素（示例） |
|---|---|
| 开题 | 开题报告 |
| 实施 | 原始数据、实验记录 |
| 结题 | 成果材料、结题报告、经费决算表 |

可选要素缺失不会扣分；必需要素缺失会显示为「待补」。

### 让 AI 定制规程

如果内置阶段不符合你的学校/单位要求：

1. 在规程卡片下方填写补充要求（如"学校要求开题、中期检查、结题三个阶段，必须有开题报告和结题报告"）；
2. 点击「AI 定制规程」；
3. 查看生成的阶段与交付物草案；
4. 点击「绑定生成的规程」后生效。

未配置 LLM 时，Sage 会基于内置规程与你的文字生成确定性草案（界面会提示"已降级"）。

## 2. 检查完整性

- 点击「检查完整性」重新扫描项目目录；
- 点击「AI 检查内容」可让 AI 判断文档是否包含要求的内容（如研究问题、随机种子）；未配置 LLM 时保留关键词检查结果；
- 每个待补项显示文件匹配规则与实际扫描到的文件（前 5 个）；
- 若文件存在但超过规定时效，会标记为「过期」；
- 不适用的事项可点「豁免」；手动退出条件可点「标记完成」。

## 3. 补材料

- 待补项右侧有动作按钮：
  - 「创建目录」：按规程创建缺失目录；
  - 「生成骨架」：创建带章节标题的 Markdown 文档（不会覆盖已有文件）；
- 所有写操作前自动创建项目检查点，可在项目设置中还原；
- 重复点击是安全的：已存在的目录/文件会跳过；
- 待补项旁的「转待办」会把缺失项加入 Todo（自动关联当前项目）。

### 归类建议

如果文件内容已存在但放错了目录（例如开题报告放在项目根目录），卡片会显示「归类建议」：

- 每条建议显示 `原路径 → 目标路径`；
- 点击「移动」逐项确认；目标文件已存在时拒绝覆盖；
- 不会自动批量移动。

### 编辑规程

- 点击「编辑规程」：默认表单模式可改名称、描述、阶段与产物（匹配 glob / 目标目录 / 是否必需）；
- 切换到「JSON」可编辑规则、里程碑、内容检查等高级字段；
- 点击「保存为新版本」生成新快照，旧版本仍保留，可回退。

## 4. 阶段推进

- 当 Sage 检测到你可能已进入下一阶段时，会显示「检测到可能已进入『实施』阶段」；
- 点击「确认推进」才会真正修改项目阶段；点击「保持当前」只隐藏提示；
- 阶段变更记录在 `playbook_state.stage_history`，可回溯。

### 解绑与清理

- 「版本历史」：查看每次绑定/编辑生成的快照（只读）。
- 「清理规程规则」：删除由规程写入的项目规则，不影响手工添加的规则。
- 「解绑规程」：清空当前规程状态，历史快照保留；解绑后不会再按规程检查。

## 5. 导出与分享

- 「导出」：下载 `.sageplaybook.json`，包含规程定义与空目录骨架，**不包含你的项目文件内容**；
- 「导出手册」：下载 Markdown 版规程手册，便于打印或放进 Wiki；
- 「导出 AGENTS」：下载兼容 `AGENTS.md` / `CLAUDE.md` 的片段，让其他 AI 工具读到同一套目录与阶段约定；
- 「写入 Wiki」：把规程手册写入 `wiki/guides/playbook-handbook.md`；若该页面已存在且不是 Sage 生成，会拒绝覆盖；
- 把文件发给同事后，对方可在项目主页选择「导入」：
  1. 选择文件；
  2. Sage 校验并显示结构差异；
  3. 选择「另存为新规程 / 合并到当前规程 / 替换当前规程」；
  4. 点击「导入并绑定」。

## 6. 常见问题

**Q：为什么我的开题报告显示缺失？**
A：检查文件名是否包含「开题报告」且位于项目目录内；支持 `.doc/.docx/.pdf/.md`。可在设置中查看并编辑规程的匹配规则（P2）。

**Q：规程会不会自动移动我的文件？**
A：不会。当前版本只建议、不移动；创建目录与骨架需要你逐项点击。

**Q：切换规程会丢失已有数据吗？**
A：不会。旧规程快照保留在版本历史中；约束、里程碑、项目文件不受影响。

**Q：导入别人的规程安全吗？**
A：导入前会校验格式与路径，拒绝 `../` 和绝对路径；不会在项目外创建文件，也不会包含对方的项目内容。
