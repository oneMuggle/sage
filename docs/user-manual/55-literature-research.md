# 55 · 文献研究

> 在 Sage 里用对话完成“定题 → 检索 → 筛选 → 精读 → 分节写作 → 核验 → 导出”的文献综述流程。所有结果都落在你的工作区里，可随时打开、复用和带走。

## 1. 能做什么

用一句话告诉 Sage 你想研究什么，它就会带你走完一条完整的文献综述流水线：

- **按站点检索**：使用你自己配置的站点（在 `~/.sage/literature_sites/` 放置站点配置，示例模板见 `docs/templates/literature-sites/`）。检索词、数量、是否下载 PDF 都按你的要求执行。
- **整理文献池**：把检索结果整理成统一的文献记录，自动去重，并记录每条来自哪个站点、哪次检索。
- **做证据笔记**：为每篇重点文献记下关键结论、方法、数据位置（页码等），方便后面逐条引用。
- **分节写作**：先生成大纲给你确认，再按章节写作；正文里的每个论断都必须挂到具体文献上。
- **引用可核对**：正文只用 `[cite:文献标识]` 标记来源，编号和参考文献列表由程序自动生成，LLM 不能自己编造编号。
- **多重核验**：会自动检查引用是否真实存在、文献元数据是否对得上、结论是否有证据支撑，并给出逐句判定。
- **质量自检**：生成一份“方法 / 覆盖 / 逻辑 / 写作”四维评分报告，告诉你哪些地方还能补强。
- **一键导出**：输出完整综述 Markdown、参考文献（GB/T 7714 或 IEEE）与 BibTeX，也可以把稿子和文献交给论文写作功能生成 Word 文档。

> 说明：文献研究目前**没有单独的页面**，全程通过对话触发；结果以文件形式保存在工作区，可在 Sage 的产物预览中查看。

## 2. 怎么用

### 第 1 步：发起需求，选站点

直接说需求即可，例如：“帮我写一篇关于大模型检索增强生成的综述，先找 15 篇文献。”

Sage 会先和你确认：

- **用哪个站点**：使用你已配置的站点（示例模板见 `docs/templates/literature-sites/`）。第三方站点默认关闭，需要你明确同意才会使用。
- **检索范围**：关键词、时间范围、只要期刊还是也包含会议、每批找多少篇。
- **是否需要全文**：只要题录信息，还是要把 PDF 下载到本地。

### 第 2 步：登录站点（需要时）

需要登录的站点会在**可见的浏览器窗口**里打开登录页，由你自己完成登录（输入账号、密码、验证码）。

- Sage 不会替你填写密码，也不会导出或保存你的登录凭据。
- 遇到滑块验证、验证码，Sage 会停下来提示你手动完成，不会尝试绕过。
- 请只使用你本人账号或机构授权的访问权限；Sage 不会绕过付费墙。

### 第 3 步：检索

Sage 会按站点配置执行检索：

- 有的站点是“打开检索链接直接出结果”；
- 有的站点（如学术资源站）需要在页面里输入关键词再按回车，Sage 会自动完成输入和提交，并把页面解析成文献列表。

检索完成后，Sage 会把结果整理成文献池，并告诉你这次找到了多少条、去重后剩多少条。

### 第 4 步：筛选与精读

- 你可以让 Sage 按主题、年份、期刊、被引情况等条件再筛一轮。
- 对重点文献，Sage 会做精读并记下证据笔记（结论、方法、数据、局限等），必要时下载 PDF 全文。
- 每篇文献都有一个唯一的“文献标识”，后续引用都靠它对应，避免张冠李戴。

### 第 5 步：确认大纲

Sage 会先给出综述大纲（各章节标题、每节要点、每节准备引用哪些文献），等你确认或修改后再开始写正文。

### 第 6 步：写作与核验

按大纲逐节写正文，每个论断都挂上 `[cite:文献标识]`。写完后自动跑核验：

1. **门禁**：检查检索记录、文献池、证据、大纲、草稿是否齐全，正文引用的文献是否都真实存在于文献池；
2. **逐句判定**：给每句带引用的论断打状态（支持 / 有疑点 / 不支持 / 存疑 / 引用不存在 / 未核验）；
3. **元数据核验**：拿 Crossref、OpenAlex、Semantic Scholar 三个外部库交叉核对作者、标题、年份，至少两家一致才算通过；
4. **证据核验**：检查被引文献有没有对应的证据笔记；
5. **质量自检**：生成四维评分报告。

### 第 7 步：导出

可以随时导出，导出前 Sage 会先确认门禁通过。可选：

- **综述正文**（Markdown，含参考文献列表）；
- **参考文献**：GB/T 7714（默认）或 IEEE 格式，附 BibTeX；
- **核验报告**与**质量自检报告**；
- **交给论文写作**：把稿子和文献清单转成 Word 文档，并自动做格式检查。

## 3. 结果怎么看

所有结果保存在工作区的 `.sage/literature_runs/<运行编号>/` 目录下，常用文件：

| 文件 | 看什么 |
|---|---|
| `draft.md` | 综述草稿正文（带 `[cite:...]` 标记） |
| `export/final.md` | 最终稿：正文 + 参考文献列表 |
| `export/references.json` | 参考文献条目与编号，以及使用的样式 |
| `export/papers.bib` | 可直接导入文献管理软件的 BibTeX |
| `export/verification_report.md` | 逐句核验报告 |
| `export/rubric_review.md` | 四维质量自检报告 |

### 逐句判定的六种状态

| 状态 | 含义 | 你该怎么做 |
|---|---|---|
| 支持（supported） | 引用真实存在，且没有明显问题 | 无需处理 |
| 有疑点（flagged） | 引用存在，但被引文献缺少证据笔记 | 补证据笔记，或换更贴切的文献 |
| 不支持（unsupported） | 这句话没有任何引用 | 补充引用，或删掉该论断 |
| 存疑（unclear） | 语义上无法确认这句话是否被文献支持 | 人工复核该句与原文 |
| 引用不存在（unresolved） | 引用的文献不在文献池里 | 必须修正，否则无法导出 |
| 未核验（unverified） | 尚未做语义核验 | 补跑核验 |

报告里只显示有内容的状态分组；全部通过的句子不会逐条堆出来。

### 四维质量自检

四个维度各 0–5 分，满分 20 分：

| 维度 | 看什么 |
|---|---|
| 方法 | 检索是否充分、被引文献是否有证据、元数据核验通过率 |
| 覆盖 | 文献数量、被引比例、来源站点是否多样 |
| 逻辑 | 大纲是否完整落地、是否还有不支持或引用不存在的论断 |
| 写作 | 正文篇幅、引用密度、门禁是否通过 |

总分档位：16 分及以上“优”，12 分及以上“良”，8 分及以上“及格”，其余“待改进”。

> 这份评分是**写作自检**，不是同行评审，也不评价论文的学术价值；分数只反映流程是否完整，可作为补强清单使用。

### 参考文献样式

- **GB/T 7714**（默认，国内期刊常用）：`[1] 作者. 题名[J]. 刊名, 年.`
- **IEEE**：`[1] A. Author, "Title," Venue, Year.`

编号按正文首次引用顺序自动生成，只列出实际引用过的文献；文献池里没被引用的文献不会被塞进参考文献。

## 4. 常见问题

**问：站点页面改版了，检索失败怎么办？**
答：说明站点的页面结构变了。可以让 Sage 用站点自带的“校验 / 录制”能力重新确认入口、搜索框和下载按钮；修好后再次检索即可，不需要改 Sage 本身。

**问：出现滑块验证或验证码怎么办？**
答：Sage 会把窗口留给你，由你手动完成。它不会自动破解，也不会绕过。

**问：PDF 明明下载了，页面却显示“页面不存在”？**
答：这是站点跳转的正常现象。以下载目录里实际落盘的文件为准，Sage 会校验文件是不是 PDF、标题是否对得上。

**问：为什么有些下载链接点开报“参数错误”？**
答：这类链接带有签名参数，必须点击页面上的下载按钮才能拿到完整参数；直接复制链接会失败。Sage 已经按“点按钮”的方式处理。

**问：能导出，但 Sage 提示有些文献没被引用？**
答：这是一个提醒，不阻断。没被正文引用的文献不会进入参考文献列表；你可以决定是补写引用，还是把它们留在文献池备用。

**问：门禁不通过，不能导出怎么办？**
答：按提示逐项修：补检索记录或文献、补大纲、补正文、把 `[cite:...]` 里的标识改成文献池里真实存在的。门禁全过之后即可导出。

**问：有些文献显示“未核验”或“部分通过”？**
答：外部核验只对带 DOI 或 arXiv 编号的文献生效。没有外部编号的文献会被跳过；只有一家外部库匹配上会显示“部分通过”。这些不影响导出，但建议人工抽查。

**问：某句话被标成“有疑点”是什么意思？**
答：引用本身是存在的，但被引文献还没有对应的证据笔记。补一条证据笔记，或换用有证据支撑的文献即可。

**问：质量自检分数偏低怎么办？**
答：看报告里每个维度下的问题清单，通常是最容易补的几项：多检索几轮、补证据笔记、扩大文献量、提高被引比例、让草稿覆盖大纲全部章节、增加引用密度。

**问：Sage 会不会编造参考文献？**
答：不会写入文献池之外的文献。正文引用必须对应文献池中真实存在的标识，否则门禁直接失败；编号和参考文献列表也全部由程序按实际引用生成。

**问：目前支持哪些站点？**
答：支持你自建/配置的站点（在 `~/.sage/literature_sites/` 放置站点配置，示例模板见 `docs/templates/literature-sites/`）；通过学术检索技能使用的站点（如 CNKI）也走同一套流程。第三方站点默认关闭，使用前需要你明确同意。

**问：我的账号和检索内容会不会被上传？**
答：登录在本地可见浏览器里完成，Sage 不保存密码、不导出 Cookie；检索与写作产物保存在你的工作区。合规使用仅限本人账号或机构授权范围，请勿用于绕过付费墙或批量抓取。
