# 57 智能体编排

智能体编排让 Sage 把一件复杂的事拆成若干子任务，交给多个子代理并行推进，最后汇总结果。你可以在执行前确认计划、执行中查看每个子代理在做什么、随时暂停或补充要求，并在完成后回溯完整过程与花费。

适合：需要多步调研、批量处理、跨文件改写或多方向并行探索的任务。
不适合：一句话就能完成的小问题，或必须由你逐步手工确认的高风险操作。

## 1. 发起一次编排

在对话里直接描述目标即可。任务较复杂时，Sage 会自动进入编排模式，也可以手动把编排模式切到「强制编排（LLM 拆解）」。

进入编排后，Sage 先生成一份计划，不会立刻开工。计划中的每项任务包含：

- 任务目标；
- 负责的子代理；
- 依赖关系（哪些任务要先完成）；
- 复杂度徽章：高 / 中 / 低；
- 预估轮次：≈N 轮。

预估只是参考，不代表硬性上限。

## 2. 确认与调整计划

计划以卡片形式出现在对话中，确认前可以自由调整：

1. **改目标**：直接编辑某项任务的描述。
2. **增删任务**：在计划末尾添加新任务，或删除不需要的任务（至少保留一项）。
3. **自然语言修订**：在修订输入框里说明你的调整，例如「把第 2 项拆成检索和整理两步」，Sage 会按你的话重排计划，其余任务尽量保持原样。
4. **开始执行**：确认无误后点「开始执行」。Sage 会先保存最终计划，再正式开始。

点「开始执行」后计划进入锁定状态，卡片折叠成一行摘要，不能继续编辑。如果还想调整，需要取消本次执行后重新发起。摘要可以手动展开回看。

如果你完全不想要这次编排，点「取消」即可。

## 3. 执行中的审批与步骤确认

两种确认机制可能在不同场景出现：

- **子代理工具审批**：子代理要执行敏感操作（例如删除文件、运行破坏性命令、访问工作区外路径）时会暂停并请求你确认。你可以在状态栏把「自动批准」打开，让非危险工具自动放行，危险操作仍会询问。
- **步骤确认**：如果计划被设置为逐步确认，Sage 会在每一步前弹窗，提供「继续」「跳过此步」「中止」。跳过会把当前步骤标记为已跳过并继续后面的任务；中止会结束本次编排。

## 4. 查看运行进度

打开会话右侧的「进度」面板，顶部有三个页签：

| 页签 | 内容 |
|---|---|
| 概览 | 总体状态、当前焦点任务、任务清单、历史运行 |
| 任务 | 任务树，点击任意任务进入详情 |
| 轨迹 | 完整的事件时间线 |

在「任务」页签点击一个子任务，会打开任务详情，详情内有两个页签：

- **过程**：当前步骤、是否在等待审批、错误信息、结果预览，以及实时动态（工具调用、工具返回、提问等）。这是判断「它现在在做什么」最快的入口。
- **对话**：这个子代理的完整消息记录，包括目标、思考过程、回复正文、工具调用与返回。运行中会自动刷新；任务结束后停止刷新，可手动点「刷新」查看最新内容。

任务状态包括：排队中、执行中、已暂停、已完成、失败、已取消、已跳过。

## 5. 与子代理交互

在任务详情里可以：

- **暂停 / 恢复**：暂停不会立刻打断当前这一轮思考，而是在下一轮开始前生效；暂停期间不消耗模型调用。
- **跳过**：不再执行这个子任务，其他任务继续。
- **重试该任务**：任务失败后，在整次编排结束后可单独重试失败任务；如果从整个 run 的入口重跑，已成功的任务会直接复用结果，不会重复执行。
- **补充要求（插话）**：任务运行中，在底部输入补充信息（最多 8 KB），例如追加约束、纠正方向或提供新资料。补充内容会在合适的时机进入该子代理的上下文。
- **继续追问**：任务完成后，在「对话」页签底部输入问题并点「继续」，Sage 会基于该子代理已有的上下文派发一个后续任务，并自动切换到新任务的对话记录。

任务详情顶部还会显示已用时间、消耗的 token、重试次数，以及已知定价时的估算金额。

## 6. 任务中心

侧栏「任务」入口与页面标题「任务中心」展示跨会话的统一任务列表，按「进行中 / 失败 / 已完成」分组。与编排相关的来源标签有：

- **子代理**：正在运行、暂停或失败的子任务；
- **编排运行**：当一次编排暂时没有可见子任务时，用一行代表整个 run。

点击子代理行会直接打开所属会话，并把右栏进度定位到该任务的详情；点击编排运行行会打开会话的进度面板。运行中的编排行可以直接取消。

侧栏「任务」旁的角标表示「进行中 + 失败」的任务数，便于你快速发现需要处理的事项。

## 7. 完成通知与跳转

一次编排结束（完成、失败或被取消）后，Sage 会发送桌面通知。点击通知会：

1. 聚焦 Sage 窗口；
2. 打开对应会话；
3. 把右栏切到「进度」；
4. 如果通知对应某个具体子任务，直接打开该任务详情。

通知只在 Sage 运行期间有效；退出应用后，未点击的通知不会保留。

## 8. 成本与用量

每个任务与整次编排都可能显示金额，例如 `≈ $0.0123` 或 `≈<$0.0001`。含义：

- 这是按模型定价估算的金额，不是账单；
- 只统计已知定价的模型调用；
- 如果定价未知，界面不显示金额，而不是显示 0；
- 金额按任务和整次运行分别汇总，方便判断哪一步花费较高。

## 9. 相关设置

在「设置 - 编排」中可以调整与编排相关的参数：

- **允许深层拆分**：开启后，Sage 在拆解复杂任务时可以生成带父子层级的任务树；关闭时只生成扁平任务列表。默认关闭。
- 其他编排旋钮（并发上限、预算等）修改后对新发起的编排生效，正在运行的编排不受影响。

「思考展示档位」会影响任务详情「对话」页签中思考过程的展示方式：选「详细思考」时默认展开；选「仅执行」时思考默认折叠、工具执行仍可查看；选「仅结果」时只保留结论与摘要条。

## 10. 常见限制与处理

- **重启后无法继续追问旧子代理**：继续追问依赖应用进程内的运行状态。如果 Sage 已重启，旧编排的子任务只能查看记录，不能再续聊；可以基于已有结果重新发起一个任务。
- **暂停需要等当前一轮结束**：暂停是「下一轮生效」，不会立刻中断正在进行的一次模型调用或工具执行。
- **已完成的历史子任务不在任务中心显示**：任务中心只展示进行中、暂停和失败的子任务；已完成任务的详情请回到对应会话的进度面板查看。
- **编排运行列表只显示最近一段**：统一视图默认加载最近的运行，更早的记录需要回到原会话查看。
- **历史任务行可能缺失**：早期版本在同一任务编号跨多次运行时可能互相覆盖，升级后不再发生，但已被覆盖的旧记录无法恢复。
- **编排看板与聊天编排是两条路径**：侧栏的编排看板面向 lane 维度的工作流，聊天里自动触发的编排运行是另一套执行链路，任务中心会分别标注来源。
