# 62 · 待办交互升级与工作日志 / 日报周报

> 待办页现在不止是「记事本」：你能随时改已有待办的详情、拖动调整顺序、把一条拖进另一条下面当子任务，也能在「工作日志」里随手记下今天干了什么，然后一键生成日报 / 周报直接发出去。

## 1. 能做什么

| 能力 | 说明 |
| --- | --- |
| 改详情 | 已有待办的描述、标签、关联项目、提醒、优先级都能在详情面板里改 |
| 三态循环 | 行首圆形按钮点一下切换「未开始 → 进行中 → 已完成 → 未开始」 |
| 拖动排序 | 拖住行首的把手（⣿）上下移动，顺序立刻保存 |
| 拖成子任务 | 拖到另一行的**左三分之一**松手，即成为它的子任务 |
| 状态筛选 | 工具栏可按「未开始 / 进行中 / 已完成 / 已取消」筛选 |
| 工作日志 | 单独一个面板，记进展、做完了什么、卡在哪、下一步 |
| 日报 / 周报 | 一键把日志 + 待办聚合成可复制的 Markdown 报告并存档 |

## 2. 怎么用

### 2.1 改一条已有待办的详情

在待办列表里点开某一行（或点行尾的展开箭头），会打开**详情面板**。里面可以改：

- 描述
- 标签（逗号或空格分隔）
- 关联项目
- 提醒档位
- 优先级

改完**点别处（失焦）或按 `Ctrl + Enter`** 即保存；按 `Esc` 取消本次修改。

> 如果什么都没改，不会往库里写 —— 避免无谓的保存和界面闪烁。

### 2.2 三种状态怎么切

每行最左边的圆形按钮就是状态开关，**每点一次往前走一格**：

```
○ 未开始  →  ◐ 进行中  →  ● 已完成  →  ○ 未开始
```

- 「进行中」的行有独立的半填充圆环标识，方便一眼扫出正在做的事。
- 「已取消」不在循环里，它是单独的操作（行尾菜单里）。
- 标成「已完成」时会自动记下完成时间；再点回「未开始」会清掉这个时间。

### 2.3 按状态筛选

工具栏右侧有状态下拉，选「进行中」就只看正在做的事。

> 提示：状态筛选和「今天 / 本周 / 已完成」这类**智能视图互斥** —— 选了其中一个，另一个会被清掉。这样筛选条件始终是单一的、不会互相打架。

### 2.4 拖动调整顺序

1. 把鼠标移到行首的**拖拽把手**（⣿ 图标）上；
2. 按住左键上下拖动；
3. 松手即保存。

**几个前提要知道**：

- 只有在排序方式为「**手动**」时把手才可用（这是默认排序）。换成「按优先级」「按截止时间」等排序时把手会禁用 —— 因为手工顺序和自动排序本来就冲突。
- 子任务只能在**同一层**内上下移动，不会跨层乱跳。
- 拖动失败（比如后端报错）会回到原位并提示，不会留下半截数据。

### 2.5 拖成子任务

把一条待办拖到另一条上，**松手位置决定结果**：

| 松手位置 | 结果 |
| --- | --- |
| 目标行**左 1/3** | 成为目标的**子任务** |
| 目标行**中间 1/3** | 排在目标**前面**（同层） |
| 目标行**右 1/3** | 排在目标**后面**（同层） |

拖到列表最末尾则回到**顶层**。

系统会拦住非法操作：不能把待办拖进自己的子孙里，层级最多两级（顶层 + 子任务）。

### 2.6 记工作日志

待办页顶部有**分段控件**：「待办」/「工作日志」。切到「工作日志」看到三块内容：

**① 收件箱（待确认）**

AI 从对话里抽取的工作日志候选会先落在这里，标着「待确认」。每条有两个动作：

- **确认** —— 认可这条，记入正式日志，之后会进日报/周报；
- **忽略** —— 不要这条，直接丢掉。

> **只有确认过的日志才会进报告。** 这是刻意的：AI 抽错很正常，留一道人工闸门，报告里的每句话才站得住。

**② 已确认日志流**

按天分组显示（组头是日期，如 `2026-11-27`）。每条日志有四种类别：

| 类别 | 记什么 |
| --- | --- |
| 进展 | 今天在做什么 |
| 完成 | 做完了什么 |
| 阻塞 | 卡在哪 |
| 下一步 | 接下来要做什么 |

**③ 手动添加**

不想走 AI，直接手写一条也行：选类别 + 填内容 + 保存。

**AI 抽取怎么触发**：在聊天窗口顶部的操作区点「提取工作日志」，系统读取当前对话，列出候选。也可以直接对助手说「帮我记一条工作日志：今天把 X 做完了」，助手会调用工具写入。

### 2.7 生成日报 / 周报

待办页右上角有「**日报**」和「**周报**」两个按钮。点开后弹窗分四块：

1. **时间窗** —— 起止日期（日报默认今天；周报默认近 7 天含今天），可改。
2. **历史抽屉** —— 已存档的报告列表，点一条即可回看旧报告。
3. **统计块** —— 这次报告的统计切片：工作日志条数、涉及会话数、完成 / 未完成待办数、高优先级未完成数、已逾期数，以及一个「AI 生成」或「模板生成」的徽标。
4. **正文预览** —— Markdown 格式的报告全文。

底部三个动作：**复制**、**导出 Markdown**（文件名如 `日报-2026-11-27.md` / `周报-2026-11-21_2026-11-27.md`）、关闭。

**关键点：打开弹窗不会自动生成。** 只是加载历史并预览最近一份存档 —— 你点「生成并存档」才真正生成并入库。这样不会每开一次弹窗就往库里塞一条记录。

**报告是存档件，不是实时视图。** 生成那一刻的统计会被冻结在报告里；之后你再改日志或待办，昨天生成的日报不会跟着变。

**没配大模型也能用。** 没配模型时自动降级为**模板汇总**（工作日志 + 未完成待办清单），功能不中断，只是文字没 AI 润色那么顺。

## 3. 怎么配合用

一个典型的日常节奏：

1. **白天**：在对话里干活，随手让助手记工作日志（或让助手自动抽取成候选）；
2. **抽空**：到「工作日志」面板把候选逐条确认 / 忽略；
3. **下班前**：点「日报」→ 选时间窗 → 「生成并存档」→ 复制或导出，直接发出去；
4. **周五**：点「周报」，默认覆盖近 7 天，同样导出。

待办本身仍然照常用：拖一下排优先级、点两下改状态、把大块任务拆成子任务。工作日志负责记录「事实」，待办负责「计划」，日报/周报把两者合起来。

## 4. 常见问题

**问：拖不动？**
多半是排序方式不是「手动」。在工具栏把排序切回「手动」再试。

**问：拖到别的待办上，但它没变成子任务？**
只有松手在目标行**左 1/3** 时才会变成子任务。中间和右边是「排在前面 / 后面」（同层）。

**问：为什么我不能把一条待办拖到另一条待办下面去？**
两种情况：一是被拖的待办本身已经有父级了（层级上限两层）；二是目标行自己也是子任务（子任务不能再有子任务）。

**问：日报里没有我今天记的东西？**
检查两件事：那条日志**有没有被确认**（只有 confirmed 进报告）；以及**时间窗有没有覆盖那一天**。

**问：工作日志和待办里的条目是重复的吗？**
不是。待办是「要做的事」，工作日志是「已经发生的事」。日报/周报会同时取两边：日志提供进展叙述，待办提供完成情况与未完成清单。

**问：以前的「简报」「周回顾」去哪了？**
它们改名叫「日报」「周报」了，功能更强（现在也能汇总工作日志）。底层的接口仍然保留，其他调用方不受影响。

**问：报告生成失败了？**
弹窗里会直接显示失败原因。最常见的是后端没连上；AI 润色失败会自动退回模板汇总，不会整份报告失败。

**问：工作日志能删除吗？**
能。已确认的日志可以在面板里编辑或删除；删除后它也不会再出现在后续报告里（但已经存档的旧报告不受影响）。
