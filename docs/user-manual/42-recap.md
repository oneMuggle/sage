# 进度总结（Recap）

输入 `/recap` 可让 AI 总结当前对话的进度，并给出下一步建议。对标 Claude Code 的同名命令。

## 使用方法

### 触发

1. 在聊天输入框输入 `/`
2. 在弹出的命令菜单中选择 `/recap` — 进度总结
3. 等待 AI 生成总结

### 卡片展示

生成完成后，卡片直接显示在聊天流中，包含以下段落：

- **进度总结**（始终展开）：一句话概括当前对话进展
- **下一步**（默认展开）：建议的后续操作，最多 3 条
- **关键决策**（默认折叠）：对话中做出的重要决定，点击段落标题展开
- **待确认问题**（如有，默认展开）：尚未解决的问题清单

### 关闭卡片

点击卡片右上角的 × 按钮即可关闭。

## 常见问题

### 为什么提示"对话较短"？

少于 3 条消息的对话无法生成有意义的总结。继续对话后再试。

### 为什么提示"没有可用的 LLM 配置"？

Recap 需要调用 LLM 生成总结。检查设置中是否已配置 API Key 或本地模型。

### 为什么点击后没有反应（提示"请稍后再试"）？

5 分钟内已经生成过一次总结。稍等片刻再试，避免重复消耗 token。

### 总结内容不准确怎么办？

总结基于对话历史生成，受限于 LLM 能力。如果结果不理想，可以：

- 继续对话，让上下文更丰富后再 `/recap`
- 在下一步反馈中调整提问方式

## 与上下文压缩的关系

Recap 是**手动触发、面向人类**的进度总结。系统还有自动的"上下文压缩"（`compaction`），在对话变长时自动把历史压缩成摘要续接上下文，两者互不影响：

|          | 进度总结（Recap） | 上下文压缩（Compaction） |
| -------- | ----------------- | ------------------------ |
| 触发方式 | 用户手动 `/recap` | 系统自动（上下文变长）   |
| 输出对象 | 用户阅读          | 系统内部续接             |
| 输出格式 | 结构化卡片        | 摘要文本                 |

## 自动触发（M2）

除了手动 `/recap`，系统还会在以下两种场景自动触发 recap：

### 窗口回归 recap

离开 Sage 窗口 ≥ 5 分钟，且当前会话已有 ≥ 6 条消息时，回到 Sage 会自动生成一份 recap，帮助你快速重建上下文（例如接完电话、倒完咖啡回来）。

### 上下文压缩后建议

当系统完成"上下文压缩"（compaction）时，弹出的成功提示会同时提供两个按钮：

- **进度总结**：立即查看 recap
- **查看归档**：浏览已归档的历史会话

两个按钮独立，按需选择即可。
