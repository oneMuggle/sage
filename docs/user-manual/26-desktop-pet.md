# 26 — 桌面宠物（大肥鱼）

> 适用版本：2026-10-30 起的桌面端。桌宠是可选功能，默认关闭。

## 1. 它能做什么

大肥鱼会浮在桌面上，用动画和气泡显示 Sage 当前的工作状态：

| 状态            | 表现                                                             |
| --------------- | ---------------------------------------------------------------- |
| 思考中          | 冒泡思考的待机动画                                               |
| 调用工具        | 按工具类型切换「敲命令 / 改代码 / 翻文件 / 上网查 / 用外部工具」 |
| 等待审批 / 提问 | 举手动画 + 气泡「有个操作等你确认」                              |
| 重试            | 碎碎念动画 + 气泡                                                |
| 完成            | 雀跃庆祝 + 气泡                                                  |
| 出错            | 垂头叹气 + 气泡                                                  |
| 空闲            | 随机小动作（吃饭/玩耍/节日等 87 个）；2 分钟后打盹睡觉           |

它**不会**读取屏幕内容、不会截图，也不会为了宠物额外调用模型。

### 状态面板与徽章

- **单击宠物**：打开/关闭状态面板；面板里的「回到会话」按钮跳回 Sage。
- 面板显示：当前会话名、状态、正在用的工具、待办/步骤进度、上下文用量、最近/活跃会话列表，以及 Task Center 里的后台任务（Office/Wiki/编排）。
- 宠物右上角有常驻状态徽章：转圈=思考/执行，黄色 `!`=等待审批，红色 `!`=出错，绿色 `✓`=完成，`z`=休息。
- 完成/出错会在宠物和面板里保留 45 秒，不会一闪而过；空闲后仍可在面板看到「最近：已完成/出错」。
- 面板底部显示「陪伴 N 天 · 摸头 M 次」，摸头次数与第一次见面日期会保存在本机。

## 2. 打开与关闭

1. 打开 **设置 → 智能体 → 桌宠**。
2. 打开「启用桌宠」。
3. 也可以在系统托盘右键 →「显示/隐藏桌宠」。

关闭：同位置的开关，或托盘菜单。桌宠右键菜单里的「关闭桌宠」也会写入关闭状态。

## 3. 常用设置

| 设置                     | 说明                                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| 显示位置                 | 仅在桌面 / 仅在应用内 / 两者 / 不显示；仅在应用内时显示在主窗口右下角，适合 Win7/远程桌面 |
| 大小                     | 迷你 / 小 / 中 / 大 / 特大                                                                |
| 待机节奏                 | 安静 / 标准 / 活泼；控制随机小动作之间的休息间隔（45–90 / 25–45 / 12–22 秒）              |
| 气泡提示                 | 仅重要状态（等待/完成/出错）/ 常驻 / 隐藏                                                 |
| 减少动态                 | 只显示静态姿势，适合低性能设备或不喜欢动效                                                |
| 等待审批/出错/完成提示音 | 分场景开关；首次点一下宠物后才会解锁音频（浏览器策略）                                    |
| 兼容模式                 | Win7 无 Aero / 远程桌面下使用不透明窗口、关闭点击穿透                                     |
| 回到初始位置             | 把宠物移回当前屏幕右下角                                                                  |

## 4. 交互

- **单击**：随机播放一个点击回应动画，并打开/关闭状态面板；面板里的「回到会话」可以跳回对应会话。
- **长按 0.55 秒**：摸头，播放专属动画并 +1 次摸头计数。
- **2 秒内连点 5 下**：惹她生气，播放生气动画并提示「别戳啦！」；短暂冷却。
- **拖拽**：按住移动到任意位置，松手后记住位置。
- **右键**：打开会话 / 大小 / 节奏 / 减少动态 / 气泡 / 回到初始位置 / 宠物设置 / 本次隐藏 / 关闭。
- 鼠标移到透明区域会穿透到下面的窗口，只有移到角色身上才能拖动/点击；面板打开时整窗可交互。
- **仅在应用内**：宠物显示在主窗口右下角，不占独立窗口；点击打开当前会话，右键打开宠物设置，适合 Win7 无 Aero 或远程桌面。

## 5. 隐私与素材

- 桌宠只接收状态事件（工具类别、动作、会话 ID、待办/步骤进度），不接收消息正文、命令参数或文件路径。
- 面板会显示会话名、工具名、待办文本和用量数字；这些内容只在本机渲染，不上传。
- 摸头次数、第一次见面时间和位置只存在本机 `pet-profile.json` / `pet-window.json`。
- 气泡文案来自模板，不展示对话内容；`showSessionTitle` 开启后气泡才会追加会话名，面板始终显示会话名。
- 内置动画来自开源项目 `dsh-pet`（MIT），出处与许可见 `third_party/dsh-pet/NOTICE.md`。
- 「大肥鱼」为社区二创角色；若用于商业发行，请先确认角色授权，不要暗示与 DeepSeek 的官方关系。

## 6. 排查

| 现象                 | 处理                                                            |
| -------------------- | --------------------------------------------------------------- |
| 设置里看不到「桌宠」 | 确认使用桌面端，而不是浏览器访问                                |
| 打开后没有出现       | 托盘 →「显示/隐藏桌宠」；或检查是否被「本次隐藏」               |
| 透明背景变黑         | 系统未开启桌面合成（Linux）或 Win7 未开 Aero；打开「兼容模式」  |
| 点不到宠物           | 鼠标移到角色身体上；兼容模式下整窗可点                          |
| 动画不动             | 检查「减少动态」是否开启；或显卡驱动/硬件加速问题，可关闭后重启 |
| 提示音不响           | 先点一下宠物解锁音频；再确认对应场景的提示音开关已打开          |
| 位置跑到屏幕外       | 设置 → 桌宠 →「回到初始位置」                                   |
