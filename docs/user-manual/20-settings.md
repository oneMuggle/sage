# Sage 设置

## 设置分组

Sage 设置页按用户任务分为 7 组（共 17 个 tab），左侧平铺展开，一屏可见：

| 分组 | Tab |
|---|---|
| 基础 | 基础 |
| 模型与服务 | 模型与服务（页内子导航：端点 / 模型 / 更新源） |
| 智能体 | 编排、权限与工具、MCP、插件与技能、全局规则 |
| 记忆与知识 | 记忆、Zotero 文献库 |
| 网络与远程 | 网络、远程工作区 |
| 使用与维护 | 使用统计、更新 |
| 诊断与实验 | 运行环境与诊断、进化、Harness、审计导出 |

「插件与技能」与「模型与服务」通过页内子导航切换子 tab，避免左侧导航过长。
左侧搜索可以查找设置项；高级设置默认折叠，避免普通用户被运行时参数干扰。

## 查找与导航

- **搜索**：`Ctrl+K`（macOS 为 `Cmd+K`）直接聚焦搜索框，输入后可按「tab 名」和「设置项」两级定位。
- **最近访问**：左侧顶部显示最近打开过的 3 个 tab，当前 tab 不在其中（它已在下方分组高亮）。
- **恢复默认**：任何被修改过的设置行右侧会出现「恢复默认」，点击即回到该设置的内置默认值；
  未修改的行不显示该按钮，避免误点。
- **保存反馈**：即时保存的设置项会显示明确的生效时机标记（见下节）；少数需要点「保存」的
  卡片（附件检索、端点、全局规则）在未修改时按钮禁用，修改后才有提示，离开未保存的端点
  编辑前会二次确认。

## 生效时机

| 标记 | 含义 |
|---|---|
| 保存后：立即生效 | 当前进程或下一个调用会读取新值 |
| 保存后：下次请求 | 当前请求不变，下一次请求使用新值 |
| 保存后：下次 Run | 正在运行的编排任务不变，下次 Run 使用 |
| 保存后：重启生效 | 配置已经写入，但需要重启 Electron 或后端 |
| 保存后：重新加载模型 | 已加载模型不追溯更新，重新加载后生效 |
| 保存后：仅保存 | 只保存配置，不改变当前运行状态 |

## 模型与上下文

- **自动上下文**开启时，Sage 根据模型目录选择上下文窗口；固定上下文输入会被禁用。
- 关闭自动上下文后，才使用手动设置的最大上下文长度。
- **最大输出长度**：单次回答允许生成的最大 token 数（默认 `4096`，范围 `512–32768`，步长 `512`）。回答频繁出现「回答达到长度上限，已被截断」时调高该值；数值越大占用越多上下文窗口，若超过上下文长度会自动收敛到「上下文长度 − 512」。
- Temperature 范围为 `0-2`；数值越高通常越随机，实际效果取决于模型实现。
- 当前有效配置摘要会显示当前对话模型、上下文策略、网络模式、权限模式和流式输出状态。

## 基础

基础页集中了流式输出、时区、日志时区、LLM 重试与 LLM 任务上限等通用参数。

- **LLM 重试**：请求失败后自动重试的次数上限（默认 3，范围 0–10）。`0` = 禁用重试。高级选项默认折叠，包含退避基数（秒）与最大退避（秒）。
- **LLM 任务上限**：单次任务（LLM 调用 + 工具执行 + 子代理派发 + 重试退避的累计 wall-clock）的总耗时上限（秒）。默认 `1800`；`0` = 不限上限。UI 保存后**立即优先于环境变量** `SAGE_LLM_TOTAL_TIMEOUT_S`（仅在 UI 未设置时回退到环境变量，再回退到内置默认 1800s）。超出上限时前端会明确提示「整轮任务总耗时超出上限」并指出该设置入口——这与「请求超时」（网络/端点语义）不同，后者指单次 chunk 读间隔。

## 编排

编排设置修改后对**新发起的 Run**生效。最大并发子任务数必须大于 0；预算和墙钟上限中，`0` 表示不限。高级迭代、结果截断、Worktree 和 Scratch 参数默认折叠。

超过上限导致 Run 失败时，错误提示会**直接带出具体上限数值**，例如：

- 「任务复杂度超出迭代上限 25 次，可在「设置 → 编排 → Agent 迭代次数上限」调高后重试」
- 「工具调用次数超出单轮预算 100 次，可在「设置 → 编排 → 工具调用预算」调高或拆分任务后重试」
- 「子代理未在迭代预算内收敛 6 次，可在「设置 → 编排 → 子代理迭代上限」调高或拆分任务后重试」

提示同时出现在聊天内联错误条和侧栏会话的失败徽标 tooltip 中。看到这类提示时，按其中给出的路径调高对应上限，或把任务拆成更小的目标后重试。工具调用预算按 Run 开始时生效的设置计算，调整后对下一次 Run 生效。

### 提问限制

「提问限制」分区控制 AI 在需要澄清时向用户提问的次数与选项个数，保存后**立即生效**（无需重启）。

- **连续未应答上限**（默认 3）：连续问了几次都没人回答就停止追问。觉得太啰嗦就调小，想给用户更多补充机会就调大。
- **每题最少 / 最多选项数**（默认 2 / 4）：AI 提问时必须给出的选项个数区间。「最多选项数」不能小于「最少选项数」。
- **提示词澄清问题上限**（默认 2）：告诉 AI 一轮里「至多问几个问题」。
- **单轮澄清问题上限**（默认 3）：计划前置阶段一轮最多澄清几个问题。

选项个数调高后，AI 给出的选项会更多，但用户的选择成本也随之上升；调低则适合只需二选一确认的场景。

## 网络与权限

网络模式包括在线、内网白名单和离线。TLS 例外和域名白名单属于高风险设置，处理敏感项目时建议使用内网或离线模式。权限模式决定工具调用是否需要逐次审批；`full_access` 只应在可信工作区使用。

## MCP、Hooks 和网关

- MCP 服务器和单工具开关可以单独启用/禁用。
- Hooks 会在工具事件触发时执行，命令内容应视为高权限配置。
- Telegram、Discord、Slack 网关配置会立即保存；部分 Bot Token 或连接参数需要重启后端，解绑操作即时生效。

## 更新

更新页的基础设置包括策略和通道，高级设置包括：

- 回滚窗口天数
- 自动回滚触发次数
- 自动检查周期
- 更新服务器地址（必须 HTTPS）
- 更新遥测开关
- 更新缓存保留天数

更新服务器地址由主进程校验，不能包含用户名、密码或非根路径。

## 审计导出

「诊断与实验」组下的「审计导出」把原本散落在各设置页的「复制摘要 / 复制 JSON」按钮集中到一处，
按来源分组列出。需要把当前配置、端点、权限、模型等状态发给支持人员时，直接在这里找到对应条目
点击复制即可，不必逐个页面翻找。该页只做导出，不修改任何设置。

## 恢复默认

恢复默认是破坏性操作，需要二次确认。它会重置应用设置和行为偏好，但保留站点凭据、工具审批规则和当前会话。建议在恢复前先执行记忆备份或导出。
