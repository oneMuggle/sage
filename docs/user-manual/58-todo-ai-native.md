# 58 — 待办事项与 AI 辅助

> 文档编号：58

Sage 的待办页把清单、提醒和 AI 辅助放在同一个页面。所有待办保存在本机，不需要账号或云同步。

> **本章已被 [63 · 待办交互升级与工作日志 / 日报周报](./63-todo-worklog-report.md) 部分超越**：待办侧新增详情编辑、三态循环、拖拽排序与拖拽嵌套；「简报 / 周回顾」升级为可存档的「日报 / 周报」，并新增「工作日志」面板。本章保留仍然有效的快速录入、提醒、重复任务与导出说明。

## 1. 能做什么

- 新建、编辑、完成、取消、删除待办；
- 用一句中文快速录入，例如「明天下午3点 交报告 !高 #工作」；
- 用麦克风说出待办，自动转成文字；
- 设置优先级、截止时间、标签、子任务和多档提醒；
- 搜索、按今天/近 7 天/已完成筛选、批量完成或删除；
- 让 Sage 从聊天对话中提取待办，生成日报和周报；
- 查看最近 91 天的完成热力图；
- 导出 Markdown 或 JSON。
- **改与拖**：改已有待办的详情、点行首圆形按钮切「未开始 / 进行中 / 已完成」、拖动把手排序、把一条拖到另一条上变子任务；
- **工作日志**：单独面板随手记进展 / 完成 / 阻塞 / 下一步，日报周报据此汇总。

> 改详情、三态、拖拽排序 / 嵌套、工作日志与日报周报的完整说明见 [63 · 待办交互升级与工作日志 / 日报周报](./63-todo-worklog-report.md)。

## 2. 打开待办页

点击左侧栏「待办」，或使用命令面板搜索「待办事项」。页面顶部是新建表单与操作按钮，下方是筛选栏和清单。

## 3. 新建待办

1. 在页面顶部的输入框填写标题，按回车即可创建；
2. 需要更多设置时点开「更多选项」，可以补充：
   - 描述；
   - 优先级：高 / 中 / 低；
   - 截止时间；
   - 项目标签；
   - 多个标签（用逗号或空格分隔，例如「工作 论文」）；
   - 提醒：提前 1 天 / 提前 1 小时 / 提前 10 分钟，可多选；
   - 专家归属（仅当已创建专家时显示）。

未填写截止时间的待办不会触发到期类提醒。

## 4. 一句话快速录入

点页面上的「快速添加」按钮，或直接按键盘 `N`（光标不在输入框内时），打开快速录入框。

输入框下方会实时显示解析结果：日期、优先级、标签。支持的说法：

| 类型 | 示例 |
| --- | --- |
| 相对日期 | 今天、明天、后天、大后天 |
| 星期 | 周三、星期一、礼拜五；可加「下」「本」「这」 |
| 具体日期 | 11月28日、12月1号（已过则自动顺延到明年） |
| 时间 | 下午3点、晚上8点半、9点30分、14:30、14：30 |
| 时段 | 凌晨、上午、中午、下午、傍晚、晚上 |
| 优先级 | `!高`、`!中`、`!低`（也可写 `!high`、`!medium`、`!low`） |
| 标签 | `#工作`，可写多个 |

默认规则：

- 只说日期不说时间 → 当天 18:00；
- 只说时间不说日期 → 今天该时刻；如果已过，则顺延到明天；
- 无法识别的内容会保留在标题里。

示例：输入「明天下午3点 交周报 !高 #工作」，标题为「交周报」，截止时间为明天 15:00，优先级为高，标签为「工作」。按回车创建；如果解析结果不对，可以关掉快速录入，改用新建表单手动填写。

## 5. 语音录入

1. 打开快速录入框，点右侧麦克风按钮；
2. 说出待办内容，再次点按钮结束录音；
3. 识别出的文字会追加到输入框，并继续按上面的规则解析。

限制与前提：

- 单次录音最长 60 秒；
- 需要在设置中配置好语音识别（ASR）模型；
- 首次使用需要允许 Sage 访问麦克风；
- 无法访问麦克风、环境不支持或识别失败时，会弹出错误提示。

录音只用于本次转写，不会作为附件保存在待办里。

## 6. 编辑、完成、取消、删除

- **编辑**：点击待办行内的标题即可修改；点「详情」打开详情面板可改描述、截止时间、项目标签与标签，改完按 `Ctrl+Enter` 保存、`Esc` 取消，失焦也会自动保存。
- **切换状态**：点行首圆形按钮循环「未开始 → 进行中 → 已完成」；也可在详情面板里直接选状态。
- **完成**：点击左侧的完成按钮，待办进入「已完成」视图。
- **取消**：在待办行的更多操作中选择「取消」。
- **删除**：点击删除按钮并在二次确认中确认；删除后不可恢复。
- **稍后提醒**：在待办行的右键菜单或更多操作里选择「稍后提醒」，可选「10 分钟后」「1 小时后」「明天」。截止时间会相应后移。

被推迟 2 次及以上时，行内会出现推迟次数标记，提醒你这条待办可能一直在拖。

## 7. 子任务

只有顶层待办可以添加子任务：

1. 在待办行上点击「添加子任务」；
2. 输入子任务标题，按回车创建，按 Esc 取消；
3. 子任务显示在父待办下方，可折叠、可单独完成，父行会显示完成进度。

目前最多两级：子任务不能再添加下一级。

## 8. 查找、筛选与批量操作

- **搜索**：在筛选栏输入关键词，约 300 毫秒后自动搜索标题和描述；
- **智能视图**：全部 / 今天 / 近7天 / 已完成；
  - 「近7天」只限制最晚日期，已逾期的未完成待办也会列出；
- **标签**：从下拉中选择已有标签；
- **专家**：有专家时可按下拉过滤（当前桌面端该过滤未生效，见第 16 节）；
- **优先级**：按高 / 中 / 低过滤；
- **状态**：按「未开始 / 进行中 / 已完成 / 已取消」筛选（与上方智能视图互斥 —— 选了其中一个，另一个会被清掉）；
- **排序**：按**手动**（默认，拖动调整）/ 创建时间 / 截止日期 / 优先级排序，并可切换升序/降序；
- **清除**：一键清空筛选和搜索条件；
- **批量操作**：勾选多条待办后，点「批量完成」或「批量删除」；表头「全选」可选择当前列表全部条目。

**拖动调整**：抓住待办行左侧的拖动手柄拖动即可调整顺序与层级。拖到另一条待办上方松手时，落点分三档：**左 1/3 = 变成它的子任务**、**中 1/3 = 插到它前面**、**右 1/3 = 插到它后面**。子任务不能拖入子任务（最多两级）。

搜索没有结果时会显示「没有匹配的待办」；没有搜索词时显示无待办的空状态。

## 9. 提醒与通知

待办可以触发以下提醒：

| 提醒 | 触发时间 |
| --- | --- |
| 提前 1 天 | 截止前 24 小时 |
| 提前 1 小时 | 截止前 1 小时 |
| 即将到期 | 截止前 5 分钟 |
| 已逾期 | 到期后；同一待办最多每小时提醒一次 |
| 自定义档位 | 创建时勾选的「提前1天 / 提前1小时 / 提前10分钟」，每档只提醒一次 |

说明：

- 桌面端需要保持运行（可以最小化或收到托盘）。完全退出 Sage 后不会弹通知；下次启动时会补发在关闭期间到期的提醒。
- 修改截止时间或重新打开待办后，提醒会重新计时。
- 已完成或已取消的待办不会再提醒。

## 10. 重复任务

重复任务由 cron 规则控制，当前页面没有设置入口。需要时可在智能体对话中让 Sage 创建，例如说明「每周一上午 9 点」等重复规则。完成一次任务后，Sage 会自动生成下一次实例；未完成时不会提前生成。

## 11. 从对话提取待办

1. 打开一段聊天会话；
2. 点击聊天页头部的「提取待办」；
3. Sage 会阅读最近一段对话，列出候选待办；
4. 勾选需要的条目，可直接修改标题，然后确认创建；
5. 创建出的待办会带上来源标记，方便回到原对话。

注意：

- 该功能需要先配置好模型服务，否则会提示未配置；
- 只读取最近约 80 条消息，每条最多约 2000 字符，最多给出 10 条候选；
- 不会自动与已有待办查重，重复提取可能产生重复条目。

## 12. 日报与周报

在待办页顶部：

- 点「日报」生成今日报告，基于逾期、今日到期、未来 7 天、高优先级、今日完成情况，以及你**已确认的工作日志**，给出最多 3 条建议；
- 点「周报」生成 Markdown 周报，包含「完成情况」「拖延提醒」「下周建议」三部分，并会参考推迟次数较多的待办。

两个窗口都是打开时生成一次，可以点「重新生成」。生成失败会显示错误信息；需要配置模型服务。

> 「日报 / 周报」是原「简报 / 周回顾」升级后的名字，现在还会一并汇总**已确认的工作日志**。点「生成并存档」后可以复制或导出 Markdown，报告本身会存进库里（冻结生成时刻的统计与正文，之后工作日志再改也不影响历史报告）。
>
> 工作日志面板、三态切换与拖拽排序 / 嵌套的完整说明见 [63 · 待办交互升级与工作日志 / 日报周报](./63-todo-worklog-report.md)。

## 13. 完成热力图

点顶部「热力图」展开或收起。热力图显示最近 91 天每天完成的待办数量，颜色越深表示完成越多；鼠标悬停可看到具体日期和数量。

## 14. 导出

顶部提供「导出 Markdown」和「导出 JSON」两个按钮：

- Markdown：带复选框的清单，适合粘贴到笔记；
- JSON：结构化数据，适合备份或自行处理。

当前导出固定包含已完成待办，页面暂不提供「只导出未完成」的选项。

## 15. 数据与隐私

- 待办保存在本机应用数据目录的 SQLite 数据库中，不会自动上传；
- 工作日志与已生成的报告（日报 / 周报）同样存在本机数据库，不会自动上传；
- 语音转写会把本次音频发送到你在设置中配置的 ASR 服务；
- 「提取待办」「日报」「周报」「从对话提取工作日志」会把相关对话摘录、待办标题、工作日志内容或统计信息发送到你在设置中配置的模型服务；
- 不配置任何外部服务时，待办的增删改查、快速录入、提醒和导出仍然可用。

## 16. 已知限制

- 桌面端的专家下拉过滤目前不生效（后端和接口已支持，桌面转发层缺参数）；
- AI 提炼、日报、周报、从对话提取工作日志依赖模型配置；语音录入依赖 ASR 配置；
- 快速录入只有本地规则解析，没有模型兜底；说法过于口语化时可能识别不出日期；
- 重复任务没有页面设置入口，且只在完成时生成下一次；
- 提醒依赖 Sage 保持运行，逾期提醒在重启后可能重复一次；
- 子任务最多两级；
- 批量操作逐条执行，不是一次性原子操作；批量创建中途失败时，前面已创建的条目会保留；
- 搜索在中文分词增强不可用时会退化为普通包含匹配，结果可能不如预期精确。
