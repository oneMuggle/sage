# SVG 转可编辑 PPT

Sage 可以把一组 SVG 幻灯片转换成 **PowerPoint 里能直接改的原生 PPTX**——文字是文本框、图形是图形，不是截图拼起来的图片。这个功能在 **Office 工作台**里。

## 使用前提

- 先**绑定一个工作区**，生成的 PPTX 会存到这个工作区里；
- 运行 Sage 的机器上要能访问 ppt-master 技能目录。打开对话框时 Sage 会自动检查，不可用会直接提示原因（见文末「常见问题」）。

## 操作步骤

1. 打开 **Office 工作台**，找到「**SVG → 可编辑 PPT**」区块，点「**打开**」。
2. 对话框会先显示「正在检查 ppt-master 环境…」，检查通过后即可继续。
3. 添加幻灯片，两种方式任选：
   - **添加 SVG 文件**：可多选 `.svg` 文件，按添加顺序作为页序；
   - **粘贴 SVG 源码**：展开「或粘贴 SVG 源码」，把含 `<svg>` 的文本贴进去，点「添加为幻灯片」。
4. 在幻灯片列表里核对页序：每页可用 ↑ / ↓ 调整顺序，用垃圾桶按钮移除。
5. （可选）修改「输出文件名」，默认是 `presentation.pptx`。没写后缀时会自动补 `.pptx`。
6. 点「**生成 PPTX**」。渲染期间按钮显示「渲染中…」，任务中心会出现一条「正在渲染演示文稿」。

## 结果怎么看

生成完成后，对话框下方会出现质量报告，顶部的状态标签是判断结果的关键：

| 状态标签 | 含义 | 有没有产出文件 |
| --- | --- | --- |
| **生成成功** | 质量检查通过，已转成 PPTX | 有，会显示保存路径 |
| **生成未完成** | 质量检查通过，但转换阶段出错 | 没有 |
| **质量门禁未通过** | SVG 存在**阻塞问题** | 没有 |

质量报告里会分别列出：

- **阻塞问题**（红色）：必须修复才能生成；
- **警告**（黄色）：不影响生成，但建议留意；
- 页数统计：共几页、通过几页、警告几条、错误几条。

问题条数较多时只显示前 50 条，底部会提示还有多少条未显示。

> 质量门禁不通过时 Sage **不会**生成半成品文件——避免你拿到一个「看起来能用、实际有缺陷」的 PPT。

## 编写 SVG 的小建议

- 每页一个独立 SVG，画布尺寸保持一致，生成的幻灯片版面才整齐；
- 文字尽量用文本元素而不是转成路径，生成的 PPT 里才能继续改字；
- 先自己检查一遍明显问题（元素重叠、文字溢出画布），能减少被门禁拦下。

## 常见问题

**Q：提示「ppt-master 环境不可用」，怎么办？**
A：常见有三种原因：技能目录没找到（需设置 `SAGE_PPT_MASTER_ROOT`）、技能目录不完整（完整性校验失败，恢复完整目录即可）、调用解释器不可用（`SAGE_PPT_MASTER_PYTHON` 路径不对）。按提示里的具体原因处理。

**Q：提示「请先绑定工作区后再生成演示文稿」？**
A：先在项目里绑定工作区，再回到这个对话框生成。

**Q：添加文件时提示「仅支持 .svg 文件 / 不是有效的 SVG 内容」？**
A：只接受 `.svg` 扩展名且内容里要有 `<svg>` 标签的文件。图片格式（PNG/JPG）或 Markdown 文件都不行。

**Q：生成成功，但找不到文件？**
A：报告里会显示完整的输出路径，文件在工作区的对应位置下，文件名就是你填的那个。

**Q：一次最多能放多少页？**
A：单次最多 200 页，单页 SVG 最大 5 MB。

**Q：能反过来把 PDF 或图片直接转成 PPT 吗？**
A：当前版本不行，需要先把内容整理成 SVG 幻灯片。图片转 PPT 在后续规划中。
