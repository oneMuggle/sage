# 专家资产中心

> 查看与管理某个专家「拥有什么」：私有记忆、知识绑定与技能。

## 入口

「专家」页面 → 任意专家卡片 → 点「资产」按钮。

## 资产总览

对话框顶部显示统计：**私有记忆 N 条 · 知识绑定 M 项 · 技能 K 个**。

### 私有记忆

- 只显示**该专家自己的记忆**（不含共享记忆）。
- 记忆来源有两个：
  1. 与专家对话时自动沉淀的事实与偏好；
  2. 你在「添加记忆」表单里手动写入的条目。
- 每条记忆显示：内容摘要、类型（情景 / 语义）、重要性、创建时间。

操作：

| 操作       | 说明                                                                               |
| ---------- | ---------------------------------------------------------------------------------- |
| 提升为共享 | 把这条记忆从「仅该专家可见」改为「所有专家可见」。提升后从本列表移除，出现在共享层 |
| 删除       | 删除该条记忆（不可恢复）                                                           |

### 添加记忆

在对话框底部输入内容（例如「本项目的代号必须拼成 SAGE」），选择类型与重要性（1–10），点「添加记忆」。新条目只对该专家可见。

适用场景：把长期有效的项目事实、写作偏好、术语约定直接写进专家，而不用通过对话反复"教"它。

### 知识与技能

- 知识绑定：列出该专家已绑定的知识源（项目资料 / 项目 Wiki / Zotero 分类等）；点「管理知识绑定」增删绑定。
- 技能：只读展示。要修改请点卡片上的「编辑」，在向导第 3 步勾选。

## 常见问题

**为什么记忆列表是空的？**
该专家还没有产生或手动添加过私有记忆。与它对话后会自动出现；也可以直接添加一条。

**「提升为共享」后还能撤回吗？**
目前不支持把共享记忆改回私有。请确认这条内容适合所有专家可见再操作。

**资产里的记忆和「记忆」页有什么区别？**
「记忆」页是全局管理视角（可按归属筛选所有专家）；「资产」是单个专家视角，只列它自己的私有记忆。
