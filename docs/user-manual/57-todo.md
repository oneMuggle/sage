# 57 · 待办事项

> 待办把「要做的事」从聊天里拎出来，变成一张随时可查的清单：能设截止时间和提醒、能按今天/本周/已完成快速切换、能回顾完成情况，还能让助手直接从对话里帮你把任务整理出来。

## 1. 能做什么

- **记下来**：手动填写，或用人话一句话快速录入（「明天下午3点 交报告 !高 #工作」）。
- **从对话提取**：把一段聊天交给 AI，让它列出其中的待办候选，你勾选确认后才入库。
- **提醒**：到期前自动提醒，可提前 1 天 / 1 小时 / 10 分钟，或到点前 5 分钟再催一次；没空做可以「稍后提醒」。
- **回顾**：一键生成「日报」和「周报」，并有一张完成热力图看近期节奏。
- **整理**：标签、优先级、项目关联、专家归属、子任务、搜索、排序、批量完成/删除、导出 Markdown / JSON。
- **改与拖**：改已有待办的详情、点行首圆形按钮切「未开始 / 进行中 / 已完成」、拖动把手排序、把一条拖到另一条上变子任务。
- **工作日志**：单独面板随手记进展 / 完成 / 阻塞 / 下一步，日报周报据此汇总。

> 改详情、三态、拖拽排序 / 嵌套、工作日志与日报周报的完整说明见 [62 · 待办交互升级与工作日志 / 日报周报](./62-todo-worklog-report.md)。

## 2. 怎么用

### 2.1 从对话提取待办

在聊天窗口顶部的操作区点「提取待办」，系统会读取当前对话，列出它认为可执行的事项（默认全部勾选）。你可以：

- 取消勾选不想要的；
- 直接改某条的标题；
- 点确认后，选中的条目会一次性加入待办，并标注「来自对话」，方便日后追溯是哪段对话产生的。

> 这一步只做「建议」，不会在你确认前偷偷写入任何内容。

### 2.2 手动新增

打开「待办事项」页，在顶部输入框填标题即可快速创建。点「展开详细选项」还能补：

| 选项 | 说明 |
| --- | --- |
| 描述 | 补充细节 |
| 截止时间 | 用来排序与提醒 |
| 优先级 | 高 / 中 / 低 |
| 关联项目 | 填项目标签，归到某个项目下 |
| 标签 | 逗号或空格分隔，如「工作 论文」，最多 10 个 |
| 提醒 | 可多选：提前 1 天 / 提前 1 小时 / 提前 10 分钟 |
| 专家归属 | 指定这条待办属于哪个专家；不选则为全局待办 |

**更快的输入：自然语言快速添加**

在待办页按快捷键 `N`（或在命令面板里打开，或访问带 `?quickadd=1` 的页面），会弹出「快速添加待办」。直接输入一句话，系统会实时识别并预览：

- 日期：今天 / 明天 / 后天 / 大后天；周一～周日（可加「下/本/这」）；1月20日（已过则算明年）
- 时间：下午3点 / 9点半 / 15:30，可带上午、中午、下午、傍晚、晚上、凌晨
- 优先级：`!高`、`!中`、`!低`（也认 `!high` / `!medium` / `!low`）
- 标签：`#工作`、`#论文`（可多个）

例子：「明天下午3点 交报告 !高 #工作」。识别到的日期、优先级、标签会显示成小标签，按回车即创建。只写日期不写时间默认当天 18:00；只写时间且今天已过则顺延到明天。

弹窗右侧的麦克风按钮可以语音输入（说话内容转成文字后照常解析），需要先在设置里配好语音识别模型，单次录音最长 60 秒。

### 2.3 子任务

在一条**顶层**待办上点「添加子任务」，输入标题回车即可。子任务只支持两级：子任务下面不能再挂子任务。删除父任务时，子任务会保留下来变成独立待办，不会被一起删掉。

### 2.4 提醒

设了截止时间后，系统会在这些时点提醒你：

- 提前 1 天（如果你在创建时选了「提前1天」）；
- 提前 1 小时（选了才会）；
- 到期前 5 分钟再催一次；
- 已逾期后会持续提示（同一任务大约每小时提醒一次）。

提醒会以系统通知的形式弹出，即使 Sage 缩到托盘也照样提醒（后台每隔几秒检查一次新提醒）。

**稍后提醒（snooze）**：在待办行上右键，选「稍后提醒」→「10 分钟后 / 1 小时后 / 明天」。到点会重新提醒。被推迟 2 次及以上的任务，行内会出现 `×N` 的小徽标，提示你它已经被拖了几次，周报里也会单独点出来。

### 2.5 日报

在待办页右上角点「日报」，会把今天的到期、逾期、未来一周和高优先级情况汇总，交给 AI 生成几条行动建议。未配置可用的大模型时，会退回一段固定模板文案，不会报错卡住。

> 「日报」是原「简报」升级后的名字，现在还会一并汇总你**已确认的工作日志**。点「生成并存档」后可以复制或导出 Markdown，报告本身会存进库里。

### 2.6 周报

点右上角「周报」，AI 会结合本周完成情况、最近完成的任务、还没做的高优先级事项、以及你反复推迟的任务，写出一段包含「完成情况 / 拖延提醒 / 下周建议」的复盘。

> 「周报」是原「周回顾」升级后的名字，默认覆盖近 7 天，同样可复制 / 导出并存档。

### 2.7 完成热力图与导出

- 点「热力图」展开一张近 91 天（约 13 周）的方格图，颜色越深表示当天完成得越多，用来直观看到自己的节奏。
- 点「MD」「JSON」可以把当前清单导出成 Markdown 或 JSON 文件。

## 3. 视图与筛选

待办页顶部有几组控件，可组合使用：

**智能视图**（分段按钮）：

| 视图 | 看到什么 |
| --- | --- |
| 全部 | 所有**还没完成**的待办（已完成的不在这里） |
| 今天 | 今天到期的未完成待办 |
| 近7天 | 未来 7 天内到期的未完成待办（已逾期但没完成的也会包含进来，方便清理） |
| 已完成 | 已完成的待办 |

**其他筛选与排序**：

- 搜索框：输入关键词即时搜索标题和描述；
- 按标签过滤（有标签时才出现）；
- 按专家过滤（有专家时才出现）；
- 按优先级过滤；
- 状态筛选：按「未开始 / 进行中 / 已完成 / 已取消」筛选（与上方智能视图互斥 —— 选了其中一个，另一个会被清掉）；
- 排序：按**手动**（默认）/ 创建时间 / 截止日期 / 优先级，并可切换升序、降序；
- 点「清除」一键复位所有筛选。

**批量操作**：勾选多条后，会出现「已选择 N 项」，可「批量完成」或「批量删除」。

## 4. 常见问题

**问：「全部」里为什么看不到我已经完成的任务？**
「全部」只展示未完成的待办。要看已完成，请切到「已完成」视图。

**问：语音按钮点了没反应 / 提示识别失败？**
语音输入需要先在设置中配置语音识别（ASR）模型。没配置时识别会失败并提示；配置后再试，单次录音不超过 60 秒。

**问：日报或周报没生成出内容？**
这两项依赖已配置的大模型。没有可用模型时会退回到固定文案；如果你连兜底文案都没有，检查设置里的模型配置。

**问：日报里没有我今天记的东西？**
工作日志要**确认过**才会进报告；已忽略的候选不算。另外确认报告的时间窗覆盖了那一天。

**问：设了提醒却没收到通知？**
先确认待办有截止时间、且状态不是已完成/已取消；提醒档位要在创建时勾选（比如「提前1小时」）。如果 Sage 完全退出（不是最小化到托盘），后台不会再轮询提醒。

**问：`×2` 这种小徽标是什么意思？**
表示这条待办已经被「稍后提醒」推迟了 2 次。推迟次数多会被周报列为拖延项。

**问：能不能建重复任务（比如每周都要做的事）？**
可以，通过让助手帮你创建带重复规则的待办实现；创建表单本身暂不提供重复设置入口。

**问：中文搜索搜不到？**
系统优先用中文分词做全文检索；如果检索组件在当前环境不可用，会自动退回按字面包含匹配，功能不会中断，只是精确度略有差别。
