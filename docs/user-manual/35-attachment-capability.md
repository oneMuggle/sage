# 聊天附件

> 适用版本：2026-11 之后
> 适用场景：在会话页或新对话页把文件交给 Sage 阅读

## 1. 能做什么

把文件拖进输入框（或点附件按钮选择、直接粘贴），Sage 会在发送时**读取文件全文**，
作为上下文一起交给 AI 模型。你可以：

- 上传**文档**（txt / md / csv / json / yaml / 各类源代码 / html / sql / log 等约 50 种格式）、
  **PDF / Word / Excel** 与**图片**；
- 一次最多 **10 个**附件，单个文件不超过 **25 MB**；
- 把文件拖到**页面任意位置**（不一定是输入框）也能添加——屏幕会出现"松开以添加"遮罩。

音频附件暂未开放（入口已隐藏），避免出现"显示了但发不出去"。

## 2. 怎么用

### 方式一：拖入

把文件从桌面 / 文件管理器拖到会话页，任意位置松开即可。遮罩消失后，
附件会出现在输入框上方的文件条里。

### 方式二：选择

点击输入框的附件按钮，一次可多选。

### 方式三：粘贴

复制文件后直接在输入框按 `Ctrl+V`，图片与文档都会进入附件条。

### 发送与查看

1. 附件条里先显示**文件名 + 大小**，随后自动上传（状态在图标上变化）；
2. 输入问题并发送；
3. 消息气泡上方的附件卡片会显示**读取结果**：
   - **已读取** —— 文件内容已交给模型，并显示字符数；
   - **已跳过 / 读取失败** —— 卡片会说明原因（例如"不是文本文件"、"编码不是 UTF-8"、"文件为空"）；
   - **内容过长已截断** —— 文件太大时只注入前一部分，卡片会标注；
   - **按相关度检索注入** —— 长文档按与问题的相关度选取片段后注入。

刷新会话后，附件卡片上的状态依然可见。

## 3. 附件条上的状态含义

| 显示 | 含义 | 你需要做什么 |
| --- | --- | --- |
| 灰色（处理中） | 正在读取 / 上传 | 稍候 |
| 绿色（就绪） | 已就绪，等待发送 | 直接发送 |
| 红色（失败） | 类型不支持 / 超过 25 MB / 数量超 10 个 / 上传失败 | 悬停看原因；换文件或移除后重试 |

同名文件再次添加会**替换**旧的同名附件，不会重复。

## 4. 常见问题

**Q：为什么回复里说"没有看到附件"？**
先看气泡附件卡片的状态。如果显示"读取失败"，卡片上会有具体原因。
最常见的是编码问题（如 GBK 编码的文本）——可先另存为 UTF-8 再上传。

**Q：PDF/Word/Excel 的内容准确吗？**
Sage 会提取文档的文本内容。扫描版 PDF（只有图片没有文字层）需要先用
本地 OCR（见用户手册 §29）识别，或使用带视觉能力的模型。

**Q：附件内容会占用多少上下文？**
每份文件最多注入约 10 万字符，超出部分会截断，卡片上会标注"已截断"。
附件很多或很大时，建议一次只发最关键的几份。

**Q：文件内容会被保存吗？**
附件保存在本地媒体目录，只在你的设备上，用于当前会话的上下文注入。

**Q：发送附件时能同时用 `@` 引用工作区文件吗？**
可以。`@` 引用与附件是两条独立通道，可以同时使用。
