# §41 规则中心

**日期**: 2026-11-07

## 1. 进入规则中心

- 在侧栏点击任一项目 → 进入项目详情页。
- 顶部章节 Tab 选择「规则」即进入规则中心。

## 2. 四类规则的读写

| 类型                                        | 来源              | 可编辑性                 |
| ------------------------------------------- | ----------------- | ------------------------ |
| 项目规则                                    | 当前项目数据库    | 完全可写                 |
| 规程阶段规则 / 内容检查                     | 绑定规程          | 只读（点编辑跳规程页）   |
| 项目总纲（SAGE.md / CLAUDE.md / AGENTS.md） | 项目根文件        | SAGE.md 可写，其余只读   |
| 全局规则                                    | `~/.sage/SAGE.md` | 完全可写（影响所有项目） |

每行规则：分类徽章 + 内容 + 启用开关 + 「···」菜单（编辑 / 复制 / 停用 / 删除 / 查看来源）。

## 3. 用 AI 修改规则

1. 规则页顶部「AI 帮我改」按钮 → 弹出对话抽屉。
2. 用自然语言描述期望（例如「把散落的代码风格规则统一为 ruff」）。
3. AI 返回一组 diff 卡片，**逐条勾选**接受；delete 操作**默认不勾选**。
4. 点「应用」→ 写库；冲突项标红不覆盖。
5. 单条规则「···」→「让 AI 改写这条」：只对该条出 patch。

## 4. 导出与导入

**导出**（规则页工具栏 · 导出）：

1. 选格式：规则包 JSON / 可读 Markdown / AGENTS.md。
2. 勾选范围：项目规则、项目总纲、规程、全局规则（默认不勾全局）。
3. 点「导出」落盘。

**导入**（项目总览页工具栏 · 导入规则包 / 规则页菜单）：

1. 拖入或选择 `.sagerules.json` 文件。
2. 系统预览：每项标注「新增 / 重复 / 冲突」，默认勾选新增与冲突。
3. 勾选「覆盖」后冲突项才会替换既有内容；否则跳过。
4. 全局规则勾选后需二次确认。
5. 规程项单独一张卡，点「绑定」跳转规程库。

## 5. 常见陷阱

- **规程规则不可在规则中心就地改** —— 必须去规程阶段编辑器生成新版本。
- **全局规则写入 `~/.sage/SAGE.md`** —— 影响本机所有项目，分享前请取消勾选。
- **导出 JSON 与导出 Markdown 用途不同** —— JSON 走 Sage 往返；Markdown / AGENTS.md 给人或外部 AI 工具消费，不回来。
- **导入不会自动覆盖** —— 必须显式勾选「覆盖」。

## 6. 规程库增强

- 规程库支持搜索（按名称/描述/标签）。
- 可重命名、改描述、打标签（标签入 `spec["meta"]["tags"]`，描述入 `spec["description"]`）。
- 分享链接保持原有 §126 入口，在导出弹窗中提示「想发链接？去规程库用分享」。
