# 启动状态提示

> 了解 Sage 启动过程中界面上的各种提示：哪些是在加载、哪些真的出了问题。

---

## 1. 启动时会看到什么

1. **窗口先出现**（约 1–2 秒）：侧栏和页面骨架先显示出来，不需要等所有后台服务。
2. **会话列表加载**：短暂显示灰色骨架条（"正在加载"），而不是直接显示"尚无会话"。
   如果一两秒内加载完成，骨架不会出现，避免闪一下。
3. **顶部细进度条**：显示"正在加载后台服务（3/15）"，表示 MCP 服务、调度器、
   消息网关等后台能力正在陆续就绪。
4. **全部就绪后进度条自动消失**，不再打扰。

> 如果上次打开过会话，Sage 会自动回到那个会话，不需要手动点击。

## 2. 会话加载失败

如果后端启动失败或连接中断，会话列表位置会显示**"会话加载失败"**和**重试**按钮：

- 点击「重试」即可重新拉取（后端恢复后通常一次成功）；
- 如果顶部出现「后端服务正在启动…」「后端暂时断开，正在自动重连…」横幅，
  是正常的启动/重连过程，稍等即可；「后端连接失败，请重启 Sage」才需要重启应用。

## 3. 「N 项功能降级」提示

当后台服务加载完成、但某些能力不可用时（例如 MCP 服务器连不上、磁盘剩余空间不足），
顶部会保留一条 **"N 项功能降级：MCP 服务"** 的提示：

- 鼠标悬停可以看到每个模块的具体状态（就绪 / 降级 / 失败）；
- 核心功能（会话、聊天）不受影响，可以继续使用；
- 常见原因：MCP 服务器配置了但进程未启动、磁盘空间少于 500MB、某网关凭据失效。

修复后重启 Sage 即可恢复。

## 4. 常见问题

**问：刚打开时侧栏显示"尚无会话"，是我的数据丢了吗？**

不会。启动最初一两秒内侧栏显示的是加载骨架或空白（不是"尚无会话"）；
只有数据真正加载完成且确实没有会话时，才会显示"尚无会话"。

**问：为什么有时看不到"正在加载后台服务"的进度条？**

后台服务通常在几百毫秒内就绪，进度条会在全部完成时自动消失；
如果你看到它一闪而过，说明加载很快，属正常现象。

**问：Web 降级模式（浏览器访问）有这些提示吗？**

Web 模式下不显示启动进度条（该状态由桌面端主进程转发），但会话加载骨架
与失败重试同样生效。
