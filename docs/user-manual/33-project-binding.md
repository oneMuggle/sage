# 新会话页：选择项目或使用默认工作区

> 适用版本：2026-11-20 及以后
> 入口：新会话页工具栏的项目选择器、聊天页顶部的工作区徽标

## 1. 这是什么

每段对话都需要一个工作目录，Sage 用它来读写文件、保存下载和截图、定位代码仓库。新建会话时，您可以决定这次在哪个目录里工作：

- **默认工作区 `~/Sage/`**：不挑具体项目，Sage 在用户主目录下的 `Sage` 文件夹里工作；
- **某个已登记项目**：在项目自己的目录里工作。

关键变化：**新建会话时不再有"没有工作区"的会话**。即使不选项目，新会话也会落在默认工作区 `~/Sage/`，而不是空着等您手动选择。

## 2. 新会话页的两个选项

| 选项 | 会话在哪个目录工作 | 侧边栏位置 |
| --- | --- | --- |
| 默认工作区（`~/Sage/`） | 用户主目录下的 `Sage` 文件夹（首次使用时自动创建） | 不进入任何项目分区 |
| 一个项目 | 该项目的目录 | 出现在该项目分区 |

工具栏的项目选择器在未选项目时显示"选择项目"；展开下拉列表后，第一项固定是"默认工作区（`~/Sage/`）"，后面是已登记的项目。

## 3. 直接使用默认工作区

1. 打开新会话页。
2. 展开工具栏的项目选择器，第一项就是"默认工作区（`~/Sage/`）"，选中它。如果选择器显示"选择项目"（说明还没选过项目），也可以直接跳过这一步——不选项目时默认就使用默认工作区。
3. 输入内容并发送。

发送后，Sage 会自动创建并使用 `~/Sage/`（Windows 上是 `%USERPROFILE%\Sage\`）。会话不会出现在任何项目分区中，这是正常的——它不属于某个项目。

如果系统不允许在用户主目录下创建文件夹，Sage 会退回到系统临时目录继续工作，会话不会被卡住。

## 4. 选择项目

1. 点击工具栏的项目选择器，选中目标项目。
2. 输入内容并发送。

会话的工作目录就是项目目录，会话也会归入该项目分区，便于以后在项目里找回。

**选择会被记住**：下次打开新会话页时，选择器仍会默认选中这个项目。想换回默认工作区，按上一节把选择器切回"默认工作区（`~/Sage/`）"即可；切回后这个"默认"选择同样会被记住。

## 5. 会话中切换或解除

- **聊天页顶部的工作区徽标**：显示当前目录名、来源和可用状态。展开后可以切换到其他已登记项目。
- **Office 页的"工作区目录"弹窗**：可以绑定、更换或解除当前会话的目录。解除绑定后，当前会话会暂时没有工作目录（不会自动改绑到 `~/Sage/`），需要时请重新选择目录；新建会话不受影响，仍会使用默认工作区。
- 目前没有"一键切回默认工作区"的按钮。需要回到默认目录时，可以在弹窗里手动选择 `Sage` 文件夹，或新建会话时选择默认工作区。

## 6. 和旧版本的区别

| 项目 | 2026-11-20 之前 | 现在 |
| --- | --- | --- |
| 未选择项目时的选项 | "不绑定项目" | "默认工作区（`~/Sage/`）" |
| 会话的工作目录 | 没有工作目录 | 新建会话总是有：`~/Sage/`，创建失败时退回临时目录（会话中主动解除绑定除外） |
| 不选项目时的工作方式 | 需要手动选择工作区，部分操作可能被拒绝 | 直接在 `~/Sage/` 中工作，无需额外选择 |
| 需要项目根目录的能力 | — | `git`、代码检索等仍建议在具体项目中使用 |

一句话概括：以前"不绑定项目"等于"没有工作区"；现在不选项目等于"用默认工作区"，会话始终有一个可写目录。

## 7. 常见问题

**问：新会话为什么没有出现在任何项目里？**
答：因为它使用的是默认工作区 `~/Sage/`，不属于某个项目，所以不会出现在项目分区。

**问：我上次打开过项目，为什么这次新会话又落在那个项目？**
答：新会话页会记住上次选择的项目。把选择器切回"默认工作区（`~/Sage/`）"后再发送即可；这次切换也会被记住。

**问：找不到"不绑定项目"选项了？**
答：它已被"默认工作区（`~/Sage/`）"取代，但含义不同——以前是完全不绑定工作区，现在会绑定到默认目录。

**问：`~/Sage/` 在哪里？**
答：Linux/macOS 是用户主目录下的 `Sage` 文件夹；Windows 是 `C:\Users\<您的用户名>\Sage\`。

**问：工具提示"需要绑定工作区"怎么办？**
答：少数能力（例如 `git` 操作、代码检索）需要明确的项目根目录。在聊天页顶部切换到具体项目后重试即可。

**问：可以把默认工作区改成别的目录吗？**
答：默认工作区固定为 `~/Sage/`。如果经常使用某个目录，可以把它登记为项目，在该项目下工作。
