## 1. 这个功能做什么

Sage 自带一个**双向反馈通道**：你在应用里提交问题或需求，管理员在他的工单系统里
回复，回复会沿着原路回灌到 Sage，变成你和一个「管理员」之间的会话。

整个过程不需要你配置邮箱、不需要打开浏览器，也不需要管理员另外开发一套后台 ——
管理员那边用现成的 Jira / GitLab / 邮件处理，Sage 只负责把消息送过去、把回复取回来。

三条约束决定了你的使用方式：

| 约束 | 对你的影响 |
| --- | --- |
| 需要管理员先给你一台「转发地址 + 共享密钥」 | 没配置也能写反馈，只是会停在「待送达」 |
| 客户端只负责送礼和取货，不保存管理员地址之外的任何凭据 | 地址和密钥用本机 safeStorage 加密存在本地 |
| 管理员回复靠定期拉取，不是实时推送 | 最快几分钟才能看到回复；Win7 上没有桌面通知 |

## 2. 入口

| 入口 | 位置 |
| --- | --- |
| 反馈中心 | 菜单 **帮助 → 反馈问题...** |
| 反馈配置 | **设置 → 反馈** |
| 直接地址 | 应用内路由 `/feedback` |

从菜单进入时，Sage 会直接跳到反馈中心页面；如果你是从「设置 → 反馈」进去的，
改完配置后还需要手动切到反馈中心。

## 3. 第一次使用：先配置

管理员通常会给你两样东西：**转发地址**（形如 `http://10.0.0.5:8900`）和
**共享密钥**（一长串随机字符）。

1. 打开 **设置 → 反馈**
2. 在 **管理员转发地址** 填入管理员给的 URL
3. 在 **共享密钥** 粘贴密钥
4. 视需要打开 **自动附带诊断日志**（见 §4.3）
5. 点 **保存**

保存成功后顶部状态从「未配置」变成「已配置」。

| 字段 | 说明 |
| --- | --- |
| 管理员转发地址 | 留空 = 暂不启用转发。填了才会开始同步 |
| 共享密钥 | 用本机 safeStorage 加密保存。**留空表示不改动**；想删除就先清空输入框再保存 |
| 自动附带诊断日志 | 开关。开启后新建反馈时自动把最近日志附在第一条消息末尾 |
| 本机 ID | 自动生成的安装标识。点 **复制 ID** 可以发给管理员，方便他关联工单 |
| 立即同步 | 不等下一轮，马上跑一次「提交 + 拉取」 |

> **共享密钥不是传输加密。** 它只用来证明「你是被授权的客户端」。跨网段使用时
> 请确认管理员已经在前置了反向代理加 TLS，否则消息在网线上是明文。

## 4. 新建一条反馈

### 4.1 填写内容

在反馈中心点 **新建反馈**，右侧出现表单：

1. **类型** —— 三选一：**问题** / **需求** / **其他**
2. **标题** —— 一句话概括，例如「导出 Excel 后中文变成问号」
3. **详细描述** —— 发生了什么、你期望什么结果、怎么复现
4. 点 **提交反馈**

取消就点 **取消**，已填内容不会保存。

> 类型只是给你自己分类用的，不会限制后续对话。

### 4.2 添加截图

在会话底部的输入框内点 **添加截图**，可以选一张图片：

- 单张不超过 **5MB**，超过会提示「截图不能超过 5MB」并拒绝上传
- 上传成功后输入框里出现缩略图，点 × 可以 **移除截图**
- 一条消息可以带多张图，界面显示「截图 N」

截图会被存到管理员侧；Jira/GitLab 目前只**存档**不自动贴进评论，SMTP 转发会作为
邮件附件带上。

### 4.3 自动附带诊断日志

设置里打开「自动附带诊断日志」后，**新建会话时** Sage 会自动在首条消息末尾追加：

```
—— 自动附带的诊断日志 ——
（最近 80 行运行日志，最多 4000 字符）
```

- 日志写入前会做**脱敏**（路径、token 形状的字符串等）
- 只影响**新建**会话；后续续聊不会重复追加
- 已经建好的会话里可以用会话头部的 **诊断日志 → 查看日志尾部** 手动查看

> 如果不确定日志里有没有敏感信息，先把开关关掉，只贴你确认可以外发的内容。

## 5. 看回复、继续聊、改状态

### 5.1 界面

| 区域 | 内容 |
| --- | --- |
| 左栏顶部 | **新建反馈** / **同步** 两个按钮 |
| 左栏搜索 | 输入关键词搜**所有消息正文**，命中行显示片段，点一下跳到该会话 |
| 左栏筛选 | 全部 / 问题 / 需求 / 其他 |
| 左栏列表 | 会话标题 + 类型徽标 + 状态 + 最后活动时间 |
| 右侧消息流 | 每条消息标注「我」或「管理员」，带时间戳 |
| 右侧头部 | 状态徽章 / 标记已解决（或重新打开）/ 诊断日志 |
| 底部输入框 | 继续补充…… / 添加截图 / 发送 |

### 5.2 继续对话

直接在底部输入框写内容再点 **发送** 即可。你的补充消息会先落到本地，标成
**待送达**，等下一轮同步成功后才变成 **已送达**。

### 5.3 状态

| 状态 | 含义 | 是否继续同步 |
| --- | --- | --- |
| 进行中 | 默认状态 | ✅ 会 |
| 已解决 | 你已确认问题解决 | ❌ 停止 |
| 已关闭 | 会话彻底结束 | ❌ 停止 |

- 点 **标记已解决** 从「进行中」变成「已解决」；已解决/已关闭的会话头部按钮变成
  **重新打开**，点一下回到「进行中」并恢复同步
- 停止同步**不会删除已有消息**，只是不再提交新消息、也不再拉取新回复

> 如果你标记已解决后管理员还在工单里回复，那条回复要等你**重新打开**会话后才会同步下来。

## 6. 管理员回复怎么回到你这里

`已送达` 只代表你的消息成功进了管理员侧。回复是反方向过来的：

1. 管理员在 Jira / GitLab 评论、或在管理员管理页回复
2. 管理员侧的中继把回复存下来
3. 你这边后台循环每隔几分钟去拉一次，拉到就写进本地会话
4. 有条新回复时，系统弹一条桌面通知：**管理员回复了你的反馈 · <标题>**
5. **点通知** → Sage 窗口被唤起并直接跳到反馈中心那条会话

不想等可以随时点反馈中心的 **同步** 或设置页的 **立即同步** 手动触发一轮。

> **Win7 / 老系统上可能没有桌面通知。** 当系统不支持 Electron 的 Notification 时，
> Sage 会静默跳过弹窗 —— 消息本身照样会同步下来，只是需要你主动打开反馈中心查看。

## 7. 没网、地址填错、密钥不一致时会怎样

你的消息**总是先写本地**，不会因为网络问题丢失。

| 情况 | 表现 |
| --- | --- |
| 还没填转发地址 | 会话正常保存，消息一直显示 **待送达**；填好地址后自动补发 |
| 网络中断 | 消息停留 **待送达**，后台按退避节奏重试：5 分钟 → 15 分钟 → 1 小时 → 4 小时 → 24 小时，之后一直保持 24 小时一轮 |
| 恢复网络 | 成功一轮后退避立刻重置回 5 分钟 |
| 共享密钥不一致 | 客户端日志出现 `remote POST 401`，消息始终送不出去；找管理员核对密钥 |
| 地址指向错误的服务 | 同上，通常表现为 4xx/5xx |

每轮同步最多处理 **50 条**本地会话，避免一次性把本地数据库锁住太久 —— 会话特别多的
情况下，靠后的会话要等到后续几轮。

## 8. 常见问题

**Q：没配置转发地址，写反馈有意义吗？**
有。内容会完整保存在本机，方便你先记录；等管理员给你地址和密钥后填进设置，
这些「待送达」的消息会在下一轮同步时自动补发。

**Q：消息一直显示「待送达」怎么办？**
先看设置页顶部是不是「已配置」，再点 **立即同步** 看返回的统计里「错误」是不是 0。
仍不成功就找管理员核对 **转发地址** 与 **共享密钥**，并确认你的机器能访问那台服务器。

**Q：截图能传多大？能传几个？**
单张上限 5MB；一条消息可以带多张，但会受管理员侧单请求体上限
（默认 8MiB）约束。

**Q：标记「已解决」后管理员还能看到我的新消息吗？**
不能。已解决/已关闭的会话不再向上提交，也不拉取回复。需要继续沟通就点 **重新打开**。

**Q：反馈数据存在哪里？卸载会丢吗？**
本地存在 Sage 数据目录里的 SQLite 库（`feedback_conversations` /
`feedback_messages` / `feedback_attachments` 三张表）。卸载程序**不会**自动清除
数据目录；管理员侧另有一份独立副本。

**Q：自动附带的诊断日志会不会泄露密钥？**
写入前会按脱敏规则处理路径与凭据形状的字符串，但脱敏不是万无一失的。不确定就
关掉开关，只贴你确认可以外发的内容。

**Q：Win7 上收不到通知，是不是没同步？**
不是。老系统不支持 Electron 的通知能力时 Sage 会静默降级，消息照常同步，只是不弹窗。
打开 **帮助 → 反馈问题...** 就能看到。

**Q：能不能同时连多个管理员地址？**
不能。设置里只有一组「地址 + 密钥」，指向唯一的管理员侧。
