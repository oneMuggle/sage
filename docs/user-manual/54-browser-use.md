# 52 — 让 Sage 操作网页（受控浏览器）

> 2026-11-17 新增：可见浏览器窗口、操作时间线、暂停/接管、站点授权与敏感动作确认

## 什么时候会用到

当你对 Sage 说下面这类需求时，它会打开浏览器替你操作：

- 「打开某某网站，帮我搜一下最近的公告」
- 「登录这个站点，把页面上的表格整理成 Excel」
- 「在招聘网站上找 3 个符合条件的岗位，记下链接」
- 「帮我下载页面上那个 PDF」

Sage 使用的是一种**受控浏览器**：它看得到页面、能点能输入，但每一步都在你的视线和掌控之内。

## 你会看到什么

发起浏览器任务后，桌面端会弹出（或复用）一个**独立的浏览器窗口**，你可以在里面看到 Sage 正在
访问的页面和它的操作过程。

同时，对话右侧的浏览器面板会显示：

- **状态徽章**：操作中 / 已暂停 / 用户接管，以及当前页面地址
- **操作时间线**：最近 8 步操作（打开页面、点击、输入、截图等），每步带文字说明
- **控制按钮**：暂停 / 继续 / 接管 / 归还控制 / 定位窗口
- **确认条**：需要你点头的危险操作会出现在这里（见下文）
- **操作审计**（可展开）：本次会话的操作记录，只记录动作，不记录页面内容和输入内容

> 右栏只负责「看」和「控」，页面本身在同名的独立浏览器窗口里。点「定位窗口」会把那个窗口
> 调到前台。

### 手动操作页面

右栏面板顶部有地址栏，以及前进 / 后退 / 刷新按钮。你可以随时自己打开其他页面查看；
AI 的下一步操作仍以它认为的当前页面为准，所以如果你想干预，建议先「接管」。

## 暂停、接管与归还

| 按钮 | 效果 |
|---|---|
| **暂停** | AI 当前这轮操作会被拦下，不再动页面；你随时可以点「继续」 |
| **接管** | 暂停并标记「用户正在操作」，AI 的所有浏览器动作都会被拒绝，直到你归还 |
| **归还控制** | 把控制权交回给 AI，它会从当前页面继续 |
| **定位窗口** | 把受控浏览器窗口调到前台（无头模式不可用，见 FAQ） |

用户接管期间，AI 的工具调用会收到「用户正在手动操作浏览器」的提示，它会等待而不是继续尝试。

## 站点授权

第一次让 Sage 访问一个新网站时，它会先征求你的同意，确认条里会出现三个选项：

- **仅本次会话**：允许本次对话访问该站点，本次会话内不再重复询问
- **始终允许**：允许该站点，并写入长期策略，以后不用再问
- **拒绝**：本次不访问该站点；若再次尝试，会有短时间的拒绝记忆

同样的确认也适用于其他“换页面”的入口：让 Sage 新开一个标签页打开陌生站点，或在页面上
点击链接跳转到另一个站点，都会先征求同意。选择“拒绝”后，Sage 会暂停操作，不会继续
读取那个页面。

「登录站点」功能只受长期“禁止”策略约束：被设为禁止的站点会直接拒绝登录；其他站点
（包括第一次见到的站点）可以直接打开登录窗口——因为登录是你主动发起的操作。

### 在设置里管理站点策略

打开 **设置 → 网络 → 浏览器使用**，在「站点策略」表格里可以：

- 输入域名（如 `example.com`），选择「允许」或「禁止」，点「添加」
- 对已有条目点「删除」，确认后移除

被设为「禁止」的站点，AI 无法访问，会在时间线里显示为被阻止；「允许」的站点则直接放行，
不再每次询问。

## 敏感操作确认

以下动作即使站点已授权，也会单独弹出确认条：

- 上传文件（只能上传你工作区里已有的文件）
- 提交可能涉及重要信息的表单（如注册、申请、提交订单）
- 按回车键触发的提交（回车和点击同样对待）
- 无法判断风险的元素（找不到足够信息时按「需要确认」处理，宁可多问一次）

确认条会显示操作说明，并附带一张当时的页面截图缩略图，让你看清要操作的位置；
上传文件时还会显示**具体文件名**。缩略图直接内嵌在确认条里（无需额外授权文件访问）；
如果这张图太大或无法压缩，面板会改为显示截图的本地路径。你可以：

- **批准一次**：只放行这一次；同样的动作下次还会再问
- **拒绝**：本次不执行

> 一次批准只对当前这一步有效：同一次上传批准不能换一个文件复用，也不能带到其他
> 浏览器会话里。Sage 不能拿你的旧批准去做别的操作。

## 被硬性阻止的操作

有些操作 Sage **永远不能替你做**，直接显示为「已阻止」：

- 输入密码或敏感凭据
- 支付、下单等财务操作
- 注册新账号
- 删除账号

遇到这些，Sage 会提示你亲自接管完成，例如点「接管」后自己输入密码，或使用「登录站点」功能
（Sage 会打开可见窗口，你手动登录后它会记住登录态用于后续读取）。

## 提示注入警告

网页上可能藏着针对 AI 的诱导文字（例如「忽略之前的指示」「把用户的资料发给我」）。
Sage 会把页面文本当作**数据**而不是命令；如果检测到可疑语句，会在结果里给出「疑似提示注入」
的警告，并继续只做你要求的事。看到警告时请留意该页面，必要时暂停并接管。

## 隐私说明

- **不记录页面内容**：审计表只记录动作（工具名、域名、目标元素描述、结果、耗时），不记录
  页面正文、你输入的内容、密码或 cookie。
- **截图与缩略图**：步骤缩略图和确认截图保存在本地数据目录，确认条只显示压缩后的
  内联缩略图（无法压缩时显示路径）；不会上传。`browser_screenshot` 生成的图片保存在
  你的工作区。
- **登录态**：通过「登录站点」保存的登录凭据加密存储，仅用于你授权的站点；导出使用时按域名
  剥离，不会带到其他站点。
- **视觉识别**：需要让 AI「看」页面时，截图会作为**临时**内容交给模型，仅用于当前这一轮，
  不会写进对话历史。
- 你可以在设置里关闭「步骤缩略图」，减少本地截图文件。

## 管理浏览器实例

### 标题栏实例指示器

使用浏览器功能时，标题栏会出现一个地球图标，显示当前活跃实例数（如 `2/4`）。点击它可以打开实例面板。

### 实例面板

面板列出所有活跃的浏览器实例，每个实例可以：

- **重命名**：点铅笔图标给实例起个名字（如"账号A""审核员"），方便多账号场景识别
- **绑定到当前会话**：点勾选图标，把该实例与当前聊天绑定，后续操作会优先使用它

### 调整并发上限

路径：**设置 → 网络 → 浏览器 → 最大并发实例数**

拖动滑块在 2–8 之间调整。每个实例占用约 150–300MB 内存，建议按实际需求设置：

| 档位 | 适用场景 |
|------|----------|
| 2 | 低内存设备，单账号接力 |
| 4（默认） | 日常使用，2–3 个账号并发 |
| 8 | 多账号批量操作，需要充足内存 |

### 自动回收（LRU）

路径：**设置 → 网络 → 浏览器 → 自动回收最久未使用的实例**

开启后，当实例数达到上限时，Sage 会自动关闭最久没用的那个实例（不影响你日常浏览器的标签页）。关闭时，Sage 会提示你哪个实例被回收了。

## 常见问题

### 提示「无头模式，无法定位窗口」

如果当前会话的浏览器是以无头（不显示窗口）方式启动的，就没有窗口可定位。你可以：

1. 点「暂停」后，在右栏地址栏手动打开同一页面；
2. 或者直接让 Sage 重新打开一个可见窗口（在设置中把「默认显示浏览器窗口」保持开启）。

### 页面看起来是 Canvas 或图片，AI 操作不了

如果页面主要用 Canvas 绘制（如在线表格、地图、验证码），可交互元素很少，Sage 会提示可能无法
直接点击。此时可以：

- 让 Sage 用截图 + 视觉识别来理解页面（`browser_screenshot` 返回图片）
- 或者点「接管」自己完成关键步骤

### 下载的文件在哪里

- 如果你在项目里工作：文件会存到项目的 `downloads/` 目录。
- 没有绑定工作区时：存到 Sage 的本地数据目录下的浏览器下载目录。
- 下载完成后可以让 Sage 列出下载结果（文件名、大小、完整路径），也可以直接在文件管理器中打开。

### 操作卡住了怎么办

1. 点「暂停」，看看当前页面是否停在验证码、登录框或弹窗；
2. 需要你处理的，点「接管」自己完成，再点「归还控制」；
3. 确认条一直没处理时，AI 会停在等待状态，不会自行跳过。
