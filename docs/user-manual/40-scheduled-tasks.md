# 定时任务

> 入口：左侧栏 → **定时任务**（时钟图标）
> 适用版本：main（2026-11-06 起新增「自动执行」模式）

## 1. 这是什么

定时任务让 Sage 在指定时间**自动做事**，不需要你盯着：

- **单次任务**：在某个时间点执行一次；
- **周期任务**：按 cron 规则重复执行（例如每天早上 8 点）。

触发后有两种模式，在创建/编辑任务时选择：

| 模式 | 到点后发生什么 | 适合场景 |
| --- | --- | --- |
| **自动执行**（默认） | Sage 在目标会话里跑一轮完整对话（会调用 AI 和工具），把回复写进该会话 | 每日摘要、定期检查、自动整理资料 |
| **仅提醒** | 只在目标会话里插入一条提醒消息，不调用 AI | 纯粹的时间提醒、给未来的自己留言 |

> 升级前创建的任务默认是「仅提醒」，行为与以前完全一致，不会突然产生额外的 AI 调用。想让它自动干活，编辑任务切换模式即可。

## 2. 创建一个任务

1. 进入 **定时任务** 页，点击右上角 **新建任务**；
2. 填写任务名称（自己看得懂即可）；
3. 选择 **目标会话**：到点后的内容会写进这个会话，所以请选一个你之后会去看的会话；
4. 选择执行类型：
   - **单次**：选一个未来的日期和时间；
   - **周期**：选择 cron 表达式，或用界面上的常用预设（每小时、每天 8 点等）；
5. 选择 **执行模式**（自动执行 / 仅提醒）；
6. 在 **任务内容** 里写清楚要让 Sage 做什么，例如：
   - 自动执行：`汇总今天新增的项目文件，列出需要我确认的三件事`
   - 仅提醒：`15:00 开会，提前准备周报`
7. 勾选 **启用**，点击保存。

> 任务内容是直接发给 AI 的指令，写得越具体，结果越可用。「仅提醒」模式下它就是提醒文案本身。

## 3. 看懂任务卡片

任务列表每一项会显示：

| 标记 | 含义 |
| --- | --- |
| ⚡ 自动执行 / 🔔 仅提醒 | 当前执行模式 |
| `session: xxx` | 目标会话 |
| `runs: 2/10` | 已执行次数 / 最大次数（设置了上限才显示） |
| 执行中 | 任务正在跑，完成后会变成成功或失败 |
| 耗时 1234ms | 最近一次执行用了多久 |
| 仅提醒 | 上一次触发成功，但那是提醒，不是 AI 回复 |

失败时卡片会显示红色的失败原因。失败的一次性任务会**自动停用**，不会自动重试——因为失败原因可能不确定（例如回复已经写入但后续步骤出错），自动重放可能产生重复内容。确认问题后可以手动点「立即运行」。

## 4. 查看执行结果

自动执行的任务成功后，卡片右侧的 **眼睛图标（查看结果）** 会亮起：

1. 点击眼睛图标；
2. Sage 自动切换到目标会话；
3. 页面滚动到这次任务产生的 AI 回复，并高亮显示。

「仅提醒」任务的这个按钮是灰色的——提醒没有 AI 结果可看，直接去目标会话即可看到那条提醒。

> 任务只保留**最近一次**结果。如果你手动删除了那条消息，或者换了一个新会话作为目标，旧的结果入口就会失效。

## 5. 常用操作

| 操作 | 说明 |
| --- | --- |
| 启用 / 停用 | 点击卡片上的状态徽章，停用后不会触发，但配置保留 |
| 立即运行 | ▶ 按钮手动触发一次；失败后重跑前会先确认 |
| 编辑 | 修改时间、内容、模式或目标会话 |
| 删除 | 删除任务；已产生的结果消息不会被删除 |

**改目标会话前请注意**：历史结果留在旧会话里，切到新会话后「查看结果」只会指向新会话中未来的执行。

## 6. 常见问题

**到点了没反应？**
- 确认任务是「启用」状态；
- 确认目标会话还存在（会话被删除后任务会失败）；
- 自动执行任务需要后端已配置可用的模型；没配置时会失败并显示错误。

**任务一直显示失败？**
- 先看卡片上的失败原因；
- 自动执行失败通常是模型连接、配置或超时（单次执行最长 5 分钟）；
- 修复配置后点「立即运行」验证，再重新启用。

**为什么 AI 回复没有出现在我当前打开的会话？**
任务写的是**创建时选的目标会话**，不是你现在打开的那个。点击「查看结果」会自动跳过去。

**「仅提醒」模式能不能看结果？**
不能，也无需——它只是一条提醒消息。想拿到 AI 产出就编辑任务改成「自动执行」。

**执行会不会很贵？**
自动执行会调用一次完整的对话（最多 8 轮工具调用，仍受全局工具调用预算限制）。如果只是需要提醒，选「仅提醒」即可零 AI 成本。

**能中途取消正在执行的任务吗？**
当前版本不支持中途取消；单次执行最长 5 分钟，超时会被标记为失败。
