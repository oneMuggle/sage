# 网页访问与登录态

> Sage 的网页搜索 / 网页抓取 / 文件下载能力，以及「已登录的网站」的管理：一次登录、三个通道共用登录态。

## 能力总览

Sage 的 agent 有三条出网通道，按需自动选择：

| 通道 | 用途 | 说明 |
| --- | --- | --- |
| 静态抓取 | 普通网页 / API | httpx 直连，带重试与限速 |
| JS 渲染 | SPA / 动态页面 | 无头 Chrome 渲染，命中 JS 壳或反爬时自动升级 |
| 交互浏览器 | 登录 / 复杂操作 | 真实 Chrome 窗口，支持点击 / 输入 / 截图 |

所有通道共享同一份**登录会话（Cookie + localStorage）**：在浏览器里登录一次，
Sage 会自动保存；之后静态抓取、JS 渲染与浏览器通道都能沿用。

## 设置 → 网络 → 已登录的网站

这是日常唯一需要关心的入口。

- **添加网站**：输入网址（或从「选择常见网站」里选知网、万方、维普、IEEE、Springer），
  点「登录网站」→ 在弹出的浏览器窗口里完成登录 → 自动保存并出现在列表里。
- **列表**：展示网站名称、域名、登录状态（已登录 / 已过期）与最近登录时间；
  「重新登录」会重新打开该站点登录页，「断开」会删除登录态（二次确认）。
- **登录过期**：列表会显示「已过期」；在对话里抓取该站点时也会出现「登录并继续」卡片，
  点击后直接完成登录并自动继续原任务，不需要重新描述需求。
- **浏览器会话**：带此标记的站点登录态同时包含 localStorage（知网等双 token 站点需要）。

### 高级：手动导入与诊断

「已登录的网站」下方的折叠区面向高级用户与开发者，默认收起：

- **手动导入凭据**：仅在无法通过浏览器登录的服务上使用（cookie / header，如 API key）。
  值全部加密存储（Windows DPAPI / macOS keychain / Linux secret-tool）；平台加密不可用时列表会标"明文"。
- **登录态自动刷新 / 渲染持久 profile / 渲染池大小 / TLS 指纹**：内部调优开关，普通使用无需改动。
- **浏览器（browser）健康**：显示 Sage 实际使用的浏览器与版本。出现黄色警告时：
  - **未发现浏览器**：安装 Chrome / Edge，或设置 `SAGE_BROWSER_PATH` 环境变量指向浏览器路径；
  - **版本较旧**（Chrome < 120，常见于 Win7 的 109）：部分站点可能拒绝访问，建议升级或指定新内核。
- **出网指标**：按域名显示最近的成功 / 失败 / 升级渲染次数与平均耗时；进程内存态，重启清零。

### 登录态怎么来（原理）

1. 在「已登录的网站」里点「登录网站」，Sage 打开可见浏览器窗口；
2. 你在窗口里手动完成登录（账号密码、扫码、验证码、机构 CARSI 均可）；
3. Sage 自动保存该站点的 Cookie 与 localStorage，之后三个通道立即可用。

不需要理解 cookie / header，也不需要手动导出——密码与验证码始终只在浏览器里输入，
不会经过聊天或设置页。

## 常见错误与出路

| 错误 | 含义 | 出路 |
| --- | --- | --- |
| `http_403/429/503` | 站点反爬拦截 | 已自动尝试真浏览器重放；仍失败请配置代理或换源 |
| `credential_expired` | 登录态全部过期 | 在「已登录的网站」点「重新登录」；或开启自动刷新 |
| `login_required` / `login_wall` | 需要登录 | 点击对话里的「登录并继续」卡片，或到设置页重新登录 |
| `html_instead_of_file` | 期望下载文件却拿到登录页 | 重新登录后重试，或走浏览器通道 |
| `forbidden_origin` | 非 Sage 页面发起的请求被拒 | 正常防护，无需处理 |

## 浏览器剪藏扩展

剪藏扩展跑在你自己的浏览器里，天然继承真实登录态，与上述登录会话互相独立。
