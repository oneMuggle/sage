# 网页访问与登录态

> Sage 的网页搜索 / 网页抓取 / 文件下载能力，以及「已登录的网站」的管理：一次登录、三个通道共用登录态。

## 能力总览

Sage 的 agent 有三条出网通道，按需自动选择：

| 通道 | 用途 | 说明 |
| --- | --- | --- |
| 静态抓取 | 普通网页 / API | httpx 直连，带重试与限速 |
| JS 渲染 | SPA / 动态页面 | 无头 Chrome 渲染，命中 JS 壳或反爬时自动升级 |
| 交互浏览器 | 登录 / 复杂操作 | 真实 Chrome 窗口，支持点击 / 输入 / 截图 |

所有通道共享同一份**登录会话（Cookie + localStorage）**：在浏览器里登录一次，
Sage 会自动保存；之后静态抓取、JS 渲染与浏览器通道都能沿用。

## 设置 → 网络 → 已登录的网站

这是日常唯一需要关心的入口。

- **添加网站**：输入网址（或从「选择常见网站」里选知网、万方、维普、IEEE、Springer），
  点「登录网站」→ 在弹出的浏览器窗口里完成登录 → 自动保存并出现在列表里。
- **列表**：展示网站名称、域名、登录状态（已登录 / 已过期）与最近登录时间；
  「重新登录」会重新打开该站点登录页，「断开」会删除登录态（二次确认）。
- **登录过期**：列表会显示「已过期」；在对话里抓取该站点时也会出现「登录并继续」卡片，
  点击后直接完成登录并自动继续原任务，不需要重新描述需求。
- **浏览器会话**：带此标记的站点登录态同时包含 localStorage（知网等双 token 站点需要）。

### 高级：手动导入与诊断

「已登录的网站」下方的折叠区面向高级用户与开发者，默认收起：

- **手动导入凭据**：仅在无法通过浏览器登录的服务上使用（cookie / header，如 API key）。
  值全部加密存储（Windows DPAPI / macOS keychain / Linux secret-tool）；平台加密不可用时列表会标"明文"。
- **登录态自动刷新 / 渲染持久 profile / 渲染池大小 / TLS 指纹**：内部调优开关，普通使用无需改动。
- **浏览器（browser）健康**：显示 Sage 实际使用的浏览器与版本。出现黄色警告时：
  - **未发现浏览器**：安装 Chrome / Edge，或设置 `SAGE_BROWSER_PATH` 环境变量指向浏览器路径；
  - **版本较旧**（Chrome < 120，常见于 Win7 的 109）：部分站点可能拒绝访问，建议升级或指定新内核。
- **出网指标**：按域名显示最近的成功 / 失败 / 升级渲染次数与平均耗时；进程内存态，重启清零。

### 登录态怎么来（原理）

1. 在「已登录的网站」里点「登录网站」，Sage 打开可见浏览器窗口；
2. 你在窗口里手动完成登录（账号密码、扫码、验证码、机构 CARSI 均可）；
3. Sage 自动保存该站点的 Cookie 与 localStorage，之后三个通道立即可用。

不需要理解 cookie / header，也不需要手动导出——密码与验证码始终只在浏览器里输入，
不会经过聊天或设置页。

### 抓取与下载怎么用到登录态

登录一次之后，网页抓取（`web_fetch`）和文件下载（`http_download`）会**自动**沿用登录态，
不需要复制或粘贴 cookie：

- **自动匹配站点**：Sage 根据要访问网址的域名，在已保存的登录态里查找最匹配的站点
  （例如保存了 `.cnki.net` 的登录态，访问 `www.cnki.net` 的页面会自动带上）。
  凭据只发给匹配的域名，页面跳到第三方站点时会自动去掉，登录态不会外泄。
- **用哪个账号**：默认使用「默认账号」的登录态。如果你在同一站点登录了多个账号，
  可以在对话里说明用哪个账号，Sage 会列出账号并切换到指定账号的登录态。
- **手动指定（一般不需要）**：高级情况下可显式指定凭据所属域名或账号；不指定时走上面的自动匹配。
  解析不到、已过期或域名不符时，会给出明确提示（`credential_expired` / `credential_not_found` /
  `credential_domain_mismatch`），按提示重新登录即可。
- **网页搜索不带登录态**：`web_search` 只查公开搜索引擎，不携带任何登录态；
  要搜索需要登录的站点（如知网站内检索），请让 Sage 直接抓取该站点页面或改用浏览器。

### 什么时候会自动改用浏览器

静态抓取能搞定时最快；遇到以下情况 Sage 会自动升级，不需要你手动切换：

| 情况 | 表现 |
| --- | --- |
| 页面由 JS 动态生成（SPA） | 自动用无头浏览器渲染后再取正文 |
| 静态请求被反爬拦截（403 / 429 / 503 等） | 自动用受控浏览器重放一次 |
| 站点登录态依赖浏览器会话（如知网） | 自动改用渲染通道，确保登录态生效 |
| 自动重放仍被拦，或落到登录页 | 对话里出现「登录此站点」「用浏览器打开」等操作卡片 |
| 需要点击、填表、翻页等交互 | 使用真实浏览器窗口 |

### 找文件与下载

Sage 在页面上「找可下载文件」时，会用你已登录的凭据去核对候选链接的真实类型，
所以登录后才能访问的 PDF / DOCX 不会被误判成「登录页」；识别为文件后可直接下载。
下载同样支持多账号：在对话里指定账号即可使用该账号的登录态。

### 日常浏览器扩展（复用你已经登录的浏览器）

如果你平时已经在自己常用的 Chrome / Edge 里登录了知网、校内数据库或企业后台，
可以直接把这个标签页「借」给 Sage，不必在 Sage 的浏览器里再登录一次。

1. **安装**：设置 → 网络 → 「日常浏览器扩展」→ 展开「安装步骤」。按提示打开
   `chrome://extensions`（Edge 为 `edge://extensions`），开启开发者模式，选择
   页面显示的扩展目录加载。安装包用户可在安装目录的 `resources/extension/agent-bridge`
   找到该目录。
2. **配对**：在设置页点「生成配对码」，再点浏览器工具栏的 Sage 扩展图标，粘贴
   后端地址与 10 位配对码。配对码 5 分钟内有效、只能使用一次。
3. **共享**：在已登录的目标网站标签页上点扩展图标 →「共享此标签页」。首次会请求
   允许扩展访问该网站。之后在 Sage 对话里直接说「读取这个页面」或让 agent 抓取即可，
   Sage 的浏览器工具会自动使用这个标签页。
4. **停止**：点扩展图标的「停止共享」，或在 Sage 设置页撤销该设备。标签页跳转到
   其他网站、关闭标签页也会自动停止。
5. **保存登录状态（可选）**：扩展弹窗里点「保存登录状态到 Sage」，会把当前站点的
   Cookie 与 localStorage 加密保存，之后即使不共享标签页，静态抓取 / JS 渲染也能复用。

安全边界：扩展只操作用户**手动共享的一个标签页**；共享期间浏览器顶部会显示调试
信息条；密码、扫码、短信验证码始终只在用户自己的浏览器中完成。同一时间只允许一个
共享标签页。

### Win7 内置浏览器

Win7 上未手动指定浏览器时，Sage 使用**内置浏览器**（Electron 自带的 Chromium 106）完成登录与网页交互；
在「设置 → 网络 → 浏览器」里选定系统 Chrome / Edge（或设置 `SAGE_BROWSER_PATH`）后，会改用你选定的浏览器。

- 登录窗口就是 Sage 自己的浏览器窗口，与渲染通道共享同一持久分区——
  登录一次后，抓取/渲染也能直接用上登录态；
- 非 Win7 系统仍优先使用已安装的新版 Chrome / Edge；开发验证可用
  `SAGE_FORCE_EMBEDDED_BROWSER=1` 强制启用内置浏览器；
- 内置浏览器版本较旧（Chromium 106），少数要求新内核的站点可能不兼容。

### 知网等登录站点

推荐流程：

1. 设置 → 网络 → 「已登录的网站」添加知网并登录（机构 CARSI / 个人账号 / 校园网均可）；
2. 直接对 Sage 说「帮我找/下载知网上的某篇论文」，Sage 会调用
   `cnki-research` skill：检索 → 结果解析 → 详情 → 点「PDF下载」（不使用 CAJ）
   → 校验文件 → 落盘；
3. 批量下载默认限速（5–12 秒/篇、单批 ≤20），遇到滑块验证码会交还给你处理。

## 常见错误与出路

| 错误 | 含义 | 出路 |
| --- | --- | --- |
| `http_403/429/503` | 站点反爬拦截 | 已自动尝试真浏览器重放；仍失败请配置代理或换源 |
| `credential_expired` | 登录态全部过期 | 在「已登录的网站」点「重新登录」；或开启自动刷新 |
| `login_required` / `login_wall` | 需要登录 | 点击对话里的「登录并继续」卡片，或到设置页重新登录 |
| `html_instead_of_file` | 期望下载文件却拿到登录页 | 重新登录后重试，或走浏览器通道 |
| `forbidden_origin` | 非 Sage 页面发起的请求被拒 | 正常防护，无需处理 |

## 浏览器剪藏扩展

剪藏扩展跑在你自己的浏览器里，天然继承真实登录态，与上述登录会话互相独立。
