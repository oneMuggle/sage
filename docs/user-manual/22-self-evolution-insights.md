# 22 — 自进化洞察

> 面向最终用户的操作指南。开发者视角见 [100-self-evolution-observability.md](../technical/100-self-evolution-observability.md)。

---

## 1. 这个功能做什么

Sage 的自进化子系统现在有三项**用户可感知**的新能力：

1. **进化任务有可看的耗时和指标** —— 不再只是"执行成功"四个字。
2. **学到的偏好真的进 prompt** —— 让 AI 越来越懂你。
3. **召回反馈可上报、可对比** —— 你对记忆召回的 👍/👎 被记录下来，
   两种融合策略（A/B 变体）第一次可以比较。

入口：**设置 → 进化 tab**，从上到下依次是：

| 区域 | 内容 |
| --- | --- |
| 进化任务列表 | 最近执行的任务 + duration + 指标展开 |
| 已学偏好 | Sage 学到的偏好列表 + 手动纠正 + 刷新画像按钮 |
| 召回指标 | 总体满意度 + A/B 变体对比 + 最近召回列表（可 👍/👎） |

---

## 2. 查看进化任务

每条任务显示：

- **类型**（`memory_reflection` / `preference_learning` / ...）
- **状态**（success / failed / skipped）
- **耗时**（ms，首次引入）
- **指标**（点击展开 JSON，按 `k: v` 逐行显示）

指标的 JSON 由后端 `json.dumps(ensure_ascii=False)` 写入，
所以中文（如"已合并 3 条重复偏好"）原样显示，不会变成 `\uXXXX` 转义。

---

## 3. 管理已学偏好

打开「已学偏好」面板：

- **查看**：所有以 `pref_` 开头的键值对。
- **纠正**：找到某条偏好 → 点击编辑 → 保存。
  纠正会**立即写入画像候选集**，但冻结快照不会立刻重建。
- **立即生效**：点「刷新画像快照」按钮 → 下次对话就会用新快照。

> **为什么要点「刷新画像快照」而不让它自动刷新？**
> 重建快照会让前端的前缀缓存失效（hermes 语义），导致对话响应变慢。
> 把刷新时机留给你决定，是刻意的。

## 4. 给召回反馈

当 Sage 从记忆里召回内容时，前端会显示一条召回事件。
每条事件右侧有 👍 / 👎 按钮：

1. 点 👍：该事件的 `user_feedback` 记为 `up`，正反馈计数 +1。
2. 点 👎：记为 `down`，负反馈计数 +1。
3. 不点：不算正也不算负，但**仍计入**总体召回次数（分母）。

**两个满意度口径**（指标面板里都能看到）：

| 名称 | 含义 |
| --- | --- |
| 总体满意度 | 所有召回里正反馈占多少。分母是全部召回次数。 |
| 反馈满意度 | 给了 👍/👎 的那些召回里，好评占多少。分母是有反馈的召回次数。 |

反馈越多，指标越可信。

## 5. A/B 变体对比

Sage 内部有两种融合权重策略：

| 变体 | 融合权重 |
| --- | --- |
| A | `[0.2, 0.8]`（偏重某一信号） |
| B | `[0.5, 0.5]`（均权对照） |

每次召回用 MD5(query) 的**前 8 位**的奇偶性决定走 A 还是 B ——
同一个查询**永远走同一个变体**（可复现）。

**指标面板的「变体对比表」**：

- **变体不足 2 个** → 显示「只有一个变体有数据，暂无对比」。
- **任一侧反馈 < 5 条** → 显示「反馈量不足」，**不下结论**。
- **两侧都 ≥ 5 条** → 显示哪侧领先 + 差值（百分点）。
- **两侧持平** → 显示「持平」。

「任一侧不足 5 条就不下结论」是刻意保守 ——
反馈量不足时任何"哪个更好"的判断都是噪音。

## 6. 常见问题

### Q：为什么「已学偏好」改了之后，下次对话还是一样的？

A：点「刷新画像快照」按钮。Sage 用冻结快照做前缀缓存，
写入新偏好不会自动刷新 —— 这是为了保持对话响应速度。

### Q：A/B 对比里说"持平"，但一侧反馈条数明显更多，为什么？

A：因为看的是 `feedback_satisfaction_rate`（好评率）而不是绝对好评数。
条数多 ≠ 好评率高，所以可能持平。

### Q：召回事件的 `query_hash` 是什么？为什么不是原文？

A：是 `md5(query)` 的完整哈希。只存哈希，不存原文 —— 保护隐私。
如果你怀疑两个变体错配，可以本地拿原始 query 跑 MD5 验证前 8 位。

### Q：`metrics_json` 太长会被截断吗？

A：超过 4000 字符会被截断并追加 `…(truncated)`。
正常任务不会触发，极端长文本任务可能触发。
