# 思考过程展示档位

> 适用版本：main（2026-11-02 起）
> 入口：聊天区顶部工具条 → 档位下拉；助手消息右键 → 思考展示；设置 → 基础设置 → 思考展示档位

## 1. 这是什么

Sage 聊天区对 AI 思考过程和工具调用明细提供**三个展示档位**，让你根据需要控制信息密度。

| 档位               | 显示什么                                        | 适合什么时候用                         |
| ------------------ | ----------------------------------------------- | -------------------------------------- |
| **详细思考**       | 思考全文展开 + 工具明细展开                     | 不确定 AI 是否理解对了，想看完整推理链 |
| **仅执行**（默认） | 思考折叠（保留折叠条） + 工具逐卡显示           | 日常协作，关注 AI 做了什么             |
| **仅结果**         | 思考与工具明细收成一条汇总条（默认折叠），点一下就展开完整明细 | 只关心最终结果，不想被过程干扰         |

**核心原则：任何被隐藏的内容都不会丢失**。切回「详细思考」后，之前隐藏的思考过程和工具明细立即可见。后端始终保留完整数据，前端只是控制「当前看不看」。

## 2. 怎么切换

在聊天区**顶部工具条**找到档位下拉按钮（🧠 图标 + 当前档位名称）：

1. 点击按钮，弹出下拉菜单；
2. 选择目标档位：详细思考 / 仅执行 / 仅结果；
3. 切换立即生效，当前会话中所有消息按新档位重新渲染。

菜单底部还有**「跟随全局默认」**选项——选择后会清除当前会话的单独设置，让会话回到使用设置页里配置的全局默认档位。

> 会话级切换只影响当前会话。换一个新会话，档位回到全局默认。

## 3. 单条消息单独设置

如果只想让某一条消息用不同档位：

1. 在助手消息气泡上**右键**；
2. 找到「思考展示」子菜单；
3. 选择：详细思考 / 仅执行 / 仅结果 / 跟随会话。

选择后该消息立即按指定档位渲染，不受会话和全局设置影响。

选择「跟随会话」会**清除**该条消息的单独设置，让它回到会话档位（如果会话也没设置，则使用全局默认）。

> 子菜单中「跟随会话」后面可能带有括号标注（如「跟随会话（仅执行）」），表示当前会话实际生效的档位，方便确认。

## 4. 修改全局默认档位

1. 打开**设置 → 基础设置**；
2. 找到「思考展示档位」下拉框（在「流式输出」开关下方）；
3. 选择默认档位：详细思考 / 仅执行 / 仅结果；
4. 修改立即生效，所有未单独设置过的会话和消息都会使用新默认值。

默认值为**仅执行**（`trace`），与功能上线前的行为一致。

## 5. 档位优先级

从高到低：

| 优先级 | 来源                     | 说明                            |
| ------ | ------------------------ | ------------------------------- |
| 最高   | 消息级（右键菜单设置）   | 仅对该条消息生效                |
| 中     | 会话级（顶部工具条设置） | 对整个会话生效                  |
| 低     | 全局默认（设置页）       | 对所有未单独设置的会话/消息生效 |
| 最低   | 回落默认值               | 仅执行（`trace`）               |

例如：全局默认是「仅结果」，但你把当前会话切到了「详细思考」，则该会话内所有消息用「详细思考」显示——除非你右键某条消息单独设为「仅结果」。

## 6. 常见问题

### 切回「详细思考」后还能看到之前折叠的内容吗？

能。后端始终保留完整的思考过程和工具调用数据，前端只控制显示/隐藏。
切回「详细思考」后，所有历史消息的思考过程**立即**可见，无需重新生成。

### 「仅结果」档里想临时看一眼过程怎么办？

「仅结果」档下，每条助手消息上方会显示一条灰色汇总条，写着「已隐藏思考过程与 N 步工具调用」
（只隐藏了其中一项时文案会相应变化）。**点一下汇总条**，思考正文和全部工具明细就地展开——
一次点击即可，整条消息不需要重新生成。再点一下即可收起。

汇总条只统计被收起来的普通工具调用；被拦截的调用、含图片或文件的调用始终单独显示，
不会算进「已隐藏 N 步」里。

### 为什么有些工具调用永远单独显示？

被拦截的工具调用（如网页访问被反爬拦截）、包含图片或媒体的调用、产出了文件产物的调用——
这些在**任何档位**下都不会被收进汇总条。这是有意设计：确保你不会误以为关键操作「没发生」。

### 切换档位后，历史消息也会立即变化吗？

会。档位是纯前端渲染策略，存储在共享状态中。切换后，当前会话内所有已挂载的消息
立即按新档位重新渲染——包括很早之前的历史消息。

### 会话级 / 消息级设置关闭窗口后还在吗？

不在。会话级和消息级的档位设置存在 sessionStorage 中，关闭窗口后会丢失。
如果希望某个档位长期生效，建议在设置页修改**全局默认档位**——全局默认持久保存在后端，跨窗口保留。

### 流式生成中切换档位会怎样？

「详细思考」模式下，流式期间思考面板自动展开，实时看到 AI 思考。
「仅执行」和「仅结果」模式下，流式期间思考保持折叠（消息里显示「🤔 思考中…」占位），
流式结束后也不自动展开——需要手动点击折叠条或汇总条查看。
