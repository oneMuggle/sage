# 54 离线组件包（内网）

> 适用于无法访问互联网的 Sage 桌面端（尤其是 Win7 内网）。全量安装包不需要重装，可以单独导入模型等组件。

## 1. 什么是离线组件包

离线组件包是管理员签名的 `.sagepkg` 文件，里面包含已经准备好的模型或组件文件。导入后不需要联网，也不需要执行 pip/npm。

常见组件：

| 组件 | 内容 |
| --- | --- |
| `embedding-bge-small-zh-*.sagepkg` | 语义检索/知识库嵌入模型 |
| `ocr-models-ppocr-*.sagepkg` | 本地 OCR 的 det/rec 模型 |

## 2. 从设置页导入（推荐）

1. 打开 Sage → 右上角 **设置**。
2. 左侧选择 **使用与维护 → 组件管理**。
3. 点击 **导入 .sagepkg**，选择管理员提供的组件包。
4. 等待进度条完成，看到「导入完成」。
5. **重启 Sage**，新组件才会生效。

页面上还可以：

- **扫描组件包**：自动扫描安装目录、`%ProgramData%\Sage\components` 等位置，发现可导入的包；
- **卸载**：删除已安装组件（需要重新导入才能恢复）；
- 查看已安装组件的版本、大小和签名状态。

## 3. 应用无法启动时：SageDoctor

如果 Sage 白屏或无法进入设置页：

1. 在安装目录双击 `SageDoctor.cmd`，或在命令行运行 `python -m backend.cli.rescue`。
2. 选择 **[8] 管理离线组件包**。
3. 选择 **[3] 导入 .sagepkg**，输入组件包完整路径。
4. 导入完成后重新启动 Sage。

批量部署时可直接运行：

```bash
python -m backend.cli.rescue components import D:\SageComponents\model.sagepkg --json --yes
```

## 4. 从哪获取组件包

由管理员提供，通常放在：

- 内网共享盘；
- WebDAV 云盘；
- Ubuntu 内网更新服务器；
- U 盘/审批介质（完全隔离环境）。

管理员会同时提供签名信息。**不要使用来源不明或签名无效的组件包**，Sage 会拒绝导入。

## 5. 常见问题

| 现象 | 处理 |
| --- | --- |
| 「请选择有效的 .sagepkg 组件包」 | 确认文件后缀是 `.sagepkg`，且路径可访问 |
| 「未配置组件签名公钥」 | 联系管理员放置公钥或配置 `SAGE_COMPONENT_PUBLIC_KEY_PATH` |
| 「组件包签名无效」 | 包被篡改或不是受信任密钥签名的，重新获取 |
| 「Python 版本不匹配」 | win7 需要 Python 3.8 构建的组件包，不能用 main 的包 |
| 「文件被占用」 | 关闭 Sage 后重试，或重启系统 |
| 导入成功但功能没变化 | 重启 Sage；模型类组件在启动时加载 |

## 6. 与全量安装包的区别

- 全量安装包：一次装好所有内容，适合首次部署和完全隔离环境。
- 离线组件包：不重装应用，只补装/升级/修复某个组件，适合已部署终端和按需维护。

两者可以同时使用；组件包不会改变安装包的完整性。
