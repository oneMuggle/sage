# 文档规则抽取预览 + AI 精炼

> 把 Word 文档里的格式/结构规范抽成可编辑的规则集，先在预览面板里逐条确认，再用自然语言让 AI 帮你补充或修改，最后一次性保存。

---

## 1. 它是什么

以前「从本文档抽取规则」会把抽取到的规则直接存下来，错了只能事后去规则列表里一条条改。现在改成三步：

```
1. 抽取预览  — 先看一遍 AI 抽出来的规则
2. AI 精炼   — 用自然语言让 AI 帮你改
3. 确认落盘  — 选好的规则一次性存下来
```

---

## 2. 怎么用

### 2.1 抽取预览

打开「文档 AI」→「规则」标签页，在顶部点击 **「从本文档抽取」**：

- 弹出一个大面板，左边是规则列表，右边是 AI 精炼对话
- 每条规则显示：
  - **名字** + 类型（如 `style.font`）
  - **置信度色标**：🟢 高（≥80%） / 🟡 中（50-79%） / 🔴 低（<50%）
  - **参数摘要**：如 `cjk_font: 宋体, size_pt: 12`
  - **来源摘录**：如"模板统计 156/164 段"

低置信度的规则**默认不勾选**——这意味着它们不会被保存，除非你手动勾选。

### 2.2 勾选 / 编辑 / 删除

- 勾选框：决定是否保存该规则
- **编辑**：点进去可以改规则名（回车保存，Esc 取消）
- **删除**：从草稿中移除这条规则

冲突的规则会被高亮在一起并排展示，让你选保留哪一个版本。

### 2.3 AI 精炼

在右侧对话面板里用自然语言下指令：

| 你说 | AI 会 |
|------|-------|
| "加上参考文献格式 GB/T 7714" | 建议新增一条引用规范规则 |
| "行间距改成 1.5 倍行距" | 把行间距那条规则改掉，显示前后对比 |
| "去掉页边距相关的规则" | 建议删除相关规则 |
| "为什么这条置信度低？" | 文字解释（不改动规则） |

每条 AI 建议都会显示为 diff 卡片，有 **接受 / 拒绝** 两个按钮。你也可以点 **「全部接受」** 一次性确认本轮所有建议。

**重要**：AI 改了什么都要你自己确认才会应用到草稿；草稿确认前不会保存到数据库。

### 2.4 筛选与批量选择

规则多的时候，工具栏可以帮你快速定位：

- **全选 / 全不选**：一键勾选或取消全部
- **仅选高置信度**：只勾选 🟢 高置信度（≥80%）的规则，其余自动取消勾选
- **筛选**：下拉选择 全部 / 高置信度 / 中置信度 / 低置信度，只影响列表展示（不改变勾选）

### 2.5 手动添加规则

抽取漏掉的规则可以手动补：

1. 点工具栏的 **「+ 手动添加」**
2. 填写规则名称（必填）、严重级别、说明
3. 点 **「添加」** —— 新规则出现在列表里（来源标记"手动添加"，置信度视为最高）

### 2.6 每条规则的「AI 修改」

点任意规则右侧的 **「AI 修改」**，右侧对话框会自动填入 `修改规则「规则名」：` 前缀，你只需补充要求（如"改成 1.5 倍行距"）后回车发送。AI 依然会给出 diff 卡片等你确认。

### 2.7 确认落盘

确认规则满意后：

1. 底部**「提交到」**选择器：默认「新建规则组」；也可以选择把规则追加到某个**已有规则组**
2. 新建组时填写**规则组名称**（默认会按文档名起）；追加到已有组时名称自动沿用，无需填写
3. 点 **「确认落盘 (N)」** —— N 是实际将写入的规则数
4. 成功后面板关闭，规则组出现在规则列表里并被高亮

**追加到已有组时的同名规则会自动跳过**（不会覆盖已有规则）。底部会提前显示"将新增 N 条，跳过 M 条同名规则"，落盘按钮的数字也是实际新增数。

### 2.8 草稿自动保存

草稿会自动保存在本地：

- **刷新页面 / 重启软件**后草稿不会丢——规则页顶部会出现 **「📝 有未完成的抽取草稿（N 条）」** 横幅
- 点 **「继续编辑」** 恢复审阅；点 **「丢弃」** 清空草稿
- 注意：点面板里的「取消 / ✕」是**主动丢弃**草稿（有修改时会二次确认）

---

## 3. 什么时候用这个

- 收到新文档 / 格式规范，想快速建一组可复用的规则
- 现有规则组想从一份参考文档里增量补充规则
- 不确定 AI 抽得对不对，想先过一眼再保存

---

## 4. 常见问题

**Q: 关掉预览面板会不会丢草稿？**
A: 点「取消 / ✕」关闭会丢弃草稿（有修改时会先确认）。但如果只是刷新页面或重启软件，草稿会自动保存在本地，规则页顶部会出现「继续编辑」横幅，点一下就能恢复。

**Q: 抽取到的规则是 0 条？**
A: 文档可能格式信息太少（纯文本、图片型 PDF 等）。可以改用「规范条文」抽取模式（spec 模式，需从规范书文件抽取），或点「+ 手动添加」手动补规则。

**Q: AI 精炼失败 / 没给出建议？**
A: 检查 AI 模型是否配置。如果配置了，可能是指令不够明确（比如「改一下」这种太泛），换个具体的指令再试。

**Q: 低置信度的规则我要不要用？**
A: 低置信度意味着抽取依据不太充分（例如只有一两段文本支持）。建议逐条检查；如果不确认，可以不勾选跳过，等有更明确的参考文档再补。

**Q: 抽取结果跟已有规则组冲突了？**
A: 底部「提交到」可以直接选择追加到已有规则组，同名规则会自动跳过（不会覆盖你已有的规则），提交前能看到"将新增 N 条，跳过 M 条同名规则"的预览。如果想让新版本覆盖旧规则，建议先在新组里审好，再手动编辑已有组里的对应规则。
