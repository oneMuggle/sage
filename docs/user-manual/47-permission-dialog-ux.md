# §47 权限审批对话框

**日期**: 2026-11-10

## 1. 权限审批对话框是什么

当 AI 要执行需要审批的操作（如写文件到工作区外、运行危险命令等）时，会弹出审批对话框让你决定「允许」或「拒绝」。

## 2. 来源会话标签

多会话并行时，对话框标题下方会显示**请求来自哪个会话**：

```
[ShieldAlert] 工具执行审批          [安全]
             来自会话：重构认证模块
```

- 有会话标题 → 显示标题（过长会截断，鼠标悬停可看完整标题）
- 无标题 → 显示会话 ID 前 8 位
- 无会话信息 → 不显示（兼容远程 MCP 等场景）

## 3. 长命令完整展示

对话框已加宽，参数展示区加高。典型的带多参数 bash 命令或长路径的文件写入操作现在可以完整看到，不再被截断成省略号。

## 4. 审批操作不变

- **允许 / 拒绝**：一次性审批
- **记住**：勾选后记住选择（可选工具级 / 插件级，永久 / 本次会话）
- **项目级允许**：如果对话框底部有「项目级允许」按钮，点它会把该路径加入项目的允许列表，以后同类操作不再弹窗
- **拒绝反馈**：点「拒绝」先展开输入框，可写拒绝原因（可留空直接拒绝）
- **Esc 键**：按 Esc 等同于拒绝
