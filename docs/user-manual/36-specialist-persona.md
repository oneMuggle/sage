# 专家（数字员工）

> 入口：左侧边栏「专家」→ `/specialists`
> 适用版本：含专家系统的 Sage 版本（M0–M4 全量）

「专家」是可以独立配置**人设、技能、知识、记忆和模型**的 AI 助手。你可以把它理解为一个「数字员工」：写作专家只管写作，研究专家只读你指定的资料。创建后，在聊天里选中该专家即可，切回普通助手也不会留下任何影响。

---

## 1. 从模板快速创建

1. 打开 **专家** 页面，点顶部 **「从模板创建」**。
2. 内置 5 套模板：**写作**、**研究**、**编码**、**演示**、**Office**。每张卡片显示头像、名称、一句话简介和自带技能数。
3. 选一个模板点 **「创建」**。系统立即生成一个可直接使用的专家（例如「写作专家」），头像、人设、默认技能都已配好。
4. 创建后可在卡片上点 **编辑** 微调任何细节。

> 模板是「起步配置」，创建后与模板再无关联，放心修改。

## 2. 从零创建（创建向导）

专家页点 **「新建专家」** 进入向导，按六段填写人设：

| 段落     | 写什么   | 示例                               |
| -------- | -------- | ---------------------------------- |
| 身份     | 它是谁   | 「你是一位资深的中文写作顾问」     |
| 职责     | 负责什么 | 「润色、改写、结构化写作」         |
| 工作方式 | 怎么干活 | 「先问清目标读者，再给两版改写」   |
| 输出要求 | 交付标准 | 「Markdown 格式，控制在 500 字内」 |
| 边界     | 不做什么 | 「不编造数据，不代写学术不端内容」 |
| 示例     | 典型对话 | 一问一答的样例                     |

保存后即可在聊天中使用。六段内容会以结构化提示词注入每次对话。

### 卡片界面快速指南

每位专家在专家页显示为一张卡片：

- **主按钮**：卡片中央的「💬 开始试聊」大按钮是发起对话的入口。
- **次操作**：编辑 / 知识 / 资产 三个按钮平铺在底部；版本 / 评测 / 导出 收进「更多」菜单（三点图标）。
- **独特色调**：每张卡片的背景色基于头像 emoji 自动生成，方便视觉区分。
- **禁用态**：若专家被禁用，卡片会灰度显示并带「⚠️ 已禁用」徽章，主按钮的 tooltip 会提示启用路径。

### 筛选、搜索与批量操作

- 顶部 Tab 可按来源筛选：**全部 / 内置 / 我的 / 导入**；搜索框按名称或标语过滤。
- 点「批量管理」进入选择模式：勾选多张卡片后可批量 **启用 / 禁用 / 删除**（删除会级联清理该专家的私有记忆、版本与评测记录，不可撤销）。

### 最近使用与置顶

- 卡片徽标显示 **「今天使用 / N 天前使用」**（与专家对话后自动更新）。
- 「更多」菜单 → **置顶**：把该专家移到列表最前。

### 专家详情页

- 点击卡片头部（头像或名称）进入详情页 `/specialists/:id`。
- 详情页 Tab：**概览**（统计）/ **人设**（六段只读）/ **技能** / **管理**（知识绑定 / 资产中心 / 版本历史 / 评测）。
- 详情页顶部可直接「开始试聊」或「编辑」。

## 3. 配置技能

在专家编辑页的 **技能** 区勾选允许使用的技能：

- **只勾选的技能才会生效**，一个都不勾表示该专家不能使用任何技能。
- 创建向导里可以一键继承模板自带的技能。
- 技能名支持通配，如 `polish-*` 匹配所有以 `polish-` 开头的技能。
- 专家私有的技能文件（放在专家包内）同样受这里的勾选约束。

## 4. 绑定知识

编辑页的 **知识** 区可以为专家指定专属资料源，支持：

- **项目 Wiki**：固定读某个项目的 Wiki 页面；
- **项目资料**：某个项目工作区里的文档；
- **Zotero 文献集合**：某个文献集合（需先连接 Zotero）；
- **专家私有知识**：直接上传给这位专家的文件。

聊天时，专家会先检索这些资料再回答；引用会以「专家知识」标签列出，点击可跳到对应页面。

**没查到就直说**：如果检索资料后一无所获，专家会明确告诉你「资料中未找到相关内容」，而不是凭空编造。

## 5. 记忆行为

每位专家的记忆默认**只属于自己**：写作专家记住的写作偏好不会出现在研究专家的对话里。记忆区可配置：

- **写入范围**：写给自己 / 写入共享层（所有助手可见）；
- **读取范围**：是否也读取共享记忆、项目记忆。

对话中产生的有价值的记忆，也可以在记忆管理页手动 **「提升为共享」**，让所有专家都能用。

## 6. 在聊天中使用

1. 新建或打开一个对话；
2. 在聊天头部点角色选择器，选中你的专家；
3. 之后该对话都由这位专家回复。

每个对话的专家绑定互相独立，随时可切换回「主助手」。

## 7. 导入与导出（分发专家）

### 导出

在专家卡片上点 **导出**，得到 `.sage` 文件（zip 格式），包含人设、头像、私有技能和私有知识。

### 导入

专家页点 **「导入」**，选择 `.sage` 文件即可。导入后是一个**新的专家**，不影响已有专家。

注意事项：

- 人设、技能、记忆策略、模型参数等行为配置会完整保留；
- 项目 Wiki、资料库等**绑定到本机项目**的知识源无法跨机器迁移，导入时会被自动丢弃并在结果中提示数量（`dropped_bindings`）；
- 出于安全考虑，导入的专家权限最高为「工作区可写」，包内声明的「完全访问」会被降级。

## 8. 版本历史与回滚

每次修改专家配置，系统都会自动保存一个版本快照（每位专家保留最近 50 个）。

1. 专家卡片点 **版本**；
2. 选两个版本可以查看 **字段级差异**（哪些设置改了）；
3. 对任一历史版本点 **回滚**，确认后即恢复该版本配置（回滚本身也会生成一个新版本，可再次撤回）。

## 9. 评测专家质量

模板创建的专家支持 **黄金任务集** 评测：

1. 专家卡片点 **评测**；
2. 系统展示内置的测试任务（每套模板 2 条，共 10 条）；
3. 点 **运行评测**，专家逐条作答，系统按「关键词覆盖 / 禁用词 / 拒答 / 字数」等确定性规则判分；
4. 结果给出总通过率、分模板通过率和逐条检查明细，并保存历史记录。

> 评测需要先配置好模型服务；未配置时会逐条记为错误而不会中断。评测会真实调用模型，请注意 token 消耗。

## 10. 常见问题

**Q：专家和普通助手有什么不同？**
A：人设、技能、知识、记忆、模型参数可以分别定制，且互不干扰。普通助手（主助手）是「无专家化」的默认状态。

**Q：删掉专家会连带删掉什么？**
A：它的私有记忆、知识文件、版本快照和评测记录都会一并删除；共享记忆不受影响。删除是逐级删除的，任何一步失败都不会留下半个专家。

**Q：专家能用我发给它的文件吗？**
A：可以。上传到对话的文件对该对话的专家可见，与普通对话一致。

**Q：为什么专家回答「资料中未找到」？**
A：它绑定了知识源但没有检索到相关内容，按设计为宁可拒答也不编造。可以检查知识绑定是否覆盖了相关项目/集合，或把资料直接上传给该专家。

**Q：导入的专家为什么少了知识绑定？**
A：项目 Wiki、项目资料、Zotero 集合都指向本机具体项目，换一台机器后无法对应，导入时会自动剔除；专家私有知识会随包迁移。

## 11. 私聊与群聊（数字员工联系人）

把专家当作「联系人」来用：点开即聊，也可以把多个专家拉进同一个对话。

### 私聊

1. 进入 **专家** 页；
2. 点击专家卡片头部（头像/名称区域）或 **「开始试聊」** 按钮；
3. 系统自动新建对话并绑定该专家，直接跳到聊天页。

想更换专家或加成员时，可随时在聊天头部操作；侧边栏会话列表会显示当前绑定的专家名字与头像。

### 群聊

1. 专家页点 **「新建群聊」**；
2. 在多选框中勾选 2 个及以上专家，确认后创建群聊对话；
3. 聊天页顶部会显示群成员。第一个加入的专家是 **主持**，默认代表团队发言，不可移除；其余成员可随时点 × 移除。

### 指定谁发言

在输入框输入 **@专家名** 即可让指定专家回答，例如：

```
@写作专家 帮我起草一段产品简介
```

- 名字按群成员精确匹配；成员名字有重叠时取更长的那个；
- 没有 @ 时，由主持专家回答；
- 群聊中每位专家的回答会显示其头像与名字，方便区分。

> 群聊中的记忆仍分别记在**实际发言的那位专家**名下，互不串味。
