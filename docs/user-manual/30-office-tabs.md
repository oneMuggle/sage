# 30. 文档与验收页面导航

> 适用版本：Sage release/win7 @ 2026-11-02（`/office` 信息架构重构）
> 用户入口：桌面端侧栏「文档与验收」（`/office`）

## 1. 为什么页面变了

「文档与验收」页面从 2026-07 起，每来一批新能力（Office CRUD、期刊模板）就在页面末尾加一个区块。几个批次叠加下来，页面平铺了 **十余个常驻区块** —— 处理流、生成流两条互不相关的任务混在一起，想找一个功能只能往下滚。

现在页面改成 **按任务分组**：顶层 2 个页签。首屏只显示一个任务域，页面长度大幅缩短。

**功能一条没少**，全部可达，只是换了位置。

## 2. 顶层两个页签

| 页签 | 什么时候用 | 里面有什么 |
|------|-----------|-----------|
| **文档处理**（默认） | 已有 Word / Excel / PPT / PDF 要看、要改、要归档 | 4 个文件选择器、预览面板、编辑预览、文档列表、历史版本与快照、批量归档恢复 |
| **文档生成** | 从零做一个新文档 | 生成表单（自由模式 / 从模板创建）；「期刊模板助手」收在下方**默认收起的折叠卡**里 |

> **还有两个页签待补**：「审校与规范」和「LaTeX」。它们依赖的功能（Word 文档智能系列、LaTeX 写作栈）目前只在 main 分支，尚未同步到 Win7 版本；等对应功能同步完成后，会以相同的页签形式出现在同一位置，网址格式与下表一致。

## 3. 切页签不会丢东西

每个面板把「你填的文件路径」「刚才跑出来的结果」存在自己的输入状态里。所以：

- **切换页签不卸载面板** —— 切回刚才那个页签，你填的路径和结果都还在，不用重填。
- **首次进入不会一次加载全部面板** —— 只有你点开的页签才会挂载，所以第一次打开页面比原来快。

## 4. 地址栏就是当前位置

页签状态写进了网址，所以可以直接把链接发给别人、收藏、或者用浏览器前进/后退：

```
/office                              → 文档处理（默认）
/office?tab=generate                 → 文档生成
```

> 网址里参数写错或过期了会自动回到「文档处理」，不会出现空白页。

**聊天里的快捷入口**也跟着变了：

- 输入 `/office` → 打开「文档处理」
- 输入 `/journal` → 打开「文档生成」（期刊模板助手就在这个页签的折叠卡里）

产物面板里点「去处理」也会直接落到「文档处理」页签。

## 5. 右上角「环境」按钮

以前页面顶部一直挂着「能力徽章条」和「暂存目录检查」两个诊断区块，不管用不用都占地方。现在它们收进页头右上角的 **「环境」胶囊按钮**：

- 点开 → 看到本机 soffice / PDF 等能力是否可用、暂存目录状态；
- 收起时仍在后台探测，所以「导出 PDF」这类依赖能力的按钮状态始终准确。

## 6. 常见问题

**Q1. 我原来在页面最下面找「期刊模板助手」，现在去哪了？**
在「文档生成」页签下方，是一张默认收起的卡片，展开即是。它不再常驻占位。

**Q2. Word 的审校功能去哪了？**
这个 Win7 版本还没有同步 Word 文档智能系列（含审校与规范抽取），所以「审校与规范」页签暂时不存在。功能同步后会以页签形式补上，位置不变。

**Q3. 我想直接跳到某个页签，链接怎么写？**
见第 4 节的地址格式。

**Q4. 页面打开时比以前慢还是快？**
首次加载更快 —— 之前所有面板一次性挂载并各自发起请求，现在按需加载。切到没去过的页签时会有一次加载延迟。

**Q5. 页面上还有那么多区块吗？**
没有了。诊断类收进「环境」按钮，其余按任务归入页签，每个页签内的区块数都在个位数。
