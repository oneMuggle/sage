# 输入框下方的会话状态条

> 了解输入框下方那条"用量 / 响应速度 / 上下文"状态条：它显示什么、怎么看明细、什么时候出现。

---

## 1. 它是什么

以前「用量统计」「响应速度统计」「上下文统计」显示在聊天顶栏，占掉了宝贵的纵向空间。现在它们统一收纳到**输入框正下方的一行状态条**里，样式参考主流 AI 应用的输入框底部状态区：

```
┌──────────────────────────────────────────────────┐
│  输入区                                          │
└──────────────────────────────────────────────────┘
💰 12.3k tok · $0.0500  🎯 68%  ⚡ 2.1s    上下文 ▓▓▓░░ 42%   128/8000
```

从左到右依次是：

| 位置 | 内容 | 说明 |
|------|------|------|
| 左一 | 💰 累计 Token 与估算成本 | 当前会话所有请求的累计量；发生过缓存交互时附带 🎯 缓存命中率 |
| 左二 | ⚡ 平均响应时间 | 本轮会话的平均延迟；超过 10 秒显示警示色 |
| 右一 | 上下文占用条 | 上一轮请求占用了多少上下文窗口，点击查看分类明细 |
| 右二 | 字数计数 | 当前输入的字数 / 上限 |

窗口较窄时，缓存命中率等次要信息会自动收起，只保留核心数字。

## 2. 怎么看明细

- **点击 💰 用量徽章**：弹出明细，包含请求次数、输入/输出 Token、估算成本、缓存命中率，以及平均 / P95 / 最慢响应时间和按模型的统计。
- **点击上下文占用条**：弹出上下文分类明细（工具定义、历史对话、项目资料、记忆等各占多少），底部说明"剩余空间"。

弹层向上展开，点击空白处或按 Esc 收起。

## 3. 什么时候出现

- **新会话、还没有任何对话**：显示的是引导语"Sage 会记住你的项目信息…"，状态条暂不出现。
- **开始对话后**：只要产生了用量数据或上下文快照，状态条就接管这一行，引导语自动让位。
- **切换会话**：状态条先清空再拉取新会话的数据，不会误显示上一个会话的数字。

## 4. 数据多久刷新一次

- 对话进行中约每分钟刷新一次；**一轮回答结束时立即刷新**，所以回答刚完成时看到的就是这一轮最终的 token、成本和延迟。
- 空闲时不做周期性刷新，避免无意义的请求。
- 拉取失败时会保留上一次的数字，不影响输入和继续对话。

## 5. 常见问题

**问：状态条上什么都没显示？**

新会话还没有用量数据时该行是空的（或显示引导语）。发送第一条消息、收到回答后就会出现。

**问：为什么缓存命中率有时候不显示？**

只有当本会话的请求发生过缓存读写时才显示。刚开始的新会话通常还没有缓存交互。

**问：上下文占用条的颜色变红是什么意思？**

占用超过 90% 会醒目显示，提示上下文即将接近模型的窗口上限。可以在弹层里查看是哪部分占得多（例如历史工具结果），或开启新话题以减轻上下文压力。

**问：以前顶栏的用量徽章和齿轮菜单里的上下文用量去哪了？**

都合并进了这条状态条：用量徽章就在左侧，上下文占用条在右侧。齿轮菜单现在只保留「权限模式」。
