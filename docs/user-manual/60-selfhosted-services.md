# 自部署服务：MinerU 与 DrawIO

> 了解如何在 Sage 里接入自部署的 MinerU 文档解析与 DrawIO 图表渲染服务，以及设置页卡片怎么用。

---

## 1. 在 Sage 里能接入哪些自部署服务

Sage 支持把你**自己部署的服务**接进来使用，目前有两类：

| 服务 | 用途 | 在哪配置 |
|------|------|----------|
| **MinerU** | 高保真文档解析：把 PDF / 图片等文档转成结构化文本、表格、公式 | 设置页「MinerU 文档解析」卡片 |
| **DrawIO** | 让 AI 画出可缩放、可下载的流程图 / 架构图 | 环境变量（见第 4 节） |

不需要任何云端账号——只要你的服务在自己或内网环境可访问即可。

## 2. 配置 MinerU（设置页卡片）

打开「设置 → 外部服务 → MinerU 文档解析」，你会看到一张卡片：

| 字段 | 怎么填 |
|------|--------|
| **服务地址（Base URL）** | 你的 MinerU 服务地址，例如 `http://10.0.0.8:8000` |
| **API Key** | 服务若要求鉴权则填写；留空表示匿名访问 |
| **启用** | 勾选后才会在对话里真正调用 MinerU |
| **在聊天附件中使用** | 勾选后，直接拖进对话的文档会走 MinerU 解析 |

填好后点 **保存**。卡片顶部会显示一条**服务状态**：

- **服务可达**：说明 Sage 已成功连上你的 MinerU，括号里是对方的鉴权模式；
- **服务不可达**：括号里会给出原因（例如地址写错、服务没启动、网络不通）；
- 如果服务要求鉴权而你还没填 API Key，会额外用红色提示提醒你补上。

> 🔒 你填写的 API Key 会**加密后**保存在本机，界面上不会明文回显，也不会出现在任何状态信息里。

## 3. 用 AI 画图（DrawIO）

部署好 DrawIO 之后，只需要在对话里描述你要的图，例如：

> 画一个"用户下单 → 支付 → 发货"的三节点流程图

AI 会生成图表并直接显示在对话气泡里。图表是**可交互**的：

- **拖拽**移动视图；
- **Ctrl + 滚轮**缩放（双击复位）；
- 工具栏可**适应屏幕 / 实际大小**；
- 支持**下载 PNG / SVG**、**全屏**查看。

**刷新页面或切换会话后图表依然在**——图片已经存到本地媒体库，不会丢。

## 4. 部署 DrawIO（进阶）

DrawIO 通过环境变量接入，不需要在设置页填：

| 环境变量 | 说明 | 示例 |
|----------|------|------|
| `DRAWIO_BASE_URL` | DrawIO 图编辑器的地址 | `http://localhost:8080` 或 `https://embed.diagrams.net` |
| `CHROME_PATH` | 用于渲染的系统 Chrome / Edge 路径 | `C:\Program Files\Google\Chrome\Application\chrome.exe` |

自己部署一个最简单的办法：

```bash
docker run -d --name sage-drawio -p 8080:8080 jgraph/drawio
export DRAWIO_BASE_URL=http://localhost:8080
```

然后正常启动 Sage 桌面端即可。

## 5. 常见问题

**Q：卡片显示「服务不可达」怎么办？**
先确认服务地址能在浏览器里打开（浏览器访问 `你的地址` 应有响应）；再看原因里的提示——最常见是地址端口写错或服务没启动。

**Q：填了 API Key 还提示需要鉴权？**
保存后状态会自动刷新；如果仍提示，检查 Key 是否有效、服务端是否真的开启了鉴权。

**Q：画图不出现 / 报错？**
确认已按第 4 节设置 `CHROME_PATH`（系统里要有 Chrome 或 Edge），并确认 `DRAWIO_BASE_URL` 可达。

**Q：MinerU 和 DrawIO 的密钥安全吗？**
MinerU 的 API Key 加密存储在本机；DrawIO 不涉及密钥，仅通过环境变量配置地址。
