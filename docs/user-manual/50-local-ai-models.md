# 本地 AI 模型（OCR / 语义检索）

> Sage 的文字识别与记忆语义检索依赖本地 AI 模型。安装包已内置这些模型，安装后即可使用；
> 内网环境如需换用新版模型，可用「从本地导入」功能。

---

## 1. 涉及哪些功能？

Sage 内置两个模型，分别支撑两项功能：

| 功能 | 在哪用 | 所需模型 |
| --- | --- | --- |
| 文字识别（OCR） | 截图、图片转文字 | RapidOCR 模型（约 6MB） |
| 语义检索 | 记忆搜索、按意思找内容 | 语义嵌入模型（约 91MB） |

**安装包已自带这两个模型**，正常安装后无需任何额外下载即可使用。

---

## 2. 怎么确认模型是否可用？

- **OCR**：打开 设置 → 本地 OCR，可看到当前 OCR 引擎状态；可用即可识别图片。
- **语义检索**：打开 设置 → 记忆，语义嵌入区域会显示当前嵌入器类型与维度。
  若显示为「HashEmbedder」而非 ONNX，说明语义模型未加载（功能降级为字面匹配）。

---

## 3. 从本地导入模型（内网 / 升级场景）

当您在内网环境，需要手动分发自带的模型文件时：

1. 由 IT 将模型文件拷到本机（U 盘或内网共享均可）；
2. 打开对应设置页：
   - OCR：设置 → 本地 OCR → 点击「从本地导入」
   - 语义嵌入：设置 → 记忆 → 语义嵌入区 → 点击「从本地导入」
3. 在弹出的**目录选择框**中，选中包含模型文件的文件夹；
4. Sage 会自动复制文件并进行完整性校验；
5. 看到成功提示后，功能立即可用。

### 目录里需要放什么？

| 模型 | 需要的文件 |
| --- | --- |
| OCR | `det.onnx`、`rec.onnx` |
| 语义嵌入 | `model.onnx`、`tokenizer.json` |

文件可以放在所选文件夹的**根目录**，也可以放在**一层子文件夹**里（例如把
`model.onnx` 放在 `onnx/` 子文件夹中）。Sage 会自动找。

---

## 4. 常见问题

**Q：导入时提示「找不到文件」？**
A：请确认所选文件夹（或其一层子文件夹）中包含上表列出的全部文件。

**Q：导入时提示「sha256 不匹配」？**
A：所选文件的版本与 Sage 期望的不一致。请联系管理员获取对应版本的模型文件。

**Q：我想用更新的模型，但不想重装整个应用？**
A：把新模型通过「从本地导入」导入即可，导入的模型会优先于安装包内置的模型。

**Q：模型缺失会怎样？**
A：功能不会崩溃，而是自动降级：OCR 不可用时可能回退系统识别；语义检索会退化为
近似字面匹配。补齐模型后恢复正常。

---

## 5. 开发者提示

模型文件不随源码仓库分发。本地开发或自行构建安装包时，先运行：

```bash
bash scripts/download-models.sh
```
