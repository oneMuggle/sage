## 0. 结论速览

BU8 头部行只报"已消耗/预算（%）"不报**剩余**；墙钟上限启用时未触顶前
聚合头部没有任何时间进度信息——conductor 判断"是否值得再派一轮"时缺
剩余额度与已用时长两个输入。本轮补全：预算行追加"剩余 N tokens"；
墙钟启用未触顶时新增"已运行 M 分钟 / 上限 L 分钟"行。

## 2. 设计（批次 A：BU18）

- **预算行**：`已消耗 X / 预算 Y tokens（Z%）` → 追加 `，剩余 R`（R = Y-X，可为 0）。
- **墙钟行**：`run_wall_clock_limit_min > 0` 且未触顶且已开始派发时，
  新增 `- 已运行 M 分钟 / 上限 L 分钟。`（M = elapsed 分钟向下取整）。
- **测试**：+2 例（预算行含剩余 / 墙钟行在启用未触顶时出现且未启用不出现）。
