# r70 批次计划：MCP OAuth 401 自愈——失效 token 清理 + 错误面点名

日期：2026-09-18（分支创建于 main@e99f12c0，含 OAuth 切片 1-3c）
文件面：http_client.py（401 处理分支）+ 单测；零 UI 改动。

## 背景

OAuth 链路（#984/#989/#998/#1039/#1056/#1066）目前的缺口：token 被服务端
吊销/过期且 refresh_token 也失效时，客户端每次请求仍带着死 token 打 401，
用户只看到含混的 "MCP HTTP error (tools/list): ..."。且 r65 的 🔑 角标
依然显示"已授权"——状态说谎。

## 交付

1. `HttpClientMcpClient._post`：401 且本次请求携带了 OAuth 头 →
   - 删除该服务器 token 记录（自愈：下次请求回退匿名/等待重授权，
     r65 角标同步消失——状态不再说谎）；
   - 抛 `McpClientError`，消息点名「OAuth 凭据已失效（已清除），
     请在设置中重新授权」。
2. 无 OAuth 头时的 401 → 错误信息保持原样（不误导）。
3. 测试：401 + token → 记录被清 + 错误文案点名；401 无 token →
   原错误面；token 保留场景不受影响。

## 不做
- 自动弹出浏览器重授权（需要前台交互，401 后由用户在设置手动点
  「授权」——r64 入口已就绪）。
