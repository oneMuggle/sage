# 网页访问 Round 34：AB3 指纹使用按 host 细分（2026-09-24）

## 设计

- `tls_transport` 增 `_stats_hosts`（host → 次数，与 `_stats` 同锁）；
  `handle_request` 成功发出即按 URL host 计数；
- `stats()` 返回 `{"requests": N, "hosts": {host: count}}`（hosts 排序）；
  host 数超 `MAX_TLS_STATS_HOSTS=100` 整体清零（诊断视角，保新弃旧）；
- metrics 快照键 `tls_fingerprint` 形状扩展（新增 hosts 子键），前端无需
  改动即可忽略。
