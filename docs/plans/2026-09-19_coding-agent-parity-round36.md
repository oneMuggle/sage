BU17 给聚合块标题加了任务级 token 消耗，但没有时长——conductor 判断

## 2. 设计（批次 A：BU20）

- **dispatcher**：BU17 标注扩展为 `（消耗 N tokens · 耗时 S 秒）`——
  S = finished_at - started_at（秒，四舍五入）；二者任一缺失只显示另一个；
  都无则不加标注。
- **测试**：+1 例（消耗+时长并排 / 只有时长 / 都无）。
