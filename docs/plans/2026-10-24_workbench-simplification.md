# 工作台页面简化重构

> 日期：2026-10-24
> 分支：feat/workbench-simplification
> 状态：✅ 已完成（PR #2453 已创建）

---

## 背景与目标

用户反馈项目工作台页面"太复杂，不知道如何使用"。具体痛点：

1. **信息过载**：打开页面即看到大量按钮（11 个 toolbar 按钮 + 9 个 hover 按钮），无清晰起点
2. **术语不可理解**：L2/L3/L4 是内部架构概念，不应暴露给用户
3. **布局无流程感**：不知道第一步该做什么，页面元素之间没有优先级

**目标**：让用户 3 秒内知道该怎么做，5 秒内开始第一次会话。

## 技术方案

### 页面结构（三段式）

简化后 `Projects.tsx` 只有三层：

```
1. 快速开始卡片（CTA 入口）
   - [新建对话] → /welcome
   - [纳管已有项目] → 打开向导
   - 拖入文件夹也触发向导

2. 项目列表（主体）
   - 直接展示 WorkbenchProjectList
   - 列表项 hover：主按钮（开始会话）+ ··· 菜单

3. 高级功能入口（折叠区）
   - 复制路径列表 / 导出台账 Markdown
```

### 术语替换

| 当前（UI） | 替换为 |
|---|---|
| L2 约束 | 项目规则 |
| L3 画像 | AI 认知 |
| L4 受控资料 | 项目资料 |
| 形态分布统计存 L3 | （删除此按钮） |
| 台账转 L2 护栏 | （删除此按钮） |
| 项目原型 Archetype | 项目类型 |

### Toolbar 删减

**完全删除**：统计存 L3 / 统计存 L4 / 统计转里程碑 / 统计转 L2 / 存台账至 L3 / 存台账至 L4 / 台账转里程碑 / 台账转 L2 护栏

**移入高级折叠区**：复制路径列表 / 导出台账 MD

**保留**：刷新按钮（改为图标）/ 项目计数

### ProjectArchetypeStudio

首页不再渲染（保留组件本身，项目设置中可用）。

### 项目行 hover 操作

| 当前（9 个） | 简化后 |
|---|---|
| +里程碑 / +L2 / +脚手架 / +L3 / +L4 / 复制路径 / +会话 / ✕ | 主按钮（开始会话）+ `···` 菜单（项目设置 / 里程碑 / 规则 / 资料 / 初始化目录 / 复制路径 / 移除） |

### ProjectGovernance Tab 改名

| 当前 | 新名 |
|---|---|
| 态势卡片 | 概览 |
| L1 项目总纲 | 基本信息 |
| L4 受控资料 | 项目资料 |
| 治理规则 | 规则与约束 |
| L3 画像 | AI 认知 |
