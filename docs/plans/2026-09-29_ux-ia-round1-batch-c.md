# UX-IA Round 1 · 批次 C：输入框「+」工具菜单

## 1. 目标
参考 ChatGPT / Claude / Gemini 的输入框布局，把输入框右侧零散的图标按钮收进左侧的一个「+」菜单，好让文本区更宽，界面更简洁。

## 2. 入口迁移
| 入口 | 原位置 | 新位置 |
|---|---|---|
| 图片上传 | 右侧图标行 | 「+」菜单 · image |
| 文件上传 | 右侧图标行 | 「+」菜单 · file |
| 知识库选择 | 右侧图标行 | 「+」菜单 · knowledge |
| 定时任务 | 右侧图标行 | 「+」菜单 · schedule |
| @ 提及 | 仅键入 | 「+」菜单 · mention（在末尾追加 `@`，前面自动补空格） |
| / 命令 | 仅键入 | 「+」菜单 · command（输入框为空时才可用） |
| 音频上传 | 右侧图标行 | **保持独立按钮**（原因见 §3） |

菜单只显示已传入 handler 的项。点击外部、按 Esc 或选中某项后菜单关闭；输入框 disabled 时「+」也一起禁用。

## 3. 决策
- `AttachmentUpload`（音频）自带上传状态。放进菜单的话，菜单一关它就会卸载，上传会中断，所以把它保留为常驻按钮。
- 模型选择器和上下文徽标的位置**本批次不动**，留到后续批次。
