# 浏览器进程树收尾加固——crashpad 禁用 + profile 残留清扫（R46，2026-09-25）

- **上游文档**：web-access 总账 §4；R26 树杀时序修复
- **范围**：后端 only（browser_cdp.py + test_browser_tool.py）

## 0. 结论速览

R26 修复树杀时序后，全量单测仍偶发残留一棵 chrome 树并锁住临时目录。
实证两层原因与对策：

1. **crashpad-handler 脱离进程树**：taskkill /T 按父 PID 遍历，被系统
   重派生的子进程遍历不到 → `_kill_profile_stragglers`：按 user_data_dir
   路径精确匹配（CIM + regex Escape + Stop-Process）清扫残留；
2. **crashpad 本不该启动**：`--disable-crashpad` + `--disable-breakpad`
   启动参数（无头自动化无需崩溃上报；旧 Chrome 忽略未知开关无害）。

## 实证（本机 Windows + Chrome 153）

- E2E：杀主进程孤儿化 crashpad → 生产 `_terminate_session` → 目录删除
  成功（修复前目录被锁不可删）；
- 残留计数在收尾后为自行退出中的短暂进程，不再持锁。
