# perf 预算测试 CI 环境容忍系数（R48，2026-09-25）

- **实证**：R44/R47 期 CI 反复在 `tests/perf` 预算断言上失败（事件投影
  0.535s/0.735s vs 0.5s 预算），本地同测试稳定通过——GitHub 共享 runner
  性能方差远超 0.5s 级预算的容错空间。
- **修复**：`tests/perf/conftest.py` 提供 `budget(seconds)`——
  `GITHUB_ACTIONS=true` 时预算 ×3，本地原值。三个 perf 文件（D1c 扩展 /
  session projection / backfill dualwrite）的字面量与 BUDGET_* 常量全部
  接入；失败信息不变（仍报实际耗时）。
- **语义**：数值门禁保留（CI 上超 1.5s 仍失败）；只消除"环境慢但代码没
  慢"的假阳性。
