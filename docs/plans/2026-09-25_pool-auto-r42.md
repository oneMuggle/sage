# 网页访问 Round 42：渲染池默认配置自动扩槽（2026-09-25）

- **上游文档**：web-access 总账 §3 第 7 项（P4）；R38 §5 评估结论
- **范围**：后端 only（web_render.py + test_web_render.py）

## 0. 结论速览

R38 将"渲染池槽位自动调优"列为推迟（理由：与显式配置语义冲突）。R42 以
**默认/显式二分**化解冲突：

- 用户**未配置** render_pool_size（配置键缺失）→ 自动模式：槽位上限
  RENDER_POOL_SIZE_MAX=4，持续并发下懒增；
- 用户**显式配置**（含显式 2）→ 钉死为配置值，不自动扩；
- 配置读取失败 → 按非自动处理（保持 R25 现状行为）。

## 设计

- `_render_pool_auto()`：配置键缺失 → True（自动）；存在 → False；
  任何异常 → False；
- `_RendererPool.acquire`：cap = 自动模式 ? MAX : 配置值；
  `_render_pool_ids(max(cap, len(entries)))` 懒增缺失槽（last_used=0
  会被 LRU 优先选中）；
- 缩小不回收已活实例（沿用 R25 语义）。
