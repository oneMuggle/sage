# 稳定收尾 R28：冷导入子进程超时加固 + AB3 使用计数可观测（2026-09-24）

- **上游文档**：Round 27（AB3 TLS 指纹，#1482/#1498）；issue #484 回归测试
- **范围**：后端 only（test_init_no_circular.py / tls_transport.py / web_metrics.py /
  web_access_routes.py + 测试）

## 0. 结论速览

R27 全量单测出现一次 `test_init_no_circular` 失败：子进程冷导入在 `-n auto`
高负载下超过 60s 硬超时（冷启动要加载 jieba 词典等，抖动窗口真实存在）。
批次 1 放宽子进程超时（60→150s 默认；doctor 冒烟 30→90s）。批次 2 给 AB3
指纹传输器补使用计数（请求经指纹通道发出的次数），并进
`GET /api/v1/web-access/metrics` 快照——R27 落地后"有没有人在用、用了多少"
首次可见。

## 设计

### 批次 1：子进程超时加固

- `_run_in_fresh_subprocess` 默认 `timeout` 60→150（-n auto 全量并发下
  冷导入 P99 实测逼近 60s）；
- doctor 冒烟用例 30→90（完整 CLI 引导比裸 import 更重）；
- 断言语义不变——超时仍是失败，只是不再把负载抖动误报为回归。

### 批次 2：AB3 使用计数

- `tls_transport` 增模块级计数 `_stats = {"requests": 0}`：
  `CurlImpersonateTransport.handle_request` 成功发出即 +1（异常不计数）；
- `tls_transport.stats()` 返回拷贝（线程安全，锁内读）；
- `web_access_routes._metrics_snapshot` 合并
  `"tls_fingerprint": tls_transport.stats()` 键——配置未开启/从未使用时
  该键计数为 0（仍存在，便于前端统一渲染）；
- 测试：handle_request 计数递增；stats 返回拷贝（外部修改不影响内部）；
  快照合并键存在。
