# UX N1 批：数字输入 / hover 误触 / 会话标题 / 压缩归档（2026-11-01）

> 分支：`feat/ux-n1-fixes`  
> 基线：`origin/main` @ 动态预算 P1 合并后

## 1. 范围

来自原始体验问题清单中风险最低、收益最高的四项（纯前端）：

1. **数字输入框可清空**：新增共享 `NumberField`，允许空/中间态 draft；
2. **消息操作按钮 hover 误触**：不再 `hidden ↔ flex` 切换布局，改为保留占位；
3. **窄分辨率会话标题被压缩**：会话操作按钮改为绝对定位悬浮层，不占标题宽度；
4. **压缩归档入口**：`CompactBanner` 增加「查看压缩前原文」，打开 `ArchivesModal`。

## 2. 实现

- `src/shared/ui/NumberField.tsx`
  - draft 状态允许 `''`、`-`、`0.` 等中间态；
  - 合法值即时提交；越界值默认钳制提交（BasicTab 语义），
    `clampOnChange={false}` 时只保留 draft、失焦再钳制（编排页防 0 落库）；
  - Enter 提交并失焦，Escape 还原当前已提交值，blur 恢复非法 draft。
- `BasicTab` / `OrchestrationTab` 数字输入迁移到共享组件。
- `MessageActionBar` 次级操作：`invisible opacity-0 pointer-events-none` ↔ hover/focus 可见，
  按钮位置固定，不再改变布局与命中区域。
- `SessionItem` 操作按钮：`absolute right-1 top-1` 悬浮层 + `group-hover`/`group-focus-within`
  显现；标题获得完整宽度并加 `title` tooltip。
- 压缩归档：`src/entities/chat/compactionArchivesStore.ts` 承接 `CompactBanner` 打开请求；
  `Chat.tsx` 订阅并对当前会话打开 `ArchivesModal`。
