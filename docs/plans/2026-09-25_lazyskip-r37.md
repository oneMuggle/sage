# 网页访问 Round 37：懒加载滚动快路径跳过（2026-09-25）

- **上游文档**：web-access 总账 §3；Round 3 触底滚动（R3）
- **范围**：后端 only（web_render.py + test_render_depth.py）

## 0. 结论速览

`_scroll_for_lazy_load` 对**每个渲染页面**无条件做最多 3 轮触底滚动
（每轮 0.4s 暂停），而多数页面根本没有懒加载标记——纯浪费时间
（典型 ~1.2s/渲染）。R37 在滚动前先探测懒加载指示器（lazy 图 /
data-src / lazy 类），无标记直接返回；有标记或探测失败保守走原路径。

## 设计

- `_HAS_LAZY_MARKER_EXPRESSION`：`querySelector('img[loading=lazy],
  img[data-src],[data-src],.lazyload,.lazy-loading')`（属性值用无引号
  CSS 形态，避免与 JS 字符串引号冲突）；
- 探测失败 / 上下文销毁 → 保守按"可能有懒加载"走原滚动；
- 既有滚动测试的探测消耗：test_render_depth 的回放假体对探针短路
  （不消耗回放序列）；三个滚动用例计数 +1 并新增 skip 用例。
